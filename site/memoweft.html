Capabilities

能力清单

Layered

四层记忆模型

证据 → 经历 → 认知 → 画像。每一层可溯源到下一层，结论永远带出处。

Source-aware

来源感知固化

对话、感知、操作，三种来源分开记录、分开采信。observed 数据默认不上云。

Honest

事实与推测分离

推测只作带把握度的候选，不冒充事实；冲突并排呈现，不静默覆盖。

Flexible

embedder 可选

支持接入向量 embedder；不配也有关键词召回兜底，开箱即用。

Portable

导入导出标准

记忆包是一个文件：可备份、可迁移、可审计。记忆属于用户，不属于某个模型。

Stack

TypeScript · node:sqlite

零原生依赖，单文件落库。一个 npm 包，装进任何 Node 应用。

Quickstart

三行，跑起来

terminal · index.ts 
# 安装
$ npm install memoweft

import { MemoryStore } from "memoweft";

const mem = await MemoryStore.open("./weft.db");  // node:sqlite，零原生依赖
await mem.ingest(turns);                         // 证据 → 经历 → 认知
const profile = await mem.profile();             // 事实与推测，分开放置
