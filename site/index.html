核心亮点

不止于记得你，更在于分得清

大多数"AI 记忆"只是把你说的话塞进向量库。WeftMate 的底座 MemoWeft 会把"记住"和"采信"分开——它记，但不乱信、不乱忘、不乱脑补。

🧭

越用越懂你

相处 → 感知 → 整理成画像 → 更懂你 → 更懂地帮你。这个循环转得越久，她对你的理解越准、越全。

⚖️
独有 · 立身之本

记得住，还分得清

你亲口说的是事实，它推断出来的只是低把握度的猜测——两种记录分开存。矛盾会摆出来问你，而不是静默覆盖。

🔄

换模型 · 重开都不忘

记忆是可迁移的，不绑定某个模型。今天用一个模型、明天换一个，同一份"懂你"一直都在。

👁️

记忆看得见、还能纠错

"她对你的了解"是一块能看还能改的画像面板，按来源分：感知来的 / 对话推断的 / 你改删过的。错了当场纠。

🎭

一份"懂你"，换张脸都在

人格是可切换的能力包——语气、形象、声音、默认模型一起换。切人格 = 切包，对你的了解不丢。星瑶只是其中一个。

🔒

本地优先 · 授权清晰

数据落在你自己机器上，感知内容默认不上云。自带 API key（BYOK）。WeftMate 采用专有授权，底层 MemoWeft 保持独立开源。

核心 · 懂你的循环

她怎么越用越懂你

不是一次问答就"懂"了。懂你是一个持续转动的循环，MemoWeft 是循环里的记忆引擎。

01相处聊天、让她帮你写代码 / 干日常活
02感知她看到你在忙什么、设备什么状态
03 · 引擎MemoWeft 整理沉淀成画像:哪些是事实、哪些只是猜测
04更懂你对你的理解越攒越准、越全
05更懂地帮你带着"懂你"回到相处,如此循环

循环转得越久 → 越用越懂你。

分事实与猜测、会随时间变淡；把"她对你的了解"做成看得见、能纠错的面板，按来源归类，一目了然。

🫶

想要陪伴感的人

我们的诚实纪律

不吹大，是我们的产品气质

别的 AI 爱说"真正懂你"。我们不这么写——因为记下来不等于采信。诚实本身，就是长期陪伴该有的样子。

🎯 记 ≠ 信
推测只能是低把握度的候选，绝不冒充事实。我们不承诺"真正理解你"——它知道哪些能信、哪些只是猜、哪些要再问你确认。
🔕 少而准
凡是主动打断你的（提醒 / 建议 / 发问）都少而准。伴侣最忌唠叨——克制，是能感知到的体贴。
🧩 冲突不静默
前后矛盾的信息会并排摆出来问你，而不是偷偷选一个当赢家。过期的状态也会慢慢变淡，不会一直当成现在的你。
