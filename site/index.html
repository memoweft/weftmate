记得住，也分得清

记忆气泡

「记住了 · 还没确认 · 改 / 删」织进聊天流。管理记忆，不用离开对话。

画像：事实与推测

你亲口说的是事实，它推断的只是带把握度的候选。来源分三类：对话、感知、操作。修改与指正，是两个通道。

人格切换

星瑶、Aria、普通助手——人格是可切换的外壳，即时生效。外壳不拥有记忆：它们共享同一份。

Agent · 三档自主度

只建议 / 问一下 / 放手做。每一步可视，每一版可快照撤回。动手之前，先给你看计划。

MCP 一键安装

官方 MCP SDK · stdio。像装扩展一样装能力——可以先装、保持关闭，需要时再启用。

隐私，默认收紧

apiKey 经 safeStorage 加密，不明文落盘。observed 感知数据默认不上云。记忆包一键导出，来去自由。

记 ≠ 信
记下来不等于采信。推测永远是候选，不冒充事实。
冲突不静默
前后矛盾的信息并排摆出来问你，而不是偷偷选一个。
打断，少而准
主动开口之前先过一遍必要性。克制是可感知的。
