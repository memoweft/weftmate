# MOB-4 · 手机可以单独使用

没有电脑的新账号注册后直接进入聊天，五项导航和设置均可访问；没有模型时原地打开提供方预设、获取密钥说明、测试连接。安卓复用本机模型库与 Android Keystore（安卓密钥库），M3-A（手机加密对话）容器按云来源与账号保存对话；网页自填密钥仅在本次页面内存中有效，刷新后清空，对话仍加密保存。

`native-verification.json` 记录真实 HybridActivity（安卓网页活动）和原生桥：实际注册表单、设置表单、MiMo（云端模型）测试与回复、五项导航、手机模型、加密文件密钥字节扫描、杀应用重开，以及首次加入合成电脑后进入原摄取接口。`web-verification.json` 是同一界面的真实浏览器流程；提供方请求走本机测试传输，以便验证浏览器允许直连的情况，没有改变产品请求逻辑。

所有账号、邮箱、云数据库、电脑和端口均为合成／临时环境。合成云使用真实账号、PKCE（授权码校验）与 DPoP（设备持有证明）；仅电脑在线状态和回环地址由测试传输补足，内容认证、设备信封和上传使用产品代码。电脑的记忆摄取器为合成接受器，证明原轮次进入摄取边界，不声称证明真实记忆形成。真实模型使用 `mimo-v2.6-flash`；密钥由机器环境变量读取，测试桥注入表单，不打印或写入夹具文件。

## 界面与系统栏

360×780／390×844、浅／深各覆盖聊天、动态、健康、目标、成果库、模型、设备、记忆；提供方菜单有浅／深打开状态。原生 PNG（图片格式）由 ADB（安卓调试桥）直接获取整屏，保留系统状态栏；尺寸由 CDP（浏览器调试协议）模拟网页视口，不改模拟器分辨率、密度、主题或输入法。原生状态栏高度、图标颜色、窗口焦点及顶部背景色差逐图列在报告。

MuMu（安卓模拟器）Android 15 的底部系统导航区域隐藏，不能据此声称底部系统栏通过。网页证据为浏览器内容视口，不包含真实手机浏览器工具栏或系统栏；这部分仍待真机。系统主题保持模拟器原值，页面分别选择浅／深。

复用既有控件、菜单、设计令牌与安全区；没有改输入区、审批卡片或底部导航结构，没有做视觉打磨。机械界面检查无命中。空状态给出图标、准确说明及下一步；所有新增选择器沿统一菜单组件。

## 衔接与边界

首次加电脑，`phoneFirst:true` 允许电脑尚未配置云模型时完成设备登记并上交原始手机轮次；旧对话仍可在手机查看。普通电脑会话、项目、工具及审批保持现有行为。现有上传回执没有可继续聊天的普通会话标识，所以旧手机对话在电脑模式下仅可阅读并返回聊天，自动接力列为遗留。电脑尚未启用记忆时保留原记录与队列重试，不声称已经记住。

S7（电脑任务暂存）的能力、兼容回退和队列均保留。无电脑时没有副本／任务接收公钥，主应用不挂载该电脑页面，因此不出现“交给电脑，上线后做”。浏览器自填模型只保留一份当前页面配置；手机单独对话暂为文字，原生语音仍使用既有转写，不提供电脑工具。

第一轮必过门曾有两项失败：新增客户端变量作用域和旧 BL-29 临时目录的 Windows（视窗系统）联接清理。前者已修正，后者复用已有有归属的临时目录清理，保留原产品断言；定向复跑通过。一次固定运行时组在合并冲突尚未解决时启动，读到冲突标记，该轮不作为通过证据。测试证书最初影响了 MiMo；现只对合成回环云采用测试 CA（证书机构），模型提供方保留原系统 TLS（加密连接）验证。

最终通过数、请求数、重活名额与清理见各验证 JSON（结构化数据）和交付结果；没有连接生产云或日用数据。
