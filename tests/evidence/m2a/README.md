本包接通的行为：回合结束交给Core持久形成工作，走M0-6后台排队与账户后台模型配置；修复账户私有本地路由被公网指纹条件拒绝的问题。下一轮等待已接受的形成工作，用MemoWeft Recall（记忆召回）查询当前消息及持续适用的称呼/表达方式偏好，去重后注入。旧注入不会进入后续请求；不足预算移除记忆，普通对话在服务失败/等待到期时继续。模型请求按原生 `inputModalities` 声明处理图像，文本模型收到图像元数据描述和原有工具文字；支持图像的模型保留原输入。

采用依据：`assistant.message.data.memoryUsed:[{id,kind,summary}]` 记录此次请求实际保留的召回依据，未命中/失败/预算移除为 `[]`。摘要来自目的模型权限过滤后的召回文本；它证明上下文依据被提供，不声称读取模型内部思考。评测器直接读指定回合字段，来源复用账户权限下的 `/memory/items/{kind}/{id}/sources`。手机/Apple（苹果客户端）标签另包。
