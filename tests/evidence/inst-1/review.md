# 独立安装窗口审查

结论：ship（可交付）。只读审查逐张检查了 16 张主图及对应的 16 张 `raw/` 原始图，并核对 `interactive-results.json` 的两条完整结果。

品牌图标、颜色、文字层级、间距与按钮焦点保持同一体系。安装和升级没有可见「下一步」；运行中覆盖明确要求先退出再重试。卸载确认显示合成数据目录并明确保留数据。浅深色的安装、自动打开、覆盖、自动重开及卸载均有真实窗口，未发现文字截断、控件重叠、程序底部裁切或先前的大片黑色余白。

主图逐像素等于原始图中 `captureGeometry` 记录的矩形，未缩放、遮盖或替换内容。原图保留 Windows 不可见的窄边界；DPI（像素密度）坐标采用各目标窗口自己的上下文。两套实际安装、覆盖及卸载的退出码均为 0；合成执行段失败为 2。数据保留、安装登记及开始菜单移除由驱动程序检查。

本次实测范围为 Windows build（系统构建号）26200、中文、144 DPI、短合成目录。其他 DPI、跨显示器移动与英文长文案未实测；磁盘不足和杀毒拦截没有分别制造故障，合成中止不能代替这些实测。隔离桌面没有 Explorer（文件管理器）任务栏，因此用同一九尺寸 ICO（Windows 图标文件）、实际安装图标哈希、卸载登记与开始菜单目标检查覆盖图标和名称，未声称已取得任务栏截图。保留系统标题栏的窗口能力，内容与按钮为 WeftMate 绘制层。

未发现需要继续修改的视觉问题。
