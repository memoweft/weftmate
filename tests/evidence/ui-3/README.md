# UI-3 同对话插话、排队与审批

复现：`node tests/integration/ui-3-queue-steer.mjs`（Windows，已安装仓库依赖及固定 DSH 产物）。

脚本通过 Playwright（界面自动化工具）的 `_electron.launch` 启动真实 WeftMate 主程序，并用 Chromium（浏览器引擎）访问同一隔离宿主。随机服务端口、系统临时目录、合成账号与合成模型，不读取或修改本人日用数据，也不调用云端或其他本地模型。

两端均验证：运行中默认插话归入原任务；Ctrl+Enter 新任务排队及输入区选择；两条排队按原生事件顺序执行；取消和编辑后重新排队的旧任务不执行；停止原任务后排队继续；「每次询问」下真实 PowerShell（命令环境）删除临时文件，允许后文件消失、拒绝后文件保留；工具来源先显示摘要，原始参数在「详情」。界面定位使用可见名称与角色。

`verification.json` 保存验收结果。`desktop-*` 是真实程序窗口，`web-*` 是远程网页；每个场景均有浅色 / 深色截图。只有合成文字、合成账号名和随机系统临时路径进入截图。

纯逻辑覆盖见 `tests/ui-core.test.ts`：意图选择、生命周期、批量事件与回执补齐、取消 / 409 / 身份切换、停止保留队列、审批与来源摘要、输出最新版本与旧版分组。界面与功能分别在组件和共享功能层实现。

范围：此包接入 M1-0b 的现有 `/personal/v1` 契约，不改后端。公开成果记录未提供目录路径时，按会话内文件名分组；可获得路径时按路径分组，旧版来自已读取的任务、时间线与资源记录。跨设备离线排队与长期稳定性不属于本包。
