# UI-P5 窗口外框与输入区收尾

2026-10-09 · `wp/ui-p5-window-chrome` · D36。本人提供的两张参考图逐张查看过，没有复制进仓库或证据。

## 已实现

- 标题栏全宽采用外框底色，左段与侧栏连续；主区独立面板、细分隔。令牌为 `--window-frame`、`--sidebar`、`--panel`、`--panel-divider`，来自 `design/tokens/tokens.json`。原生启动颜色读取打包内的生成 CSS（样式表），后续继续由原有界面主题与遮罩合成更新。FIX-6 / FIX-7 的 44px 标题栏、拖拽、原生按钮与浮层避让保留。
- 高风险审批盾牌与警示文字同色。桌面 SVG（矢量图形）的 `hidden` 属性直接切换，修复只改 JavaScript（界面脚本）属性而标签仍隐藏的问题。
- D36：设置 → 常规的「回复进行中时发送的消息」，默认排队 `queue`，可选引导 `steer`；选项各有一句说明。两端共用注册表和功能层。浏览器偏好按账户分键；桌面同时沿用既有程序账户存储，避免随机宿主端口变化丢失偏好。此偏好属于该设备的账户设置，没有增加跨设备同步接口。
- 输入区去掉方式选择；运行中直接发送遵循设置。切换对话保留偏好，临时排队快捷键不覆盖偏好，宿主接口与行为保持。界面术语为引导 / 排队。
- 首次出字前的对话阶段行合并秒数。每秒只更新现有阶段文字；不会为计时重建工具节点。输入区的普通运行状态行移除，审批 / 排队条目保留。终止、输出上限和历史读取异常仍在对话内显示。
- 停止 / 发送共用主题强调色与悬停规则。「本对话用量」放在标题右侧「输出与来源」旁的次要入口，标题下只留对话名。

## 真实程序与网页证据

执行 `node tests/integration/ui-p5-window-chrome.mjs`，以 Playwright（界面自动化工具）的 `_electron.launch` 启动真实 `main.mjs`，只用临时标记目录、随机端口、合成账号。界面请求代理到隔离合成个人宿主；模型阶段、DSH（助手运行时）日志、工具、审批、消息和队列均为合成数据。零付费模型请求，不碰日用宿主与数据。

改前基线为 `9130940`（已含 UI-P2 / UI-P3 / UI-P4）。改前 / 改后均为真实程序入口。桌面 PNG（图片文件）由系统窗口捕获，包含原生标题栏与窗口按钮；手机为 390×844 的远程桌面网页及 `apps/mobile-ui/www` 页面。

- `before-*.png`：30 张，浅 / 深两套。
- `after-*.png`：36 张，浅 / 深两套；新增两端排队条目取证。
- 桌面每套：`01-running-risk` 运行与高风险、`02-input-mode` 原输入方式 / 新常规设置、`03-collapsed` 侧栏收起、`04-maximized` 最大化、`05-settings` 设置浮层、`06-approval` 待批准操作、`07-idle` 空闲、`08-queued` 排队消息。
- 手机两种网页每套：运行与风险、设置、审批、空闲、排队。无原生标题栏。
- `before.json`：改前无页面异常。`checks.json`：改后颜色、几何与功能断言，无页面异常。

真实窗口采样验证标题栏与原生按钮区颜色一致；遮罩合成容许单通道 1 个色阶舍入误差。未开浮层时侧栏采样同色；浮层打开时检查实际计算背景同色，避免把浮层投影误认作色差。主面板采样与外框不同。检查盾牌可见 / 同色、输入区无旧方式选择、无重复运行提示、无横向溢出，停止与发送在相同悬停状态下同色。按可见名称 / 角色操作两种设置并验证实际引导、排队与排队卡片。

## 范围与边界

本包只修改约定的界面、共用功能层、外框最小主进程代码、令牌生成物和相关测试；D36 更新 PLAN / UI_SPEC，STATE 只更新 Windows-5 行。范围外的最小更新为审稿页 `scenes.json` 与对应取证映射，用于触发和验证本包审稿工作流。

没有改 `/personal/v1` 或 `steer` / `queue` 的宿主契约；没有碰 PF-1b 提示词、日用 Runtime（运行数据）或私人模型信息；没有发布程序 / 界面更新包，没有 Apple（苹果客户端）原生设置接线、真实模型推理或长期浸泡验收。
