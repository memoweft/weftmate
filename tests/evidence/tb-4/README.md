## 用量与边界

`real-mimo-usage.json`记录所有付费请求，包括第一次取证脚本通知点击标记失败的请求；8个请求，输入21754、缓存12736（包含在输入）、输出239，总计21993 token（令牌）。固定DSH（助手运行时）从真实安卓主对话创建一分钟提醒，原生调度投影动态，未读增加、真实系统通知点击定位和标为已读下降均通过。其余数据为合成边界。原模型闭环截图曾有测试兜底层，未作为视觉证据保留；行为报告与全部用量保留，最终视觉用无模型复跑。

最新网页15组检查、安卓原真实闭环11组与无模型调用复跑8组均为0页面错误。浏览器130%放大所有字体令牌，系统130%字号另在MuMu真实窗口验证。

动态缓存是同一登录身份内已读取的模型 / 常驻页面，不新增明文磁盘缓存；本包不声称重启后离线动态冷启动、实体手机或系统读屏软件验证。安卓新增`app.exit`与输入法可见事件需要新壳版本，未自行递增任何版本号。Apple（苹果端）接线清单见result（结果交接）。
