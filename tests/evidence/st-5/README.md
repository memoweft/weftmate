# 外观设置验收

使用合成账号、合成宿主 `synthetic-host`、随机端口与临时目录。真实模型请求为 0；未使用日用数据、安装版程序或任何原生模拟器。

真实 Electron（桌面程序框架）1200×800 / 480×800，远程手机网页与手机专用页面各 360×780 / 390×844，浅深色共 12 组。每组操作三种模式、开关两态、浅深强调色各四种、正文字号四档、代码字号四档，并拍下三个新增下拉的打开态，共 288 张截图。没有横向页面溢出；模式卡片和开关点击区域至少 44px。箭头、Home、Space 等键盘行为沿用统一控件，模式的读屏名称与 `aria-pressed` 状态明确。

| 选项 | 改之前看到什么 | 改之后看到什么 |
|---|---|---|
| 颜色模式 | 三个文字分段按钮 | 三张侧栏、回复与输入框缩略图；选中态有边框、底色和勾选；支持方向键与 Home / End |
| 减少动态效果 | “跟随系统／开启”的下拉 | 一个开关；首次跟随系统，本人开／关覆盖系统；可恢复跟随系统；过渡、位移、渐显、流式淡入与呼吸点停止 |
| 代码字号 | 没有独立入口，代码受固定样式控制 | 12／13／15／17 四档；行内代码和代码块实时预览，正文尺寸不变 |
| 强调色 | 电脑一个主题色，手机专用页没有色板 | 两端均有浅色强调色与深色强调色；各自保存，切换模式应用对应色板；仍使用石墨／蓝色／松绿／紫色 |
| 界面密度 | 当前两端没有有效密度控件 | 保持不提供密度；不新增假选项；旧 `density` 字段可正常读取且不会影响布局 |
| 正文字号与保存 | 电脑有正文字号，外观按设备保存 | 手机也复用相同四档；沿用各设备独立保存，旧强调色迁移到浅深两份，无新增同步机制 |

完整必过单测 1,525 项通过、0 失败、14 项既有条件跳过；指定手机交互五文件 109 项通过、0 失败、0 跳过。定向外观／回复动效／滚动／共享界面测试 71 项通过，类型检查与公开卫生扫描零命中。

偏好保存／读取／默认值／损坏值恢复／旧密度值与迁移由 [appearance.test.ts](../../appearance.test.ts) 验证。动效默认、系统／原生事件与在途取消由既有回复动效、滚动测试和本包实际界面检查共同验证。真实 Electron 退出重开保持偏好；手机专用页重载保持偏好。
