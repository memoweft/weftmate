# MOB-2 · 手机界面改版

手机采用同一组触控、阅读、留白与圆角设计令牌：两行居中顶栏、大圆角输入卡片、悬浮四选项导航；侧栏上半是主入口，下半是旁聊，搜索与新建收到底部。设置首页展示账户卡片、分组列表、可直接选择的三张外观缩略图，以及独立退出入口。对话、项目等现有对话框使用带拖动条、居中标题与圆形关闭的面板。

安卓界面包与远程浏览器保留各自现有入口。远程浏览器用小型呈现适配连接已有四个页面，不改登录或业务操作；真实 Electron（桌面程序框架）窗口通过原生标记保持原布局。没有新增依赖、模型请求、业务接口或原生权限。

## 原生系统栏的边界

MuMu（安卓模拟器）的端口从 MuMuManager 读取，使用独占 `mumu.lock` 与重活名额。独立测试浏览器 APK（安卓安装包）只展示本包的合成页面，结束会卸载、恢复屏幕和主题并断开连接；没有改安卓原生源码或版本号。

该实例的 `qemu.hw.mainkeys=1` 隐藏系统导航栏。严格验收因此失败，不能把隐藏导航栏的整屏当成系统栏已通过。诊断模式另存未经裁切、未经改色的整屏与实际系统高度，元数据明确写 `diagnosticOnly`、`bottomNavigationVisible` 和 `systemBarAccepted`。系统状态栏与页面顶栏的颜色数值见 [比较记录](comparison.json)。完整系统导航区域仍需在显示该区域的设备上补验。

## 测试与预期变更

现有点击区域、选项卡、菜单边缘翻转、长内容滚动、键盘让位、草稿、审批与账号边界断言均保留。

1. `fix-5-popovers.mjs` 的设置入口改为点击侧栏头像，再点「设置」菜单项。后面的助手设置单选、滚动与边缘断言保持原样。
2. 记忆 HTTP（网络接口）夹具的数据目录改为隔离临时目录，避免短盘符和仓库目录的权限差异；账号、游标、回执隔离断言保持原样。
3. Windows（操作系统）的完整测试命令改用相对测试文件参数，解决长工作树触发 `ENAMETOOLONG`。Node（运行时）的测试子进程继承绝对隔离报告目录，清理器仍收到绝对根目录；没有减少文件、用例或跳过范围。
4. `bl29-rework/probe-latency.mjs` 在保存全部行为观测后明确退出隔离测试程序，再关闭自动化连接，避免程序退出时调试协议的等待。会话同步、恢复显示、配置同步的原有断言与时限不变。
5. `review-capture-mobile.mjs` 的记忆场景改由设置进入，保留事实行等待；提问场景等待上一条审批动作完整收尾，再打开独立提问，保留提问区域与单选项等待。场景数量与超时时限不变。

实际测试成绩与桌面逐像素比较见 [验证记录](validation.json) 与 [比较记录](comparison.json)。截图脚本为 `tests/integration/mob-2-refresh.mjs`；系统栏严格检查与诊断为 `tests/integration/mob-2-system-bars.mjs`。

最终本地完整必过 1,693／0 失败／14 条既有跳过；手机五文件 113／0／0。桌面 8 组未见布局变化，7 张逐像素一致，480 深色设置仅 2 个像素的单通道值相差 1。共享构建 54 模块、类型检查与公开身份扫描通过。没有修改共享运行时，本地没有重跑运行时集成组，依照本包约定仅复用了已编译缓存。

## 尚未实现与原生配合

- 助手主页为低优先级展示项，本包没有增加。
- 手机界面包的设置首页已有账户卡片与三张主题缩略图；远程网页设置沿用原有分区入口，本包统一了触控尺寸与卡片样式，尚未改成相同的账户首页。远程网页的操作弹层也保留既有结构，完整面板收口以手机界面包为准。
- 文件、图片阅读继续使用现有全屏呈现；收口的是对话、项目等操作面板，没有重造阅读器。
- 安卓发布本次手机界面包即可，本包没有新业务路由或新原生能力。生产壳的系统栏传色与真实键盘仍沿已有桥，诊断截图不冒充生产壳登录或键盘验收。
- iOS（苹果手机系统）原生界面需跟进两行顶栏、输入卡片、四选项导航、旁聊侧栏、设置账户／主题卡片与操作面板；复用现有接口。macOS（苹果电脑系统）与手表布局不在本包范围。
- 云端需随现有发布流程发布新增的手机浏览器呈现资产；没有新服务配置、模型来源或接口。
