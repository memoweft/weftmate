# AND-3 · 安卓原生壳跟上主线

Android（安卓）复用主线邮箱密码／邮箱验证码登录；新设备先核对邮箱，电脑直接授予内容会话。原生壳接入已签名的电脑核对材料，首次连接沿正常 CA（证书机构）与域名验证，后续沿原有 pin（证书固定）。登录不再进入等待另一台设备批准或输入配对码的页面。

已保存的账户和内容先从本机恢复；没有登录或者登录已过期时仍保留缓存、账户范围和草稿。服务器请求仍受真实认证约束；本人需要发送时打开现有可关闭的登录弹层。原生私钥、刷新凭据与电脑 Cookie（会话凭据）继续留在 Kotlin 层。

## 固定路由保护

`node scripts/android-route-inventory.mjs` 从 `src/ui-core`、手机界面与 `docs/CLIENT_API.md` 提取客户端路径和来源；通过实际 `createAndroidBridge`（安卓桥创建函数）确定专用通道与业务通道。`ClientRouteInventoryUnitTest.kt` 调用这个脚本，逐条运行真实 `Network.kt::validBusinessPath` 和方法校验；新增业务路径遗漏白名单会使安卓 CI（持续集成）失败。Node（JavaScript 运行环境）固定测试保护提取器、来源覆盖和实际分发；允许／拒绝的查询边界留在 `BusinessRouteUnitTest.kt`。

认证、云账号、二进制附件、同步与更新使用现有专用原生通道；桌面免登、备份与桌面打开文件不能经通用手机业务桥。它们保留在路由清单里并标明通道，不用添加业务通配白名单。

## 原生验收与证据边界

运行器是 `tests/integration/and-3-android.mjs`。合成云服务、邮箱、电脑、账户、模型回复、周回顾与复核意见均属于临时测试环境；登录表单、PKCE（授权码校验）、DPoP（设备密钥持有证明）、原生密钥、凭据存储、业务桥与页面使用产品代码。真实模型请求 0；MiMo（云端模型）请求 0。测试安装使用独立包 `com.memoweft.weftmate.mobile.and3qa`，未修改版本号、依赖或 `vendor/`。

本机 MuMu（安卓模拟器）Android 15 隐藏底部导航区域，`mumu-*.png` 只证明本机原生业务与顶部栏，不作为底部系统栏通过证据。云端同一产品 `HybridActivity`（原生网页活动）及测试包在库存 Android 14 上运行；`cloud-*.png` 为原始整屏，逐张主题、系统版本、原生安全区、顶部／底部背景色差记录在 `cloud-verification.json`。云端使用现有安卓模拟器取证方式，不用网页容器替代产品原生桥。

需要新壳版本：新增原生登录能力、业务路由及审批范围；由 Claude 合并时统一递增。原生版本号与界面最低版本要求未改。

### 其他验证与失败记录

- `npm run typecheck` 通过；`node apps/mobile-ui/src/build-ui-core.mjs` 生成 57 个共享文件；公开证据扫描 0 命中。
- 不隐去失败：第一轮完整必过的清理遇到 Windows 联接权限错误，修复为先解除测试目录内的链接、不递归进入外部缓存，新增外部哨兵保持不变的回归用例。第二轮一个运行时文件以 `0xC0000409` 退出；完整第三轮通过，未增加跳过或改变产品断言。
- 前两轮 vendor 的 BL-29b M5 在整体启动预算内未完成，产品退出时限断言保留；进程身份登记改为与程序启动并行，仍核对创建时间、可执行文件和独立测试目录。
- 云端曾发现设备与云签名时间相差数秒：复用现有 30 秒未来时钟容差，保持过期材料立即拒绝，并保留错误设备、错误签名与超时的拒绝用例。还修复了取证读到半份原生 JSON 的竞态；真实原生窗口焦点和系统栏断言会拒绝系统对话框遮挡。
- 原生导航期间安全区注入早于网页根节点创建，曾产生空节点样式异常。根节点未就绪时等待既有页面完成回调重新注入；最终运行器要求全程 0 界面异常，不把初期带异常的报告当成最终通过证据。

## 界面自查与边界

复用已有按钮、菜单、底部导航及登录弹层；没有新增依赖、原生权限或首次使用配置步骤。登录错误使用现有三态与重试，缓存阅读和取消登录继续可用。原生页面沿已有标题、安全区及设计令牌；360×780、390×844 各有浅／深原图，登录方法选择、邮箱确认、过期登录弹层和审批详情均保留打开状态证据。截图前只在键盘确实显示时收起键盘，草稿与登录状态仍由断言核对。

电脑离线用转发门返回受控 503，恢复后沿真实原生传输重试；不将它称作真实电脑断电。登录过期由合成电脑时钟跨过真实会话有效期触发，不修改客户端认证响应。健康页验证尚未接入的真实状态；没有连接真机健康传感器。一加 13 真机与生产云账号／真实电脑仍待本人试用，本包不访问本人安装或日用数据。
