# 健康页验收（合成数据）

打开健康先读一句今日解读，再看恢复、睡眠和负荷。模型版与统计版用同一张卡；详情可展开解读，趋势用自己的常见范围与连续记录说明变化。电脑有常驻趋势与一周小结，手机使用单列与五项悬浮导航。

所有截图和接口响应都来自 `tests/helpers/health-page-synthetic.mjs` 的 90 天合成数据。开工时只有 HEALTH-2 的接口文档，没有其生成器或算法文件，因此按文档制作同结构夹具。参考图只在私人目录中查看，没有复制参考图或其中数值。模型请求为零；宿主、账号、端口与目录均为隔离测试用途。

## 契约缺口与后续接线

没有更改宿主接口或算法。现有 overview（今日概况）没有电脑最后使用时刻、负荷建议区间与周回顾独立健康文字；睡眠分期通过已有的逐项指标接口读取；页面解释其余缺项，一周小结暂用七天均值与当日有明确睡眠/使用依据的观察。负荷灰带仅表示个人常见范围，不把它冒充建议。首次还没有任何可用对话时，提醒接口所需 sessionId（会话标识）无法填写，轻提示先开始对话；不会自动请求模型或造会话。

Android 精确健康路径白名单与新壳版本由 HEALTH-2 / 发布方配合；本包没有改原生壳与版本。Apple（苹果端）应复用 overview / metrics / calendar / suggestions 提醒接口，接入后展示同样的缺项和统计解读，引用动作只填主对话草稿。
