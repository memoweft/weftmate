# HF-2 · 主进程卡顿回归

本包针对 Windows Electron（桌面程序框架）承载 personal-access（个人访问服务）时的真实热路径：停止请求未确认 → 每秒更新尝试时间戳 → 原子替换 store（状态存储）→ 同步 PowerShell ACL（访问控制列表）验证。

## 复现

```powershell
node tests/integration/hf-2-stalls-electron.mjs --baseline
node tests/integration/hf-2-stalls-electron.mjs
```

只运行在 Windows；每次创建临时账户数据目录及随机模型／宿主端口，清除继承的 WeftMate／模型凭据环境配置。不会请求18186或8081。`--baseline` 在测试加载钩子中加载 `f787c3c` 的原始存储、访问服务、任务和桌面代码；不会修改检出文件或已运行的应用。

真实 `createPersonalDesktop` 窗口与 `createPersonalAccessService` 服务共同运行在同一个 Electron main（主进程）。三个合成回合各含一个根命令和三个补充命令，共12个固定回执；每个合成模型请求一直不返回，测试后端明确保持 `unconfirmed`，模拟无法确认取消的回合。store约58KB。脚本从当前对话点击真实停止按钮，确认202响应，另两个回合经正式停止接口停止；持续至少60秒，记录主进程 `monitorEventLoopDelay`、实际store rename（重命名）次数、实际同步／异步子进程启动次数、真实preload（预加载桥）IPC（进程间通信）往返和独立的窗口移动往返。

结束阶段提供绑定到相同回执的 `turn.ended` 原生结束证据，验证立即投影为已停止，修复后清除重试。基线允许继续重试，并记录该缺陷。合成后端刻意不执行DSH（助手运行时）取消；DSH精确取消由相关单元测试和独立真实主程序冒烟验证，不把这里的假后端解释成真实模型取消成功。

本机原始数字在受忽略 `.local/hf2/before.json`、`after.json`；公开报告只保留合成统计，不含账户凭据、Windows SID（安全标识符）或日用数据。临时数据目录供本机ACL读回，未提交。

## 权限证明与相关测试

`tests/private-host-storage.test.ts` 使用真实Windows `Get-Acl` 读回目录、独占新建临时文件和两次替换后的store，要求唯一Allow（允许）规则为当前账户FullControl（完全控制）。目录保护且对子文件／子目录继承；新文件继承该唯一规则。原脚本只允许当前账户，本包没有添加SYSTEM或Administrators额外权限。旧文件及被替换文件仍异步收紧、检查普通文件／硬链接／目录链接，非Windows保持0700／0600。

`tests/personal-task-stop.test.ts` 验证1、2、4、8、16、30、30秒退避，同回执只持久化一次变化，幂等停止不重写store，读取和重放停止请求不能重置退避，原生结束证据清除定时器，快速重启及晚到回执仍可收尾。`tests/latest-file-writer.test.ts` 验证并发快照保留最终完整值、相同值不写及写盘失败后的恢复。

## 同步调用排查

- `src/private-host-storage.mjs` 是全仓 `src/` 唯一同步子进程启动点，已改为异步并按路径／文件身份缓存；独占新文件直接继承已保护目录权限，热写盘无启动进程。
- 主进程常规请求文件每秒轮询、宿主状态每5秒写入、设备状态／请求每秒轮询、感知快照每5秒写入已改为异步。原有请求串行顺序保留，快照只保留最新待写值。
- 窗口移动／缩放保存改为200ms异步合并，关闭时等待最终快照。桌面成果下载、记忆导出、精灵spritesheet（精灵图集）读取及诊断导出改为异步，避免大文件阻塞主进程。
- 剩余同步文件操作为启动／恢复检查、显式小型设置事务、崩溃诊断或按需宠物配置；无常规每秒持久写。`runtime/dsh-adapter/snapshot-files.mjs`、原话擦除压缩和旧gateway（网关）文件接口属于DSH子进程；大型备份／恢复属于显式操作或每日作业。模型路由／诊断、记忆形成和对话组件留在其他工作包范围，本包不改这些功能。
