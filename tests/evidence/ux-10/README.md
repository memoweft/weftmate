# UX-10 · D55 对话行状态点

合成账号、合成项目与原生事件夹具；随机回环端口、隔离临时目录。真实模型请求 0，未向 8081 请求，未使用本人日用程序或数据。私人 Codex（代码助手）参照只在本机查看，未复制或嵌入证据。

## 状态与来源

| 优先级 | 字段事实 | 显示／读屏与提示 |
|---|---|---|
| 最高 | 原生审批 `pending` | 橙点，等你批准 |
| 最高 | 原生问题 `pending` | 橙点，等你回答；同时有审批先显示审批 |
| 次高 | `running=true` | 转圈，正在运行 |
| 下一层 | `lastOutcome=failed` 且 `unread=true` | 红点，失败 |
| 下一层 | completed／stopped／旧记录未读 | 品牌蓝点，已完成，未读 |
| 其余 | 已读或无状态 | 空 |

`personalCapabilities.sessionStatus=1`；`/sessions`、`/chats` 与单聊天投影增加 `attention`、`lastOutcome`。终态从原生 `turn.ended`／`task.ended` 的标准化 reason（结束原因）取得，seq（事件序号）决定最近一条，不用消息内容、断线或接收回执猜结果。失败即使没有助手正文也会未读；aborted／stopped 是蓝点，保留 stopped 原值。

状态走 FX-16 摘要索引：启动恢复在列表请求外，长运行回合前的终态可从更早页恢复；已观察事件增量维护，删除／遗忘失效。审批与问题按不可变账户快照一次汇总，原生运行时失效与问题终态也使该缓存失效；没有逐行新增历史或待办请求。

分页响应的 `statusSummary:{main,all,projects,groups}` 只含状态枚举／布尔值，覆盖当前全部未归档、未删除会话，含第一屏 100 条之外的子会话。临时会话同样参与，没有复制标题、问题、参数或正文。主对话使用现有 `/chats/{id}/metadata` 已读接口；既有安卓白名单已放行，无新路由。普通对话继续沿原最新位置规则，读取同时覆盖消息与终态水位。已读变化刷新汇总，新建空会话不增加此刷新。

验证日志由交付时写入同目录：完整必过单测、手机登录／聊天 100 项、相关索引与状态测试、类型检查、界面包打包及机械样式扫描。首轮完整单测 1,346 通过、1 失败、14 个既有跳过：桌面验收子进程在三个场景通过后以 `0xC0000409` 原生异常退出，未返回界面断言；单独四组复现全部通过。第二轮同一桌面用例给出了 JavaScript（脚本语言）堆耗尽诊断。开发中的快照一致性检查误用 accountState 新包装，引发重复读取，已修为底层 sessions 集合身份；交互缓存同样使用底层 commands 集合身份，并补一次扫描／运行时失效回归。修复后的相关 26 项、真实桌面单文件 3 项均通过。前两轮原日志保留，最终完整命令计数见 `required-final.txt`。

安卓界面包沿既有 0.8.23／最低原生 36 构建，未改版本号或默认值，使用隔离合成签名钥匙，钥匙随后删除；未发布。实际打包发现既有渲染许可证文件名含 `@` 且没有公开类型扩展，触发发布器拒绝；生成脚本和两端副本改为安全的 `.txt` 名称，许可证内容全部保留。这是本包范围外的最小打包修复。**不需要新壳版本**。

5. iOS 聊天选项卡有待批准／回答时显示橙点；Watch（苹果手表）对话入口如显示此状态也沿同一事实与名称。
