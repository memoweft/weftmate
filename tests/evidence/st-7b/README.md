# 邮箱与日历验收

支持 QQ、163／126、Gmail 应用专用密码、iCloud 邮箱，以及手工填写加密服务器；支持 iCloud／其它日历服务器和只读订阅日历。所有网络验证只连接随机本机端口的合成服务器，账号、邮件、附件和日程都是虚构的。

`report.json` 是合入主线后的真实 Electron（桌面程序框架）＋固定 DSH（助手运行时）＋MiMo（云端模型）闭环：可见表单添加邮箱、错误授权码／成功登录、今天邮件列表、回复先审批后实际投递、周四空闲查询、新日程先审批后实际保存、读取夹带邮件没有额外发送／删除／日历写入、移除清理。服务器每轮实际收到 1 封回复并保存 1 条日程。两轮 `attempt-*.json` 都通过，分别 24 和 20 个真实模型请求，合计 44；最后一轮为 20，不能把它当作全任务请求数。模型密钥只从机器环境读取并在测试进程内使用，连接器合成授权码使用真实加密凭证库。

`visual-report.json` 是 0 模型请求的订阅日历与打开菜单补验。68 张浅／深色 × 1200／480 图覆盖邮箱服务商、授权码、成功／失败、加密选择、日历服务商、订阅地址与测试、对话邮件列表、发信审批、建日程审批、外部夹带内容、已连接列表。主流程无协议缩写，高级服务器字段仅在「其它」出现；审批只显示中文操作事实，完整参数放在展开详情。界面仅复用现有组件，没有视觉重设计。手机列表与开关沿既有共用界面；本包未修改或声称验收原生系统栏。

`checks.json` 汇总完整必过组 339 文件 1925／0失败／14既有跳过（合主线前）、固定运行时组 35 文件 241／0／0（合主线后）、手机交互完整 5 文件 114／0／0、合主线及最终审批修正相关 8 文件 121／0、最终原生业务失败反馈与预设 5／0、打包规则 9／0、类型检查、61 个共享资源生成、公开卫生 0 命中和界面机械检查 0 项。协议固定场景为邮件 12、日历子进程 8、预设 3、原生 2；日历外层测试只有一个，但子进程的八个固定场景均强制零失败。

固定安全场景包括五种邮件夹带方式（含 SEC-2 的系统身份冒充及假审批形式）、日历夹带内容、读取不标已读／不取附件、无匹配批准回执不能发送、错误参数摘要的假批准不能删除、内置凭据不能注入环境设置、证书拒绝、短凭据遮罩、凭据不写明文配置与备份、移除清掉凭据。真实程序两轮扫描 294／293 个程序数据文件未发现授权码或模型密钥明文，运行日志未含测试邮箱地址、邮件／日程主题或夹带正文；可见对话按产品功能保留邮件与日程回答。

`package-smoke.json` 为重新打包后的 7 项真实程序冒烟，全通过且进程正常退出；包边界全为 0。`package-dependencies.json` 是实际安装包归档中的五项运行依赖版本／许可及服务模块清单，合成服务器开发依赖没有进入安装包。首次打包误报见 `package-smoke-initial.json`：Mailparser（邮件解析库）的公共域名数据与构建账号名偶合。`public-data-provenance.json` 核对官方 npm（包管理服务）完整性与数据摘要；修正仅识别已核对的原封不动的上游数据，修改字节／插入用户路径或机器名／复制到其它文件仍拒绝，未改依赖数据。审计 0 漏洞见 `dependency-audit.json`。

所有重活一次只占一个名额，结束即释放，编号见 `checks.json`；完整必过 19.5 分钟、固定运行时 8.6 分钟，均未超过 30 分钟。两轮真实模型、无模型界面、手机和两轮打包各自独立取锁。`cleanup.json` 核对本工作树、本包开始后的程序，额外清理 0、失败 0；程序自身收口与原生进程树清理由固定测试验证。安装包和大临时构建已清除，仅保留小报告与截图。

复现使用 `npm ci` 后 `npm run vendor:dsh`，不修改供应文件。轻量固定测试为 `node --test tests/st-7b-mail.test.ts tests/st-7b-calendar.test.ts tests/st-7b-presets.test.ts tests/st-7b-native.test.ts`。重活辅助入口 `node tests/helpers/st-7b-heavy.mjs required|vendor|mobile|electron|visual|package` 按本机编排规则取得名额，实际执行任务书要求的命令；`electron` 需要机器 `MIMO_API_KEY`，`visual` 不调用模型。测试不会连接任何真实邮箱、日历、日用端口或线上产品云服务。

暂不支持：Google／微软网页授权、Outlook／Exchange、附件发送、永久删除、群发超过十人、后台同步／推送、规则／自动回复、联系人、会议邀请应答、重复日程修改／删除、每日摘要／每周回顾接线，以及苹果／安卓原生添加页。日历读取时区和重复例外已测；真实服务商账号按任务边界未连接，后续授权应用注册由本人决定。
