| 问题 | 根因与修复 | 合成回归 |
|---|---|---|
| 连发草稿丢失 | 原先回执无条件清空整个编辑区。发送时只移走本次文字，失败恢复；回执不再写下一条文字，不重建编辑节点、焦点或输入连接。 | `ReleaseBlockersTest` 的草稿用例修前失败；网页 `chat-interactions.test.mjs` 核对待回执期间输入下一条，原有草稿保护通过。 |
| 指定文件查看失败 | 回退在登录恢复期间导航，异常被吞掉；额外读取来源详情会扫描历史。改为复用原生窗口中已登录的网页、从已有成果元数据打开指定文件，返回直接回到原生成果库，避免第二个网页冷启动重复恢复登录。旧／新电脑两种条目形状均覆盖。 | `release-blockers.test.mjs`：修前在未登录时提前读取，修后等待恢复；旧条目无版本字段／新条目有版本字段都准确打开同一文件，不扫描来源历史。 |
| 网页 PDF（便携文档格式）读取失败 | 业务桥限制 256 KiB（千二进制字节），又把内容截为 16,384 字符；改用已有成果预览的大小边界并保留完整正文。旧 WebView（网页内核）的 `Promise.withResolvers` 缺失另导致渲染失败；在固定 PDF.js（PDF 渲染库）的主线程／工作线程入口补齐 Promise 与可读流异步迭代能力。实际旧内核仍有白页，安卓网页查看屏因此复用已有原生 PDF 渲染器，经原账户边界内的本机桥返回逐页图片，保留网页缩放与文件工具。 | JVM（Java 虚拟机）大小与内容断言修前失败；旧 Promise（异步结果对象）环境下的实际生成入口测试修前失败，修后解析、完成、失败、流读取与释放均通过。现场像素断言确认原生非白像素92,336、网页277,627，正文可见。 |
| 深色目标页持续骨架 | 读取超时按生命周期取消传播，没有错误态；每轮自动刷新又重新置为骨架。读取加整体期限，超时转可重试错误，保留已读内容／空态；真正生命周期取消仍传播。主题不参与数据读取条件。 | 截止超时用例修前错误地得到取消异常；修后为可重试错误，父协程取消保护通过。 |
| 身份文字错误 | 设置从宿主界面核心取云登录状态；该核心不是独立的云账户核心，旧电脑只投影 `local-owner`。使用手机已有登录来源与账户核心、手机已有身份邮箱；无法取得的信息留空，不显示本机说明冒充云身份。 | 云身份＋旧本机投影用例修前失败；修后不显示错误本机资料。纯本机不显示云注销项。 |
