# UX-2 侧栏与账户菜单验收

所有截图来自隔离账号与系统临时数据目录；项目、标题、费用均为合成数据。零模型请求，未向 8081 请求，未使用本人日用程序或数据。参照截图只在仓库外读取。

`node tests/integration/ux-2-sidebar-account.mjs` 启动真实生产 Electron（桌面程序框架）窗口及随机端口的个人宿主；同时验证 390×844 手机远程网页与安卓界面包。桌面使用 `scripts/review-gallery/electron.mjs` 与生产 `createPersonalDesktop`，不是替代页面或替代窗口。宿主认证、项目目录登记、会话命令、元数据、归档与用量接口真实执行；DSH（助手运行时）会话与历史由合成后端提供。安卓界面包通过其生产原生桥接适配器在 Chromium（浏览器引擎）检查，没有安装原生安卓壳或启动模拟器。

- 两个项目分别有 8 / 7 条对话，默认最近 5 条，展开后能看较早对话，项目偏好相互独立，桌面重载仍展开，收起与搜索规则沿共享功能层。
- 桌面浅 / 深色：置顶 / 归档 / 更多并列；约 0.5 秒详情卡显示完整长标题、项目、真实活动时间和执行电脑；Tab（制表键）与 Enter（回车键）可置顶，重绘保留焦点；归档后点「撤销归档」恢复。
- 账户菜单：本机账户标识、真实合成账本费用、上限剩余；帮助定位到设置 → 关于；`Ctrl+,` 打开常规设置；退出确认取消保留账号，最后确认退出回登录页。取消月度上限后显示金额与 3 次请求。
- 安卓界面包两种主题额外验证长按置顶 / 取消置顶、归档与撤销后的真实宿主状态；撤销按钮不冒泡关闭提示，等待恢复完成后收起。
- 桌面 720×600、手机 390×844 浅 / 深色均无水平溢出。手机网页长按仍打开菜单，不显示新增悬停按钮；手机网页和安卓设置顶部用量条可进入用量详情。
- `checks.json` 记录实际运行结果。截图按 `desktop / mobile-web / android-ui`、`light / dark` 与场景命名。

相关现有会话 / 用量 / 设置 / 项目 / ui-core（共享界面功能层）及真实桌面界面回归通过；新增测试覆盖项目与账户隔离、偏好重建、存储不可用时当前窗口展开、真实时间派生、临时额度、零额度、超过上限、未计价请求与晚到的旧账户用量响应。资源调用统一显式访问 globalThis（全局对象），记忆 / 界面后续 71 项通过。类型检查通过。完整测试与审稿页验证由 PR（合并请求）的 CI（持续集成）执行。

未实现主对话与固定入口、Apple（苹果端）原生接线、安装与更新、后台或模型运行稳定性测试。本包按既有权限执行，不新增权限。

Apple 接线清单：

1. Mac（苹果电脑）会话行采用 `pin / archive / more`，悬停约 0.5 秒给出标题、项目 / 分组、`updatedAt` 与执行电脑，归档提示可撤销；触屏继续长按。
2. 每项目默认按 `updatedAt` 倒序取 5 条；更多显示剩余数量，按账户与项目保存本机展开偏好，搜索不写偏好。不要把项目置顶对话移到普通置顶区。
3. 头像菜单显示账户名 / 邮箱、金额与 `budget.effectiveLimit` 的剩余比例；未设上限显示金额与请求数，保留未计价说明；设置快捷键在 Mac 使用系统常规快捷键，帮助定位关于，退出确认。iPhone（苹果手机）设置首页顶部显示同一用量条。
4. `/sessions` 新增 `hostId` 与可选 `updatedAt`，旧宿主缺时间不伪造；用量先取 `/settings/usage.timeZone`，再取同一时区的 `/usage`，金额与比例必须来自同一完整账户月份。跨账户 / 设备异步回调需丢弃。
5. 新 `design/icons/ui/logout.svg` 已生成桌面、手机与 Apple 的普通 / 小尺寸资产；其余复用已有图标与设计令牌。Windows 生成器刷新了其他 Apple 位图，本包已恢复那些无关资产，仅保留新增退出图标，Mac 可按本端生成流程复核。
