# UI-4 设置分类与浮层验收

运行：`node tests/integration/ui-4-settings.mjs`。桌面启动生产 `createPersonalDesktop`，使用真实 Electron（桌面程序框架）、临时程序目录、随机端口、隔离宿主及合成账号；手机为 Chromium（浏览器引擎）390×844，通过合成原生桥接访问同一隔离宿主。没有真实模型请求、真实邮箱或日用数据；开机自启写入被测试拦截。

- `desktop-{light,dark}-{category}.png`：11 个分类，各有浅 / 深截图，共 22 张。用量账本是三条合成数字记录，覆盖费用、缓存、日柱状图与排行。
- `desktop-narrow.png`：真实程序 680px，左导航折叠为顶部下拉。
- `mobile-list.png`、`mobile-general.png`、`mobile-appearance.png`、`mobile-usage.png`：手机分类列表和三个子页。
- `verification.json`：行为断言结果，覆盖搜索、外观保存重载、用量费用与月度 / 临时上限持久化、对话用量直达、Esc 关闭、减少动态效果、手机搜索与返回。
