# ONB-1 首次使用引导

Windows（视窗系统）程序优先；合成云账号、临时数据目录、随机端口，未访问本人日用数据或 8081。参照图片只在本机查看，没有复制。所有新文案集中于 `src/ui-core/onboarding-copy.js`；英文随 L10N-1 补齐。

## 实现

- 仅全新安装建立引导，升级旧目录不补建；已有账户 / 未开始引导的预配置账户不自动出现。账户创建后按身份恢复中断步骤，完成后不再自动出现，设置 → 常规可重新查看。
- 欢迎、账户、模型、记忆、导入占位、连手机、第一句话七步，均可跳过与返回，进度点、焦点与读屏名称；未配置模型可跳过，首页提醒，开始聊天须有模型。
- 云注册 / 登录与本地账户沿已有流程；称呼直接写 ST-1 的 `/settings/personalization.preferredName`，不另存。ST-1 未合入时明确提示稍后设置，不伪报保存。
- MiMo（小米模型服务）、DeepSeek（深度求索模型服务）、Kimi（月之暗面模型服务）、通义、豆包、OpenAI（模型接口）兼容、Anthropic（模型提供方）官方 OpenAI 兼容与本机 / 局域网预设；官方获取密钥链接、逐项诊断、明确同意后的短消息诊断；保存回执中断恢复仅留请求编号，不存密钥。
- 自动探测本机与已有网络邻居的常见模型端口，只读 `/v1/models`；非标准端口可补充地址。结果须选择并保存，不自动添加或发送对话。自动扫描不枚举整个网段，不探测 8081。
- 记忆说明与真实健康、可整理旧对话的只读预览入口；不自动整理。历史导入置灰且标「即将支持」。
- 二维码 / 配对码沿已有同账户批准；无配对码的新设备也可在引导页允许 / 拒绝。手机网页与安卓界面包沿既有扫码、云账号与可信交付流程；未改原生壳或安卓版本号。
- 三个示例进入主对话输入框，点击填入，由本人发送；不自动执行示例。

## Apple（苹果端）接线清单

1. Mac 本机执行宿主沿 `GET/PATCH /onboarding` 识别全新安装、当前账户和中断步骤；已有账户 / 旧目录 / 已完成不自动打开。设置 → 常规增加重新查看，原生保存与返回同一服务端步骤。
2. Mac 引导视图以同一七步及中文资源为准：现有云账号 / 本地账户视图，模型预设及官方密钥链接、诊断、保存回执恢复；本机服务发现调用 `POST /models/discover`，只展示结果，由用户选择。密钥沿原钥匙串，不进普通偏好。
3. 称呼沿 ST-1 的 `PATCH /settings/personalization {preferredName}`；记忆健康与历史整理只复用第11节接口。导入禁用，完成时打开主对话并提供三条可点击的草稿示例。
4. iPhone 与远程 Mac 只接「连电脑」：扫码后保留一次性配对材料至同账户认证与消费成功，已有设备明确批准时接可信交付；成功再打开宿主主对话。原生密码 / 云令牌 / pin（证书公钥指纹）沿已有安全存储，不复制桌面七步状态到手机。
5. Swift（苹果开发语言）请求 / 响应模型补本节可选字段，按设备原生焦点、读屏、浅深、窄屏与减少动态效果取证；Watch（手表）引导交给已配对 iPhone，不呈现七步。

Apple 原生接线和实机、生产云 / 中继与本人安装迁移未在本包执行。Android（安卓）界面包沿既有桥，不需要新壳权限；本包未安装或启动模拟器。
