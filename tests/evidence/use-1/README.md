# USE-1 用量与费用验收

2026-10-08，Windows（微软桌面系统）真实 Electron（桌面程序框架）与固定 DSH（模型执行框架），隔离账号、临时数据目录与随机端口；云模型 `mimo-v2.6-flash`。实际密钥仅由测试进程读取系统环境变量，没有传入应用或写进仓库；应用仅持有隔离回环代理的合成密钥。

| 验证 | 结果 |
|---|---|
| 原生模型用量与上游 `usage` 逐项比对 | 3 次实际请求，输入 18,047 token（令牌），其中缓存 12,864，输出 70；费用 ¥0.00558028，全部一致 |
| 低月度上限 | 设置为 ¥0.000000001；可见拒绝文案；真实宿主 `/commands` 返回 402 `USAGE_LIMIT_REACHED`，上游请求数不变 |
| 临时提高本月上限 | 设置为 ¥1；有效状态恢复为 `ok` |
| 手机 Web（网页界面） | 实际手机生成资产、390×844 Chromium（浏览器引擎）、原生桥协议转发到同一隔离真实宿主；数字一致，无横向溢出，三个 MiMo 单价与真实设置一致 |
| 原生 / 兼容用量、缓存 / 未知、持久恢复、单价快照、80% / 100%、本地豁免、跨账号和迟到读取 | 新增 7/7 通过 |

没有访问日用数据、连接 LAN（局域网）服务、启动或重启本地模型、安装本人设备应用、改注册表或部署。完整测试交 PR（合并请求）CI（持续集成）。Apple（苹果客户端）界面接线、独立离线手机模型的账本回传、真实 Android（安卓）原生壳及跨设备验收留后续；宿主用量 API（接口）和 Android 精确路由已具备。
