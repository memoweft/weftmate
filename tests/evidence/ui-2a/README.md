浏览器测试还覆盖五种模式的保存、会话间隔离、失败不冒充保存成功、设置默认值与重新读取、风险提示取消与确认、菜单方向键/Esc（退出键）与焦点恢复、允许一次/同类授权/拒绝的请求范围。交互单测 **94/94**，包括同类授权在超时/重启后保留原 requestId（请求标识）和 scope，以及旧模式读取不能覆盖新保存结果；发布回归 **1/1**，类型检查通过。

Android **0.8.3 / versionCode 16**：本机 JDK（Java 开发工具包）17 / Gradle（构建工具）8.9 / SDK（开发工具集）35 下 JVM（Java 虚拟机）单测 **26/26** 与 `:app:assembleDebug` 通过，新增断言覆盖精确模式路由与决定范围。当前手机页面发布必须设置 `minNativeVersionCode=16`，默认发布参数已更新；旧壳缺少同类授权范围传递。没有安装到本人设备、发布 UI 包或执行实际脚本；Android 真机、跨设备审批与真实模型由后续集成验收承担。

CLIENT_API 3.7 的模式仅用于电脑执行会话：共享电脑会话和已交给电脑的原手机对话调用会话接口；尚未绑定电脑的手机直连模型对话显示适用范围并提供默认设置入口，不宣称已给本地循环应用模式。账户默认仅影响新电脑对话，不更改已有会话。
