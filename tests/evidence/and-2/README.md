# AND-2 · 安卓真实登录恢复

这是实际 Android（安卓）原生壳、原生认证桥和随机端口个人宿主的证据。界面没有替换 `app.bootstrap`、认证响应或业务响应，没有写入 `state.loggedIn`。账号、邮件、电脑名和回复均为合成内容；没有真实模型请求，也没有访问本人程序或日用数据。

## 根因与修复

真实原生备用页「电脑账户与连接」表单登录成功后，原壳仍只保存宿主 Cookie（会话凭据），主界面一律进入云账号恢复流程。这个本地会话没有云刷新凭据，也没有等待接纳的 `cloud.adopt` 结果，两个认证生命周期发生错配，最终界面显示「登录已失效」并禁用输入。修前原生用例的失败保留在 `local-baseline-instrumentation.txt`。

现在原生 `HostIdentity.authSource` 保留登录来源：本地会话启动先经原生 `auth.me` 核验，再交给共享层；云会话继续走云令牌交换、原生接纳、共享设备读取及设备批准。没有绕过服务器认证、撤权或账户 / 设备归属边界。`HostAuthenticationSourceUnitTest` 检查显式来源优先及旧存储迁移；界面桥回归检查核验先于接纳，401 被拒绝；原生仪器化测试必须真实登录后点击主对话发送并看到合成回复。

QA-7 的运行器另外存在产品不会执行的步骤：直接调用 `auth.login`，改写 `app.bootstrap.cloudApp=false`，在已初始化的云账号界面里第二次调用 `boot()`，随后手工替换 `state.owner` / `state.loggedIn`。这条路径不能代表普通云登录；本包没有复用它。不过，本包独立的真实本地登录流程确实复现了产品问题，因此没有把 G02 只归为夹具问题。正常云登录加设备批准的首次发送已得到正向证据。

## 复现与运行边界

可重复驱动为 `tests/integration/and-2-android.mjs`，原生用例为 `AndroidLoginInstrumentedTest.realLoginThenSendMainConversation`。命令见 `apps/android/README.md`。每条路径从卸载 / 安装本驱动独立包开始，实际登录、发送；随后后台返回、停止并重开真实合成宿主进程、杀掉并重开客户端进程，再各发送一条消息。

合成云使用仓库的身份服务和邮件文件夹。Windows（视窗系统）测试进程只适配其 Linux（开源系统）目录同步操作：保留文件 `fsync`（落盘同步）和全部密钥 / 身份逻辑，跳过 Windows 不支持的目录 `fsync`；没有改云产品代码。宿主是单独的本包 Node（运行时）进程，合成后端事件写到隔离临时目录，重启从同一目录恢复。

ADB reverse（安卓端口反向映射）经本包透明传输门指向实际宿主。停掉宿主进程后，其真实监听消失；门将实际连接拒绝报告为 `HOST_UNAVAILABLE`，正常时转发原始认证与业务字节。这个门用于避免目标监听消失时 Windows ADB server（调试桥服务）卡住，界面内容和授权仍来自实际宿主。全程使用同一 SDK ADB（开发工具包调试桥）版本及本包独立服务端口。

## 原生整屏与系统栏

`results.json` 是逐场景结果与逐图测量原件。每张图都保存原始整屏，并记录系统主题、页面主题、Android 版本、状态栏 / 底部导航栏 / IME（输入法）高度、图标模式、页面几何和状态栏与顶栏相邻背景的 ΔRGB（颜色差）。图名的浅深指页面主题；系统主题取实际 `cmd uimode night`，没有修改模拟器系统主题。

浅 / 深覆盖登录页、可发送的主对话、抽屉与状态、全屏搜索、打开的「…」菜单、数据与存储、轻提示、真实宿主离线与恢复。轻提示已移到安全区及顶栏下方；手机两尺寸与键盘缩小交互测试检查它同时不遮标题和输入区。`composer-focused-without-ime` 明确只代表已聚焦输入框，不能当作真实键盘证据；键盘缺口单独记录在 `results.json.keyboardGaps`。

MuMu（安卓模拟器）隐藏底部导航栏，原始测量的导航高度为 0。这些图证明状态栏和实际页面布局，**不能当作底部系统导航栏已验收**。本机 SDK 没有 `emulator.exe`，`avdmanager list avd` 返回空列表；因此三键 / 手势导航的主对话、键盘、抽屉浅深补图留给本人真机。

没有改变模拟器导航、系统主题或输入法设置。普通点击在当前输入法下未弹出键盘时，测试 APK 通过应用的 `InputMethodManager.showSoftInput` 请求显示现有输入法；也尝试过 `SHOW_FORCED`（强制显示标志），仍未取得非零 IME 高度。驱动保留请求返回值、焦点状态、原生窗口和只读输入法设置；它不更换输入法、不修改系统设置。只有实际整屏图和非零原生 IME 高度同时具备才算键盘证据，未取得的部分留给本人真机。

需要新壳版本：登录来源持久化与启动桥元数据需要新原生壳及对应界面包。没有改安卓版本号、界面包默认版本、权限或 `/personal/v1` 业务路径。待发布更新记录已添加使用者说明。
