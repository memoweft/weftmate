# AND-4 续接：手机单独可用

本轮合入 MOB-4、MOB-3 与 ST-7b 后，默认原生入口复用现有 `WeftPhone / WeftOffline` 状态引擎、`phone.models.* / phone.complete / phone.offline.*` 原生桥，以及同一份加密保管库。没有另建模型库或本机对话数据库，没有新增业务接口、权限或修改版本号。动态、健康、目标、成果库、登录和设置仍使用嵌入网页；「完整对话功能」与「完整对话列表」保留复杂渲染、消息操作、搜索、项目和归档入口。

`native-verification.json` 是现有 `tests/integration/mob-4-phone.mjs --native-entry --fixture-model --comparisons` 的完整原生走查结果。覆盖注册后无电脑直接进入聊天、实际模型配置页往返、密钥不以明文落盘、流式与最终回复、停止、重生成／复制、首字前失败后重试、杀进程恢复身份／对话／草稿、360／390 × 浅／深五页及设备入口、旧入口往返、电脑接收原消息且原生侧栏仍可读原对话、退出／换账号隔离。复制检查等待原生复制动作回执，不读取系统剪贴板。

真实 MiMo（云端模型）本轮请求 **2 次**：模型连接测试一次、真实流式一次，模型 `mimo-v2.6-flash`，见 `mimo-verification.json` 和 `native-390-light-mimo-stream.png`。密钥仅从机器环境变量进入进程及隔离包加密设置，没有打印或写入证据。随后可停止的合成流式用于重复交互测试，没有追加真实请求。原 AND-4 首轮另有 2 次，整个工作包合计 4 次。

浅色 `comparison-light-{empty,content,menu}.png` 左侧为同账号、同会话、同模型的实际旧入口，右侧为原生。只调整测试包自身密度配置，并让旧入口的网页按同一密度缩放；没有浏览器设备视口替代整屏，也没有修改模拟器设置。消息正文、输入与代码字号直接读取原有网页外观偏好，默认正文／输入 15、代码 13；系统字体缩放继续生效。原生的消息操作采用项目图标，完整操作仍可进入原网页。

深色 `comparison-dark-spec-{empty,content,menu}.png` 左侧明确标为规范色值参考，右侧为真实原生截图。它不是应用截图，也不拿旧网页绿色深色作基准。页面、卡片、半透明输入底、浮层、选中底、分隔线、三档字色、强调色和危险色来自安卓令牌；8 位透明度取最接近规范值。Android（安卓）12 以上只模糊固定面板背景，文字与控件保持清晰；滚动时使用同色实底，停下后恢复磨砂。旧系统使用叠在页面底上的实色 `#343437 / #28282a`。长对话的新帧数据与限制见 `connected/native-report.json`、`validation.json`。

`connected/native-report.json` 是原有 AND-4 运行器的 `--regression --no-metrics` 路径：电脑连接模式的流式及三项审批／回执，浅深各一轮；另拍旧兼容原生连接页。长对话的最终有效测量在 `connected/performance-profile-report.json`，同一隔离包、同一账号与 82 条历史；网页虚拟列表只保留 6 个可见消息节点，因此检查其实际历史状态，不能用节点数当作消息总数。早期调试诊断中的旧入口节点断言失败保留原始记录，最终测量已修正并通过。

最终普通调试 APK（安卓安装包）18,119,710 字节，旧调试包 7,601,731，增加 10,517,979（约 10.52 MB／兆字节）；AND-4 首轮原生包 15,147,471，本轮增加约 2.97 MB，包含合主线的依赖与资源变化。非调试隔离测量包 14,655,851 字节，不能当作已经签名发布的包。该包原生／旧入口活动首绘为 417／387 ms（毫秒），到可输入观测上界为 1,242／1,576 ms；探针有不同自动化开销，不能把上界差值当稳定提速结论。

非调试包浅色 503 帧／1 卡顿帧，深色 491／1，均 0.20%；P95（95 分位）6／5 ms，P99（99 分位）7／6 ms。显式预编译后深色 485／3（0.62%），P95 5、P99 7 ms；相同预编译包的旧入口 344／1（0.29%），P95 6、P99 8 ms。普通调试诊断的高掉帧也保留在 `metrics.json`，不拿它冒充发布性能。`-PweftmateQaProfile=true` 仅允许独立 `and4qa` 包，关闭运行时调试，保留该包的合成网络夹具；未改模拟器设置，测完卸载。官方要求性能基准接近发布配置并控制编译状态，且模拟器共享主机资源会影响结果；本轮系统统计不能替代真机 Macrobenchmark（宏观性能基准）。[构建与编译状态](https://developer.android.com/topic/performance/benchmarking/macrobenchmark-overview)、[真机测量说明](https://developer.android.com/topic/performance/baselineprofiles/measure-baselineprofile)。`gfxinfo` 也可能只覆盖部分绘制，网页内核的合成开销不能直接外推。[统计覆盖说明](https://developer.android.com/topic/performance/vitals/render)

`composer-tool-row.png` 是实际浅色工具行的像素裁剪放大。审批模式采用 `wm_filter`（调节线），同一套候选还包括 `wm_shield`（盾牌勾，像已批准）和 `wm_settings`（齿轮，容易混为全局设置）。工具图标均 22、触控区 44、线宽 1.75，辅助按钮无底，最右主按钮唯一实心；模型只显示图标，完整名字和当前勾选在菜单中，读屏带当前模型名。网页观察清单：目标页两种新建按钮的圆角／填充不一致；成果行小「…」与大描边查看按钮密度不同；本人旧参考输入区文字模型胶囊与圆形辅助图标视觉重量不一致。这里只记录，未修改网页样式。

所有原图为 MuMu（安卓模拟器）带状态栏整屏，物理 720 × 1280，360／390 为应用配置的逻辑宽度；系统主题没有改动。该实例底部导航区域高度为 0，因此没有手势条，不能据此声称底部系统栏或真实输入法候选条已验收。每张原图的状态栏颜色／图标、窗口与键盘信息在走查 JSON 中。MuMu 锁与重活锁成对取得，结束时卸载本包及测试包、撤销自己的随机端口映射并断开。

电脑交接沿 MOB-4 原协议，将原消息上传供记忆摄取；手机原对话在侧栏保留只读查看。当前协议没有把它映射到电脑普通会话的接续回执，不能称为自动会话接力。手机独立模式的附件与工具能力仍以 MOB-4 现有能力为准；连接电脑的附件、审批和复杂功能保留。系统听写／相机／文件选择真实面板及厂商真机手势仍待真机验证。

验证数字以 `required.json`、`android-jvm.json`、`validation.json` 为准。完整必过组首轮遇到退场夹具的迟到认证失败被当作会话数组；只修测试代理，使认证失败响应原样传递，未改变桌面产品或放宽断言，单项与完整组复验通过。
