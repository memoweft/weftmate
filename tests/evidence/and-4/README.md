# AND-4 · 原生安卓聊天

本页保留 AND-4 首轮交付数据。MOB-4 接入、暖灰浅色／中性灰磨砂深色、同账号网页对比与最新验证以 [standalone/README.md](standalone/README.md) 为准；下文「MOB-4 尚未合」和首轮性能数字属于历史记录。

主框架、五项图标导航、对话列表、输入区、审批／选择卡片和图片查看使用 Jetpack Compose（安卓原生声明式界面）。动态、健康、目标、成果库、登录和设置仍使用嵌入的原网页；框架隐藏网页顶栏与底部导航。原网络、账号、附件、发送账本、通知和本机模型能力继续复用，没有新增 `/personal/v1` 路由或权限，没有修改安卓版本号。

所有走查使用独立 `and4qa` 包、随机端口、真实个人账号登录接口创建的合成账户、合成电脑与回复。初期测量用 `and4baselineqa` 从包开始时的源代码构建旧入口作对照；两包都卸载。没有访问日用数据、18186、线上 WeftMate 云服务或真实用户文件。MiMo（云端模型）通过合成电脑夹具发出真实请求，再经原聊天事件接口展示；密钥只从机器环境变量读进进程。

验证记录：

- `required.json`：完整必过组 1,903 通过、0 失败、14 既有跳过，合主线前执行一次。
- `vendor.json`：完整固定 DSH（助手运行时）集成组 239／0／0；首轮 229／1／0 的桌面配置同步 N4 超时在 `vendor-first.json` 保留，原断言的单独复验 1／0 后整组再次通过。没有修改桌面产品或该断言。
- 安卓 JVM（Java 虚拟机）测试、离线调试包／测试包构建、路由自动比对、类型与公开卫生检查通过；最终数量写入 `validation.json`。
- `instrumentation-*.txt`：生产 Compose 界面与原网络层走查；初始空输入、聚焦／草稿、模型／模式／附件菜单、流式、图片与文字文件、图片全屏、两按钮审批、三项审批、选择题、五页导航、设置、侧栏、回退再恢复。
- `performance-report.json`：杀进程后重新打开，原生就绪探针确认可输入并恢复草稿；旧入口通过原网页调试接口确认。另有 82 条合成长对话、12 次同向滑动和系统 `dumpsys gfxinfo`（帧统计）原始结果。
- `screenshots.json`：每张原始整屏图的页面主题、系统主题、Android（安卓）15、实际尺寸与系统栏色差。MuMu（安卓模拟器）底部导航区域高度为 0，截图没有手势条，不能据此声称底部系统栏已验收。实际物理尺寸 720 × 1280；360／390 是本包应用配置的逻辑宽度，未改模拟器尺寸／密度／设置。
- `pairs/`：安卓与仓库 iPhone 同类画面并排；`composer-tool-row.png` 是本包工具行的准确像素裁剪放大。私有参考只读取，没有复制。

实测旧调试包 7,601,731 字节，新包 15,147,471 字节，增加 7,545,740 字节（约 7.55 MB）。原生／旧入口冷启动到就绪观测上界 1,679／1,389 ms（毫秒）；系统活动启动 `TotalTime` 为 807／489 ms。原生的就绪探针与旧页的调试连接不同，包含 ADB（安卓调试桥）／调试连接开销，单轮数据不能当作稳定性能优劣结论。长对话原生 639 帧、4 卡顿帧（0.63%）、P95（95 分位）5 ms／P99（99 分位）10 ms；旧页 243 帧、1 卡顿帧（0.41%）、P95 6 ms／P99 7 ms。MuMu 帧统计没有单列网页内核全部合成开销，也不能外推真机表现。

本包先修了真实遇到的问题：列表观察布局信息引起反复重绘；附件与诊断提供器重名导致清单合并；对话框上下文需要回到原活动取得图片；深色正文需要继承主题文字颜色；网页 CSP（内容安全策略）允许样式属性、禁止动态内联样式元素。初次 `uiautomator dump`（界面层级导出）超时，共享 ADB 服务随后无响应；改用本包随机端口的独立 ADB 服务取得性能数据，没有重启共享服务或改模拟器设置。

真实 MiMo 请求整个包共 2 次，最后一次的消息截图为 `and4-390-dark-mimo.png`，计数与来源见 `mimo.json`；最后全屏系统栏复验没有再次请求模型。手机五文件交互组 114／0／0；安卓 JVM 92／0／0；101 张最终整屏图的系统栏色差／页面主题检查均为 0 失败。暗色与图标工具行已逐张检查；六张并排图只比较同类输入／导航或审批结构，iPhone 场景正文与安卓合成内容不同。

遗留边界：复杂 Markdown（标记文本）表格、公式、图表、代码高亮仍简单呈现；复杂消息操作、文件的既有查看／保存流程通过完整网页对话入口保留。系统听写／文件选择／相机真实面板、真机输入法候选条与手势条仍需真机确认，合成附件使用系统内容 URI（资源标识）替身。MOB-4 的全新「没有电脑」身份尚未合入本包，已接同一原生 `chat.send / conversations.* / chat.progress` 接口，不另建本机模型库或对话存储；合入后须补手机独立身份的启动与重开回归。
