# ST-1 个性化与助手

全部为合成账户、系统临时目录、随机回环端口。没有连接本人日用宿主、读取本人凭据保管库或向 8081 发请求；参考产品图片只查看，没有复制进仓库。

新增账户同步的「个性化」「助手」两页，桌面／远程网页／安卓界面包共用功能层和设置表单。固定说明 4,000 字、码点计数；写作风格在宿主本机统计本人消息的表达特征，结果可编辑／清除，临时内容不参与。D36 排队／引导移至助手，旧设备偏好首次迁入账户。只编辑本包设置，未修改记忆健康区。

DSH（助手运行时）原生系统提示在每个新回合读取账户设置并保持回合快照，联网工具沿原生目录和执行入口启停。固定说明从未加入聊天消息、MemoWeft（记忆服务）摄取或 Evidence（记忆证据）。离线加密副本带同一份账户设置，直连提示复用同一个组装函数；没有新增文件／记忆导出。思考展示使用模型已经返回的内容，不生成替代思考，原生来源和记忆输入仍不包含它。

## Apple（苹果端）改动清单

1. macOS（苹果桌面系统）／iOS（苹果手机系统）按 UI_SPEC 新顺序增加「个性化」「助手」，沿原设置导航和逐行控件；将 D36 从常规移到助手。Watch（手表）继续随 iPhone 同一账户，不新增独立设置页。
2. GET/PATCH `/settings/personalization` 接同一账户设置；只 PATCH 编辑字段，成功后显示「已同步」。读取／保存失败保留重试，身份改变时忽略迟到回执；旧本设备引导偏好仅在 `updatedAt:null` 时迁入。
3. 输入长度按 Unicode（统一字符编码）码点：称呼 80、简介 500、自定义语气 500、固定说明 4,000、写作风格 1,000；多行内容和计数、保存按钮、键盘／VoiceOver（系统读屏）描述。固定说明不走记忆写入。
4. 风格开关／重新提炼调用 POST `/settings/personalization/style`；无消息时显示空结果，可编辑／清除，说明提炼在宿主本机完成。不可在客户端读取别的账户消息或向云模型提交原文做提炼。
5. 新对话沿既有模型目录 `deepThinking.supported` 与 UX-3 会话思考接口；已有对话继续会话偏好，不支持时解释普通方式回答。网页搜索由宿主执行，客户端不自行拼原生工具列表。
6. `assistant.message.data.modelThinking` 只用于折叠／展开／不显示，模型缺字段时没有空块；不加入回复复制、重试消息、导出到记忆或上下文交接。用户手动展开状态不要被普通轮询重置。
7. A14 离线解密副本追加读取 `personalization`，直连模型的系统消息拼接同等称呼／语气／详细程度／固定说明／启用的写作风格；设置不是记忆。仅保留既有记忆来源和删除代次；离线模型无原生会话推理能力时不承诺默认深入思考。
8. 原生浅／深、窄窗、动态字体、键盘和 VoiceOver 按同等场景验收。Apple 源码本包未改；本包也没有正式安装／发布界面包。
