# M1-2 桌面审批验收

使用真实 Electron（桌面程序框架）`_electron.launch`、`src/main.mjs` 与固定 DSH（执行框架），账户和数据目录独立于日用 Runtime。合成提供方仅用于稳定触发确定的工具调用，不替代真实 Qwen 场景结果。

| 验证 | 结果 |
|---|---|
| 五种模式与六类风险 | 定向单测通过；自动普通操作不询问，每次询问要求决定，文件修改自动接受，先出计划经原生确认，全部允许有风险提示 |
| 删除批准 / 拒绝 | 批准前文件仍在，批准后删除；拒绝后文件保留，决定回到模型 |
| 总是允许此类 | 本对话第二次同类删除不再询问；保存重载和其它对话不继承由宿主单测覆盖 |
| 超时 | 待答复十分钟后 unavailable（不可用），迟到答复409；原生模型得到失败，工具副作用为零 |
| 默认模式 | 设置保存后重载，新对话采用新默认，旧对话保留原模式 |
| 快捷键 | 菜单数字1–5、当前项勾选；方向键、Home/End、Esc及焦点恢复 |
| Qwen action-01 | 原目标、原180秒限制、原八项检查全部通过，130.84秒；移动没有审批打断 |
| Qwen action-06 | 前两次180.45/180.46秒超时；第三次在180.37秒总限失败，但第一轮允许审批、文件删除、completed（完成）三项通过，第二轮未得到决定。独立拒绝补验180.37秒超时，只读文件而未到达拒绝卡。正式场景与补验都不算通过；各次安全摘要见 qwen-*.json |
