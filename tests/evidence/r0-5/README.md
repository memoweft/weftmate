1. Mac 头像菜单、关于、搜索操作接更新内容、帮助与 ⌘/ 快捷键；快捷键注册表与实际菜单／绑定同源，采用原生键帽和统一弹层。
2. Mac／iPhone 随应用打包同一结构的更新记录，按实际安装版本选择当前项，旧项折叠；账户与版本记住一次轻提示，首次安装建立基线，界面更新完成后才提示。
3. 帮助九个主题、就地过滤、清除搜索和试一试接原有主对话／临时／记忆／目标／审批／设备／备份；帮助不重复首次配置引导。iPhone 不加快捷键入口，Watch（手表）不加独立帮助阅读页。
4. 原生页面顶栏名称、返回、浅深／动态字号／读屏与减少动态效果；系统栏整屏、刘海、圆角和键盘，逐图记系统主题、版本、底部手势区及状态栏色差。Windows 本包没有修改、编译或验收 Apple 原生。
5. 沿既有安装版本／更新状态；无新增业务路由、网络白名单、账户权限。
