# QA-1 · 本人试用前五端验收

**结论：不建议本人开始试用。** 本包只记录证据，没有修改产品代码。新云账号能够注册、绑定与批准设备，但其电脑会话缺少文件 / 命令工具，手机执行状态又无法收尾；这是目前最明确的阻断。五端都启动过真实程序，但存在下述未通过与未完成项，不能把本包称为“五端全部通过”。

执行：Codex · Windows-5，2026-10-09。开始代码 `a313ea8`；后续同步 A9 的 `77b0205`，最后同步含 MF-1 的 `c3d07f8`。王小明使用 Core（记忆核心）`5d91823`；MF-1 补测使用主干固定的 `cb10a16` 源码临时导出，共用既有 Python 环境。Mac 不切分支、不改源码；指定目录的 Apple 源码与已合 A9 的主干相同，宿主夹具仍来自该目录，未冒充最新 Windows 宿主。Mac 选择**本机随机端口的隔离宿主**。

所有账号、正文和任务文件均为合成数据。没有访问 18186、8081 或本人日用数据，没有改生产服务。LAN（局域网模型服务）仅使用 `local-quality`，王小明换模型和三项办事均持有 `lan.lock`，批次结束释放。Android（安卓）使用独立测试包 `com.memoweft.weftmate.mobile.ui5qa` / `com.memoweft.weftmate.mobile.lg1bqa`，均已卸载。

## 稳定性与用量

观察 1,809.401 秒，事件循环 p99 = **31.212 ms**，最大 **215.089 ms**。主进程 RSS（驻留内存）从 199,217,152 到 264,822,784 字节，增长 **62.566 MiB**；保留了 54 个新对话，不能据此认定内存泄漏。成功轮首条本地显示中位数 **2.05 ms**。后半段的停止状态等待失败独立记录，没有被较低的主进程 p99 掩盖。

全程观察到 880 次 `store.json` 文件系统通知；通知不是写盘次数。另在最后 **520.167 秒**监测成功的原子重命名，实际 **147 次，16.956 次/分钟**；这是后段样本，不能称为全程精确写盘数。[原始计数](desktop/exact-writes.json)。合成端点报告单槽，但没有 `/switch/status`，后台标题路线出现就绪等待 / `MODEL_QUEUE_UNAVAILABLE`；并行 QA 工作也在运行。这些限制影响停止延迟的归因，后续修复包需用完整本地服务信息重现，不从这次样本直接推断真实模型故障。

MS-1 的 `logs/`：1 文件、66,439 字节、391 条元数据事件，测试正文标记和测试密钥均未命中，见 [日志扫描](desktop/log-scan.json) 与 [原始元数据](desktop/host-metadata.jsonl)。

MiMo 全包 **182 次请求**，**178 笔完整用量、4 笔缺用量**；已知输入 **3,498,767**，其中缓存 **386,368**，输出 **48,610 token（词元）**。按 2026-10-09 实际核对的[官方价目](https://mimo.mi.com/models/zh-CN/mimo-v2.6-flash)（未缓存输入 ¥1、缓存输入 ¥0.02、输出 ¥2 / 百万 token），已知费用下界 **¥3.21734636**。含所有失败、额外 action-07、手机两次失败、记忆补测及语义裁判；4 笔缺用量不当作免费，不等于账单。分组原件见 [usage.json](usage.json)。

## 问题与复现

完整按严重程度清单见 [issues.md](issues.md)，同内容交付指定的 `Runtime/Orchestrator/qa-1.result.md`。运行器快照在 `runners/`，从仓库根启动。它们仅用于隔离验收，依赖本机既有 Electron / DSH（助手运行时）/ Core / 安卓工具链，真实模型密钥从系统环境读取，不含真实凭据。`m1.mjs` 重跑必须显式 `--only` 指定六题，避免再次选择额外长任务；LAN 调用前必须原子取得编排目录的锁。

初期脚本适配失败单独保留：旧主题下拉改为现有主题截图方式、旧进展文字增加计时后更新定位器、旧本地账号探针不等于云账号登录。Mac 截图未达到所请求场景、iPhone 关于遍历失败、手机办事失败均没有通过改检查涂绿。`android-visual-verification.json` 的顶层 `passed` 仅表示原登录流程；办事结论必须读取其中 `phoneTask.passed=false`。

最终清理与公开凭据扫描见 [cleanup.json](cleanup.json)、[privacy-scan.json](privacy-scan.json)。
