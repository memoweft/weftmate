# AND-6 · 安卓原生目标与一排筛选

目标页的进行中、定时任务和长期目标列表、状态、来源对话、定时开关与行菜单、定时新建／编辑、长期目标新建／完成／归档、定时详情和执行记录使用 Jetpack Compose（安卓声明式界面）。五种定时规则都可原生保存：一次性、每天、每周、每月和固定间隔。长期目标的检查点作为目标说明保存；接口没有独立目标修订或结构化检查点写入能力，编辑入口回所属对话交代。

「完整目标功能」保留现有网页的等电脑上线事项、取消等待事项及完整对话操作。来自另一台电脑的来源对话进入原网页对应电脑与对应对话；主连接电脑的来源对话直接进入原生聊天。临时对话中的安排沿原来源对话编辑，避免把脱敏占位文字写回真实内容。网页版没有改动。

多电脑列表沿 M3-2 的已有 `uiCore.computerApi`（电脑认证通道）逐台读取，原主连接仍走 `HybridActivity` 的原生业务调度。电脑目录、名称和默认执行位置沿既有聊天引擎；仅有多台电脑才标小电脑名并在新建表单显示执行位置。离线保留当前登录期间最近列表，提示具体哪台不在线，不把来源改投另一台。换账号、退出和删除水位失效清掉旧展示；没有新建业务数据库。跨进程的目标列表缓存、真实两台电脑云登录与远程聊天原生迁移没有在本包完成。

颜色只取 `DesignTokens.kt`（生成的设计令牌），图标只取项目安卓产物。浅色对照现有安卓壳内网页；深色按本人指定的中性灰磨砂规范。菜单、按钮与选择框复用 AND-5 控件，时间／日期用应用菜单，不调用系统默认下拉或日期选择器。列表右侧只有一个启用开关和一个菜单；删除标红、二次确认，保存成功轻提示，提交时禁用并显示进度。手机独立身份进入目标页是可访问空状态，不读取电脑接口。

## 动态页、成果库页的筛选改回一排

三个页面共用 `apps/android/app/src/main/java/com/memoweft/weftmate/mobile/NativeFilterRow.kt`。组件始终一排直接点选，溢出横向滚动，当前项有圆角底和读屏选中态；没有下拉呈现开关或用户配置。动态是全部／待处理／任务／提醒／记忆，成果库是全部／文档／表格／图片／代码／其它，目标按三个现有区块提供全部／进行中／定时／长期。成果库的全部项目、全部时间仍用既有下拉。

AND-5 和 AND-7 的原测试保留原断言保护点，改为检查所有直接选项、当前选中态及点选后的过滤；本包另用同一合成账号对两页进行浅深点选和原网页并排取证。

## 验证与证据

- `jvm-results.json`：仅本包相关 JVM（Java 虚拟机）测试：目标状态／时间／表单与重试、动态状态、成果库状态、业务路由。
- `native-report.json`：360／390 × 浅／深，生产原生界面和已认证业务通道的完整目标主路。
- `filters-report.json`：动态与成果库的直接筛选点选及实际旧壳对照。
- `pairs.html` 与 `pairs/`：同一合成账号、同样数据、同一主题，左原网页右原生。目标有内容／空／行菜单／新建表单各浅深一组，另含动态和成果库筛选各浅深一组；每组下方三行说明。
- `system-bars.json`：每张原始整屏图的状态栏与页顶背景取样值。物理图 720×1280，逻辑宽度通过独立测试包配置设置，不改模拟器设置。
- `diagnostic-*.txt / .json`：保留早期错误重试缺口、时间控件文字匹配歧义、一次测试启动等待空闲超时，不把失败记录计入通过。

只使用 `com.memoweft.weftmate.mobile.and6qa` 独立安装、合成账号、合成电脑、随机端口和临时目录。不请求日用端口、日用数据或线上 WeftMate 云服务，不接管桌面。每轮拿 `mumu.lock`（模拟器占用锁）与一个重活名额，完成或失败都卸载本包及测试包、撤销本次反向端口映射、断开并关闭本包私有 ADB（安卓调试桥）服务。没有操作其他包的应用、锁和服务。

多电脑走查中的第二台电脑使用合成目录和同一已认证内容调度器验证接线、电脑标注、选择和离线保留，不等同于真实云端两台电脑认证链路。执行记录取现有 `/notifications` 返回的真实 `scheduleId` 与来源会话，已交给助手执行和实际完成分别显示，不编造历史或完成结果。

## 本人真机确认
