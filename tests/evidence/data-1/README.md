# DATA-1 · 每日摘要与这周回顾

本包使用合成账号、隔离宿主、随机端口与十个自然日的合成对话／任务／已核验成果／提醒／用量。Windows（操作系统）窗口由真实 Electron（桌面程序框架）加载产品界面，本机以机主身份直接进入；手机网页使用已验证的合成云账号。真实模型请求 **0**，MiMo 请求 **0**；每周故障场景实际进行 **1** 次合成后台模型调用，随后显示统计版。

每日摘要默认开启，账户时区凌晨 03:00 后整理前一天，错过则启动补齐；只持久化统计、短标题和来源引用，不保存对话正文。最近七天背景最多3600字符，与现有会话上下文并列。每周回顾独立一条，主要主题指向最近的相关对话，近期成果可点回来源，其他来源使用共用菜单。设置位于「通知 → 回顾与洞察」，保留90个完整自然日，可改为常用期限、关闭或清空；没有首次提示。

## 手机系统栏

本机 MuMu（安卓模拟器）启用硬件键模式，底部导航区域不可见，未把该环境截图当作通过证据。整屏取证复用仓库已有库存 Android（安卓系统）验收容器与构建方式，在隔离的测试浏览器中加载同一份手机网页；不修改安卓产品源码／版本号，不宣称产品原生桥接已发布。整屏原图不裁切、不修图。合入MOB-2／UX-3后重新取证，20张状态栏色差均0，底部色差0–2；清空确认复用新版底部面板。每次取证明确断言菜单／确认框打开，并按网页文字的位置与颜色核验整屏对应区域，拒绝黑帧或旧帧；不把网页状态断言冒充整屏正确。每张图的系统与页面主题、系统版本、实际状态栏／导航栏高度和颜色差见 `system-bars.json`；任务来源与原始校验见最终验证记录。

## 固定保护点与边界

固定回归覆盖每个分区的统计口径、日界与夏令时、补齐与不重复、完整自然日保留期与运行时离线清理、清空与账号隔离、3600字符上限、模型输入没有对话正文、健康格式校验、真实会话钩子的替换／清空／可选通道故障恢复，以及遗忘记忆保留使用统计和原始健康汇总。本机完整必过307文件：1709通过、0失败、14既有跳过；固定运行时32文件：230通过、0失败；手机五文件113通过、0失败；定向四文件32通过、0失败。共享手机界面生成、类型检查与公开卫生扫描均通过。Windows 完整必过命令的文件参数使用本工作树的短联接规避系统命令行长度限制，工作目录、文件清单和所有断言不变；没有修改 CI（持续集成）运行脚本。

只复用现有记录。使用时长按用户消息后的五分钟活动区间取并集，**是估计，不是屏幕时间**；小时分布记录实际发消息的时段，不把无人值守任务运行说成本人熬夜。当天未完整结束的使用不进入日报，主对话既有任务结果同步仍保留。健康不造数据：本包只有格式与接收入口，Apple（苹果端）后续负责 HealthKit（苹果健康数据接口）授权、按账户时区汇总并写入；设备分区仅预留格式。

源码范围之外的必要接线为现有会话上下文 IPC（进程间通信）字段透传／钩子、通知设置、动态与内容呈现器、生成的手机副本和设置搜索；这些公共文件的具体列表见 PR（合并请求）。没有修改 MOB-2 的手机页面／导航／样式主文件、SEC-1 的审批判定、安卓／苹果原生源码、版本号、依赖或 `vendor/`。
