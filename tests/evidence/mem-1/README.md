# MEM-1 验收证据

本包导入 ChatGPT / Claude 官方导出 ZIP（压缩包）或 conversations.json，以及可辨识最终答复标记的本机 Codex / Claude Code 会话。先在本机预览计数、时间跨度、选中的字数、后台模型用量与费用区间；只有使用者点开始才分批读给模型。原文件只读，宿主进度只存来源引用、编号、日期、指纹与回执，不另存一份对话全文。

固定测试在 tests/history-import.test.ts 与 tests/model-scheduler.test.ts，涵盖四个解析器、未知版本、分支、空／超长／附件名、预览零请求、选择、暂停／继续／取消、持久回执恢复、重叠去重、撤回后重导、退避停下、聊天优先、记录不含正文与账号隔离；派生答复遗忘在 tests/ia-2b-erasure.test.ts。所有源文件均由 tests/fixtures/mem-1/generate.mjs 虚构生成；没有读取真实用户导出或真实 CLI（命令行工具）会话。格式依据与国内应用调研见 [样例说明](../../fixtures/mem-1/README.md)。

真实验收脚本 tests/integration/mem-1-import-history.mjs 驱动独立 Electron（桌面程序框架）、固定 DSH（助手运行时）与真实 MemoWeft 核心。仅使用随机端口、临时目录、合成账户；MiMo mimo-v2.6-flash 密钥由机器环境变量读入父进程内存，临时传输代理只转发真实请求。账户内只保存无效的合成凭据，不记录真实密钥。测试替身仅选择合成文件和转发真实模型输运，没有替换记忆形成／召回／遗忘结果或放松权限。

验收中保留了驱动失败的 attempt-*.json，不能把它们当成通过记录。初轮主对话模型配置使用临时代理地址，后续恢复时需同步账户、应用和 DSH 的三份公开地址投影；修复仅作用于该合成环境。已形成的记忆继续复用，不重导来绕过断点续作。最后一轮结论见 [acceptance.json](acceptance.json)，结果为 passed；30段／36条、主对话双事实读取、整批遗忘后双事实不可读取、撤回后30段重新可选、最近一年／日期筛选和预览零请求、未知格式人话提示及真实运行日志无正文／凭据均通过。模型汇总见 [model-requests.json](model-requests.json)：所有尝试共150次真实 MiMo 请求，成功导入的账本31次／输入271,170／输出10,194／估算¥0.1589052；最后一轮新增6次，没有再次导入已完成的30段。所有先前失败尝试一并计入，不把账本估算当成模型提供方的最终账单。

桌面截图为原生 Electron 内容区，浅／深 × 1200／480 CSS（样式表）像素；图片实际尺寸受本机缩放影响。phone-web-* 为独立远程浏览器中 360×780／390×844 的内容区，包含记录和进度，且没有选电脑文件的入口。它们不构成手机系统栏、浏览器工具栏或原生 Android（安卓）／Apple（苹果端）的整屏验收。原生选文件对话框按第11条用替身返回合成路径，真实系统对话框冒烟待本人试用时确认。

核心现状：聊天入口仍记录 source_kind=spoken；宿主通过日期前缀、原 timestamp（时间戳）和回执映射展示导入来源。核心既有的可靠摄取与可追溯来源仍由核心保管，本包没有新建源文件／全文缓存，也没有改核心仓库。正式导入来源类型、历史时间语义与批量遗忘／账单不确定状态需核心后续合作。

实际复合问题检查还发现核心的单主题快捷返回只召回零食偏好，漏掉已成型且允许云读取的命名内容。宿主现在从使用者原问题抽取最多5个真实子问，连同整题、表达偏好和本人身份，仍通过核心最多8项的权限过滤批量召回并去重；不直接读取未经模型目的地过滤的世界事实，不添加模型调用，不改核心仓库。原双事实断言保留，固定测试同时检查批量权限参数与无原始世界读取。
