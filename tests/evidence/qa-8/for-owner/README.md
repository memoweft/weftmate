# 给本人看的 12 张图

这 12 张是原始界面截图，来自真实桌面程序与触屏网页视口，全部用合成身份和合成健康数据。没有用图片修改掩盖问题。

先看浅、深两张电脑今日健康和手机健康；再看压力详情、深夜叠加、聊天问健康、审批条、回顾与健康设置、更新内容和正常退出记录。压力聊天那张保留了平均值与最近测量混用的问题；详细对照在上一层 `walkthrough.md`。

手机图没有系统状态栏、浏览器工具栏或底部系统手势栏，因此不能当作真机系统栏验收。页面浅深色、两列布局与 360／390 的宽度检查已经完成。

周回顾图可能是模型不可用时的统计版；真实模型整理前后的文字与当地时刻依据另见上一层观察文件及补充复验。开发程序的版本头为 Electron（桌面程序框架）开发壳版本，展开的产品更新说明在 `0.1.0` 下，安装版显示仍需本人看。
