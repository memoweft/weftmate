# POLISH-1 界面细节验收

真实 Electron（桌面程序框架）使用生产窗口，1200／480 宽；手机网页使用已发布的手机界面资产，360×780／390×844。全部为合成账户、合成记录、随机端口和临时目录，真实模型请求为 0。参照 Claude 与 Muse 的私人截图只在本机查看，没有复制、转录或提交。

`before/` 为开工提交 `54e7739505ee09248a71291a5025edbdae6d7210` 的界面资源，`after/` 为当前界面。截图是实际渲染结果；桌面由 Playwright（界面自动化工具）驱动 Electron，手机网页由 Chromium（浏览器引擎）驱动。网页视口图不冒充系统栏验收，带系统栏的证据另以 `phone-system-*` 命名。

| 条目 | 改成了什么 | 改前 / 改后截图后缀 |
|---|---|---|
| l | 窄屏模式只保留图标，背景信息进入对话菜单，模型优先完整显示；更长名称保留首尾，中间省略 | `l-composer`；改后 `l-context-menu-open`、`l-context-details-open` |
| m | 搜索与新建固定在账户上方，列表独立滚动 | `m-sidebar` |
| n | 本机账户显示「只在这台电脑上用」；账户详情、侧栏菜单、旧资料说明和删除确认也不显示内部账户名 | `n-account` |
| r | 七天合并为「这周每天」，连续区间显示「周一到周四」，零散多天按天数说；模型提示沿同一规则 | `r-weekly` |
| s | 一行轻提示，约 4.5 秒后消失；轻点打开完整详情与反馈。画廊夹具补齐已读元数据与回复版本路径 | `s-notice`；改后 `s-details-open`；画廊见 `gallery/` |
| a | 动态效果开关与标题同一行，恢复按钮在下方 | `ab-appearance` |
| b | 浅深两套强调色各四个色块，选中项有描边与勾 | `b-colors` |
| u | 「回顾与健康」独立入口，通知只留通知；搜索与健康页旧跳转指向新入口，仍读写原设置 | `u-notifications`；改后 `u-review-health`、`u-clear-review-open` |
| o | 按原生回执消除发送占位与正式记录的时序重复，夹具的工具说明也改为具体动作 | `race/*-o-history-before-ack`、`sec-native/` |
| w | 对应回执开始、出字或完成后，历史排队卡消失，其他排队任务保留 | `ow-queue-completed` |

每个后缀由 `electron-1200`／`electron-480` 或 `phone-web-360`／`phone-web-390` 加上 `light`／`dark` 构成。a／b／u／r 涉及两端；l／m／n／s 的手机细节用手机证据；o／w 用真实桌面证据。周回顾与排队完成场景使用合成事实，生产模板和状态投影直接渲染，没有真实模型调用。

运行器：`tests/integration/polish-1.mjs`（分别带 `--before` 与不带该参数）；`tests/integration/polish-1-phone.mjs`（隔离 Android 测试浏览器整屏）；固定断言：`tests/polish-1.test.ts` 与界面运行器中的布局、持久化、轻提示和入口断言。

可选助手主页本包未做，保留在遗留；没有新增接口、修改健康页面、修改 Android／Apple 原生代码或版本号。

系统栏原图见 `system/`：Android（安卓）14，360／390 浅深色共 76 张，均显示实际状态栏和底部三键导航。它们来自普通 Android 网页测试容器，不宣称生产安卓桥验收。每张的主题、系统版本、状态栏／导航栏高度、实际文字像素、文件哈希和色差保存在 `system/verification.json`；顶部最大通道色差 0，底部最大通道色差 14。390 来自云端运行 38277447409，360 来自修正页面边缘采色的运行 38280827526。原图没有修改；本机联系图仅用于人工检查，没有当作原图交付。

原生队列复验使用固定 DSH（助手运行时）和合成模型，共四条审批路径；实际 `/personal/v1` 记录和 DOM（文档对象模型）节点明细在 `sec-native/after/warning-diagnostic.json`。发送时序回归单独把回执交付延后，使用同一批真实合成宿主事实比较改前／改后，不按消息文字去重。

8 / 8a 的逐项验收与最终测试数字以调度结果文件为准。手动设计扫描仅发现既有引用块的细边线，未扩展修改引用块或健康样式。
