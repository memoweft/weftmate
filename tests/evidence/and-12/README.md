# AND-12 · 安卓输入区、默认入口与侧栏

原生输入区使用同一个 `BasicTextField` 节点和 InputConnection（输入连接）。模型、审批及附件菜单保留原窗口焦点，菜单选择／关闭、语音提示、发送／停止不主动收键盘；合成候选文字在模型菜单往返后仍能继续组成同一段文字。点输入区工具间空隙保持键盘，点可见消息空白或拖动列表才收起；切页和打开文件全屏继续清除焦点。真实输入法切换语言／语音面板时不会因边距归零被应用主动清除焦点。

Android（安卓）11 以上由 Compose（声明式界面）的动画边距驱动 `imePadding`，底部导航同步收缩／回落；读取和变化发生在测量阶段，消息数据不会因每帧边距更新重新组装。列表贴底与阅读上方分别保持，输入框高度从底部展开／收回，工具行不会被顶部对齐的裁剪临时截掉。Android 8–10 使用同一份最终边距同时更新输入区和导航，避免两次回落；本轮设备为 Android 15，旧系统仍需设备复核。[官方边距与动画机制](https://developer.android.com/develop/ui/compose/system/insets-ui)。

磨砂在键盘动画期间退为令牌实色，结束后恢复；模糊效果按半径缓存，避免绘制时重新创建。浅色、字号、圆角和疏密保留原有令牌。工具行 44 点按区、22 图标、4 间距，只有右端语音／发送／停止位置是实心主按钮，辅助项没有常驻底，按下缩至 97%，禁用透明度 .45。审批是无勾盾牌，目标导航保留盾牌加勾，筛选仍是原三条线；模型星芒由 MODEL-1 主线合并继承。

## 设备、隔离与输入法恢复

所有原图是 MuMu（安卓模拟器）720×1280、应用逻辑宽度 390 的带状态栏整屏；系统主题、分辨率、实体键盘显示及其它模拟器设置均未改。页面分别选择浅／深。底部系统导航区域报告为 0，没有真实手势条，不能据此声称手势条已验收。

预装搜狗报告输入法可见，但区域高度为 0，诊断保留在 [sogou-zero-height.json](sogou-zero-height.json)。本人授权后只临时更改 `default_input_method` 和 `enabled_input_methods`，使用仓库测试包中的 `Ui2vTestIme`，由真实 InputMethodService（系统输入法服务）产生有高度的系统键盘。测试服务自身允许显示输入视图，没有改 `show_ime_with_hard_keyboard`。

[validation.json](validation.json) 保留切换前、恢复后、卸载后的两项原值及逐字比较结果。恢复在 `finally` 中执行；独立应用与测试输入法卸载，随机端口反向映射撤销，ADB（安卓调试桥）断开，锁释放。账号、数据、端口和宿主均为合成环境，无真实模型请求。已有本人安装与数据没有更新或清空，共享模拟器没有被关闭。

## A · 默认原生，取消开关

## 验证、轨迹与帧统计

实际行为结果见 [浅色](and12-light-checks.json)、[深色](and12-dark-checks.json)；每轮含旧偏好迁移、菜单和所有选择、风险确认／取消、候选文字连续组成、三个附件取消、两种语音按钮、发送／停止、输入区空隙、消息空白、滚动、阅读位置、多行输入与开关移除。

`*-frames.json` 与对应 CSV（逐帧数据表）记录输入区外框上下边；`trajectory-*.svg` 是原始数据折线。逐帧位置与多行过渡来自界面测试；正式键盘卡顿数另用没有 Compose 测试时钟的活动窗口采样，650毫秒覆盖系统动画及收尾，使用非调试隔离包。按每帧 `FrameMetrics.DEADLINE` 与 `TOTAL_DURATION` 比较，保留原始时长和期限，不用显示器标称刷新率替代应用帧期限。[官方帧指标说明](https://developer.android.com/reference/android/view/FrameMetrics)。

`*-metrics.json` 是带界面测试时钟的诊断样本，不能当作发布性能；`*-real-metrics.json` 是无该时钟的正式本轮样本。模拟器共享宿主资源，数字不能外推一加13，也不是正式真机 Macrobenchmark（宏观性能基准）。没有长期浸泡测试。

本地仅相关测试：`NativeChatStateTest` 15／0、合 AND-7 后 `NativeLibraryUnitTest` 11／0；图标与共享资源两文件9／0；离线调试／仪器包、非调试隔离变体、类型与公开卫生通过。全量在云端，最新结果见 [PR #290](https://github.com/memoweft/weftmate/pull/290)。早期 Windows 图库任务遇到私有目录 ACL（访问控制列表）校验失败，只复跑该任务后通过，没有放宽权限校验。

## 要本人真机确认

- 一加13真实输入法的候选词、切换语言、语音面板中点工具／菜单是否保持键盘与候选；测试键盘没有真实厂商候选条。
- 真实返回手势、收起键、手势条和输入法高度变化，Android 8–10 最终边距回退。
- 原生语音入口保持并打开键盘，提示使用键盘上的语音输入；未自动启动会夺走窗口焦点的独立听写活动。所用输入法的语音操作需确认。
- 真机接近发布配置下的120Hz／减少动态效果和连续输入手感；本轮系统统计保留其模拟器边界。
