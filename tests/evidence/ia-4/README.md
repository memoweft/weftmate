## 行为与证据

- [网页验证](verification.json)：390×844 / 360×780，浅 / 深、130% 字号；打开即主对话、最近内容、日期折叠与展开、搜索高亮 / 前后结果、三类结果打开原旁聊、开旁聊 / 返回来源 / 草稿转移。补验浏览器旁聊真实 `/personal/v1` 发送；测试控制用名称与角色。
- [安卓验证](android-verification.json)：真实原生桥、系统日期选择器、轻点与真实 WebView 内 CDP（浏览器调试协议）触摸长按菜单、旁聊来源、发送、D35 进展 / 审批 / 提问提交 / 停止、系统软键盘与系统 130% 字号。日期选择器和键盘图用设备全屏截图；其余为实际 WebView（网页视图）截图。
- [完整原生 / 网页 MiMo 验证](android-full-verification.json)：同一主对话、同一原生执行段，安卓与网页各一次普通消息及一次附件。附件 `weftmate-ia4-synthetic-note.txt` 只含合成编号 `PAPER-IA4-26`，真实模型读回。原请求、逻辑暂存与原生回执没有改绑。后续合成复验曾覆盖通用验证文件；完整文件由成功运行已记录的四个回执及独立保存的性能 / 用量文件恢复，保留这一来源说明。
- [用量](usage.json)：全包实际 8 次 MiMo 请求，含前两批验证尝试；输入 20,949 / 输出 62 / 合计 21,011 token（令牌），输入缓存 11,904。三批原始用量分别保留，没有把合成历史算成推理。
- 审稿页的 `main-chat` 手机场景已改为手机界面母版；安卓浅深主对话可从当前证据纳入同场景。

网页未观测到长任务；安卓有两次长任务，84 / 64ms，未观测到超过100ms的长任务。安卓最长单帧183.33ms单独保留，没有把它删掉或混入 p95。设备实际高刷新率，以记录的 `requestAnimationFrame`（逐帧回调）间隔为准，不冒充实体手机 60Hz 成绩。安卓本次 CSS（界面样式）视口 565×980、设备像素比约 1.275，物理图 720×1280；390×844 / 360×780 是网页验证。

[内存对比](memory.json)使用两个独立 Chromium 实例，相同手机界面、视口、五次历史读取和 30 次滚轮输入，采样前强制 JS heap（脚本堆）垃圾回收。1,000 → 10,000 条：渲染器私有内存 135.79 → 137.27 MiB（兆二进制字节），差 1.48 MiB；脚本堆差 0.026 MiB。每次只合计该实例的渲染器进程，不计浏览器 / 宿主进程。图片解码缓存不能单独观测；没有用整台机器内存代替界面指标。

[安卓性能](android-performance.json)另记录应用 PSS（按共享比例计入的内存）119,837 KiB（千二进制字节，约117.03 MiB）、脚本堆约7.80 MiB；这是单次应用样本，不当作千条 / 万条内存差。混合日志的合成图片引用没有原件，原生读取会拒绝不存在的资源；没有把它当作真实附件解码验证。真实附件验证用上述文本原件。

## 回归与边界

相关开发批次 114 项通过；合入最新 main（主分支）后的核心 / 移动记忆 87 项、网页登录与手机交互 100 项、后续相关134项、合 UX-4 后147项通过，批次有重叠。类型检查、安卓隔离构建 / JVM（Java 虚拟机）测试、真实 Electron（桌面程序框架）审稿与桌面交互通过。完整测试以 [PR #160](https://github.com/memoweft/weftmate/pull/160) 最新提交的 CI（持续集成）为准；没有新增跳过项或 CI 例外。首轮网页失败来自测试 DOM（文档对象树）不具备真实浏览器的插入 / 动态 ID / 状态选择器，已补齐；桌面提问条的一次交互超时在定向复验与 CI 重跑中通过，没有改断言或加例外。

Android `en-CA` 格式差异通过 `formatToParts`（分字段格式化）生成稳定日期键。六项能力只认数字1，未知版本降级；历史 / 增量游标独立，409先清旧模型、资源、命中与状态缓存。结果按原事件身份更新，来源被删除不从摘要恢复；仅引用明确提示“相关上下文尚未带入”。

已合 UX-4 的消息操作、MEM-2 临时入口、FX-14 离线修正与 FX-15 记忆确认。安卓沿主干 0.8.14 / code27，发布最低 code27；手机主对话消息操作绑定到实际虚拟行，复制 / 引用 / 编辑重发 / 重新生成 / 导出保留，操作条随轻点 / 长按显示。TB-4 的 `mobile-bottom-tabs` 容器隐藏，没有实现动态 / 目标 / 成果库页。未发布更新、部署到本人程序或验实体手机。
