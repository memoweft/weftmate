# AND-9 · 安卓原生设置与模型服务菜单

设置首页和常规、模型服务、账户、设备、外观、关于使用 Jetpack Compose（安卓声明式界面）。输入区星芒直接打开按服务分组的菜单；单服务省略组标题、当前项右侧单勾，长清单保留最近与常用型号并可搜索全部。明确支持时才提供深度思考；选择保存当前对话下一条和新对话默认，原运行回复仍由原协议处理。

连接电脑沿现有 `/personal/v1/model-services`；手机独立沿现有 `phone.models.service*` 和 WeftPhone（手机账户引擎），复用加密库，不另存密钥。旧电脑缺接口时保留旧模型菜单与准确网页设置入口。设置分类直接读取现有注册表，保留原顺序、搜索、返回位置；没有“使用原生聊天界面”开关。

原生模型页提供预设／自定义、查询目录、默认选择、地址和密钥编辑、重新查询、显示／隐藏型号、手填和二次确认删除。密钥错误与无目录分别提示。账户云模型保留在顶栏“更多”中。

保留原网页子流程：主题色；头像和完整账户保护／注销；设备配对／待批准；常规的系统状态、通知、同步、连接、更新及备用界面；关于的更新内容、帮助与法律正文。其他设置分类（个性化、助手、通知、回顾与健康、用量、数据与存储、已归档、权限、连接器、执行记录、记忆、定时任务、资料访问、系统状态）全部有准确入口。原生外观提供深浅／系统、阅读和代码字号、减少动态效果；主题色目前保留原页面实际生效的控件。

## 隔离与边界

安装包名仅 `com.memoweft.weftmate.mobile.and9qa`，测试完成或失败都卸载本包、撤销本次反向映射、断开并关闭私有 ADB（安卓调试桥）。取 `mumu.lock` 与一个重活名额，不修改模拟器设置，不操作默认调试包或本人登录数据。

MuMu（安卓模拟器）为 Android（安卓）15，系统深色；页面分别浅／深。实际截图 720×1280，测试包逻辑宽度 360／390（高度约 640／693），未修改模拟器尺寸，不能代替 360×780／390×844 真机验收。此实例没有可见系统手势条；输入法高度以 `done.json` 实测为准，零高度时仅证明草稿与焦点保持，不冒充非零真实键盘验收。

需要新壳版本：新增原生设置及服务菜单界面；未新增业务接口或系统权限，未自行修改版本号。本人真机需确认正常软键盘、候选／语言／语音、手势条安全区、字体放大、真实两电脑连接和云账户安全操作。

确认层系统栏处理参考 [Android 官方窗口属性说明](https://developer.android.com/reference/kotlin/androidx/compose/ui/window/DialogProperties)；最终采用与侧栏、模型菜单一致的同一活动窗口覆盖层，取样以实际整屏图为准。
