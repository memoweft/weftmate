[并排图总览](pairs.html)：设置首页、常规、模型服务、账户、设备、外观，浅／深各一组，共12组。每张图下列出「一致 / 故意更好 / 还差」。左原网页、右原生，来自同一合成账号、同样数据和相同页面主题；只拼接原始整屏 PNG（图片文件），没有重绘页面或系统栏。

首页沿网页的账户头像卡、卡外真实用量、胶囊搜索、分类顺序与注册表图标。卡片使用已有浅色 soft（柔和表面）令牌、26圆角，无描边；列表内边距、64最小行高、20图标、12间距与更小更淡的箭头对齐网页。常规、模型服务、账户、设备、外观、关于共用实底卡片；深色采用规范的中性灰。顶栏返回是圆形 IconButton（图标按钮），标题居中，右侧头像；模型服务标题旁的「更多」保留网页的账户云模型入口。

外观的三种颜色模式提供原生预览及当前勾选，保留减少动态效果、字号与代码字号；强调色沿原网页实际控件。头像选择、完整账户保护、设备配对及其余未迁入原生的子流程仍有准确原页入口。原包模型菜单已获认可，本次没有修改其布局、搜索字段、键盘或选择行为。

目标图标复用已有独立 `goal.svg`（带勾盾牌），网页手机底栏／侧栏和桌面侧栏、安卓底栏与苹果手机／电脑目标导航统一使用 `goal`。`approval.svg` 保持无勾，只用于权限。执行项目 `icons:generate` 流程生成各端资源，补齐安卓 palette、chart、archive、tool 的规范产物；苹果只改生成资源和图标名引用。
