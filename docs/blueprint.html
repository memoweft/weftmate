memoweft 生态 · 桌面伴侣

越用越懂你的
AI 桌面伴侣

WeftMate = 一套成熟桌面 App 的产品骨架 + 三样竞品都没有的独有肌肉。你跟她聊天、让她帮你写代码干活,她一边陪你、一边感知你在忙什么,MemoWeft 把这些整理成"对你的理解"(分得清事实与猜测)。用得越久,她越懂你。星瑶是她此刻的一个人格,可以随时换。

核心 · 懂你的循环

01相处聊天、让她帮你写代码/干日常活
02感知她看到你在忙什么、设备什么状态
03 · 引擎MemoWeft 整理沉淀成画像:哪些是事实、哪些只是猜测
04更懂你对你的理解越攒越准、越全
05更懂地帮你带着"懂你"回到相处,如此循环

循环转得越久 → 越用越懂用户。MemoWeft 是循环里的记忆引擎。

产品骨架

照搬成熟做法,别自创 — Claude/Codex/Raycast 已趟平
信息架构MVP
单一"＋"加料入口(加文件/图片、选工作区)+ `/` 命令 + 设置抽屉。功能再多也不迷路。
模型 · 切换与配置MVP
底部一个选择器:内置多模型(带用量倍率)+ 自定义模型 + 配置入口 + Max/推理档。模型配置就放这,不藏深处。
隐私与数据MVP
一个主开关 + 无痕模式 + 明确留存期 + 恢复出厂。感知设备本就敏感,这是信任红线。
历史 · 搜索 · 会话近期
对话历史、全文搜索、重命名、归档不删可恢复;跨设备接力(懂你的她要跟着走)。
账号 · 用量看板后续
个人向小看板:这个月聊了多少、烧了多少 token(本地估算·明标非账单)。BYOK；WeftMate 采用专有授权，底层 MemoWeft 保持独立开源。
主题 · 更新 · 快捷键后续
明暗主题 + 无障碍字体、App 内 changelog(她又学会了啥)、全局热键随叫随到。

三样独有肌肉

立身之本 · code 工具全没有 · 区别于"又一个 code 工具"的全部理由
记忆 + 画像可视MVP
分事实与猜测、会变淡;把"她对你的了解"做成能看还能纠错的画像面板(按来源分:感知来的/对话推断的/你改删过的)。
记忆气泡 · 管理即对话MVP
新理解当场织进聊天流:「记住了:X · 还没确认 · 改/删」。管理不用另开页——竞品都没有。
人格 = 可切换能力包MVP
一个人格 = 系统提示+语气+可选形象+声音+默认模型。切人格=切包,同一份"懂你"都还在。
感知 + 主动关怀近期
感知你在用啥/活动节奏→喂画像(observed 默认不上云);该提醒时形象说话而非冷 toast。
桌面形象 · 陪伴后续
常驻形象(Live2D/立绘)表情随对话/情绪同步。桌宠有形象但缺真记忆,WeftMate 两者合体——护城河,别当彩蛋。

帮你干活

走 MCP 接工具 · 信任基建是前提
agent 干活近期
计划→确认→执行,自主度三档(只建议/问一下/放手做)+ 沙箱 + 每步可视 + 一键撤回。敢交执行权靠这套。
MCP 一键装市场近期
像装扩展一样装能力(如 Claude CLI 写代码),不手改配置;工具定义延迟加载。
上下文 · 工作区近期
拖文件/图片给她当上下文;选个工作区(文件夹)让她在里面干活;检索式召回不全量塞。

三条贯穿纪律 · 踩竞品的坑总结的

工具定义延迟加载
只把名字放进上下文、用到才展开。长期陪伴接的工具越来越多,不这么做上下文必爆、token 失控——生死线。
只报 P0/P1 · 少而准
凡是主动打断(提醒/建议/发问)都要少而准。伴侣最忌唠叨;克制是可感知的产品气质。
不吹大 · 记≠信
守 naming.md:别写"真正理解你";慢活诚实说"要一会儿";不露原始把握度分,只给定性档;MemoWeft 不用"她"。

生态 · 越多感知源 → 越懂你

现在 · 桌面端 — 感知活动、帮你干活、攒画像,把根扎住。    后续 · 手机+穿戴 — 应用时长、睡眠、心率汇进同一画像,拼出更完整的你(架构留位、先不做)。
