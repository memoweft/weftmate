# 当前状态

路线见 [PLAN.md](PLAN.md)，产品决定见 [DECISIONS.md](DECISIONS.md)，客户端契约见 [CLIENT_API.md](CLIENT_API.md)。本页由总代理维护，只保留现状；工作包的验证与遗留写在仓库外的交付结果中。

## 各端现在能做什么

- **Windows 桌面程序**：可本机直接使用、配置自己的模型服务、聊天与切换模型；主对话、旁聊、项目、附件、流式回复、排队与引导、审批和提问已接入。电脑可执行文件、命令、浏览器与子任务，步骤和成果在对话中查看；支持记忆形成、召回、纠正与遗忘、临时对话、历史导入、定时任务、动态、目标和成果库。已有安装更新、加密备份、运行诊断、用量和设置。
- **安卓**：原生聊天、侧栏、输入区、目标、动态、成果库及模型服务已接入，部分页面仍使用网页。可独立配置云模型聊天，也可连接电脑发起任务、批准操作和查看成果；支持离线任务、记忆副本、文件预览和系统保存分享。通知在应用运行时接收，后台周期检查可能延迟。
- **macOS（苹果电脑系统）**：原生客户端支持主对话、项目、附件、步骤、审批、记忆、设置和离线聊天；本机试用程序带助手运行时，可执行文件和命令任务、重开后继续聊天。已有菜单、托盘对应的系统入口、退出清理和本机日志。
- **iPhone（苹果手机）**：可独立配模型聊天，保存账号隔离的轻量记忆；连接电脑后使用共享对话、电脑任务、审批、成果与完整记忆。已有原生设置、健康接入、附件、离线副本和恢复同步。
- **Apple Watch（苹果手表）**：可查看主对话和任务投影、接收运行中的提醒与本地通知，健康数据接入苹果端；离线投影不提供电脑任务审批，仍依赖配套手机与电脑能力。
- **远程浏览器与云服务**：网页复用桌面和手机界面，经登录、已有设备批准与加密中继访问电脑。云端已有账号、邮箱验证、设备目录、中继、离线任务暂存和加密备份接口；对话、完整记忆与健康原文留在个人设备。源码能力与生产部署状态分开确认。

## 已知的大缺口

- 五端能力和界面仍未完全对齐；安卓剩余网页迁移、苹果端系统面板与真实设备上的相机、通知、登录项和权限体验需要继续确认。
- 自动办事的真实模型表现仍不稳定，复杂审批、多轮任务和长任务不能只凭合成测试宣称可靠；跨端长期稳定性另行验收。
- 生产中继、内容证书自动签发、邮件与加密备份须按实际部署复验，代码通过不代表生产已启用。远程浏览器仍有产品已接受的云端被完全控制时的信任边界。
- 苹果端仍使用免费个人签名，正式推送、公开测试分发和 Mac 公证尚未开通；Mac 自动安装更新仍待后续接线。安卓进程被挂起后的通知有延迟。
- 精灵陪伴、共同空间与正式公开发布仍在后续路线；签名证书、外部内测、官网发布和扩容由本人决定。
