# 精灵、健康与记忆

> 依据：本人 2026-09-28《AI 健康宠物精灵 · 概念总结》（原文存于 `WeftMate/References/`）与 2026-10-06 对完整使用画面的描述。本文件是精灵 / 健康 / 相关记忆的产品规范；排期见 `PLAN.md` M4。

## 1. 精灵是什么

精灵是 WeftMate 的**可视化载体**：同一个账号、同一个助手，在电脑、手机、手表上以一只精灵的样子出现，负责陪伴、提醒和反馈。它有记忆、会互动，背后是 WeftMate + 本地模型 + MemoWeft。

> 已定（本人 2026-10-07）：精灵是**同一个助手的另一种呈现**——共用记忆与账号，说话的就是 WeftMate，语气可以更像精灵。

## 2. 核心：双向闭环，不是单向镜像

- 精灵的身体状态映射你的身体与情绪状态。
- 单向镜像会形成死亡螺旋（你蔫 → 它蔫 → 你看了更难受），所以精灵**同时是干预手段**：你抚摸它、跟它说话、安慰它，你的状态回升，它也跟着回升（照顾者效应、表达性倾诉）。
- **共情 + 可执行的出口**：先共情（「咱俩今天都蔫了」），再给一个小行动（「出去走十分钟吧」「今晚早点睡？」），不只复读情绪、不扣分。
- **不做死亡、不做惩罚**：只会「蔫」，并且可恢复（本人 2026-10-07 确认）。

## 3. 精灵状态

| 维度 | 含义 | 来源 |
|---|---|---|
| 能量 | 身体电量 | HealthKit / Health Connect：睡眠、HRV、静息心率、活动量 |
| 压力 | 紧绷程度 | HRV、心率、呼吸频率 + 对话 |
| 情绪 | 效价 × 唤醒度 → 平静 / 愉悦 / 焦虑 / 低落 | 对话文本（为什么难过）+ 自评 |
| 舒畅度 | 短时互动效果 | 抚摸、聊天后回升 |
| 成长 / 亲密度 | 长期维度 | 相处时长、互动、共同经历 |

外在表现：表情、动画、说话语气。

**分层原则**：规则 / 小模型 + 个人基线算数值；LLM 只做解释与归因。分数是游戏化表达，不是医疗诊断；情绪是推断，要标注不确定性。

## 4. 三路输入

1. **身体（HealthKit / Health Connect）**：心率、HRV、静息心率、睡眠、呼吸频率、步数与活动、锻炼。手机/手表本地汇总后上传**摘要**（如「昨晚睡 5 小时 40 分」「今日 HRV 低于个人基线 20%」），不上传原始流。擅长判断身体多累多紧绷。
2. **对话**：当天与近期对话中的情绪与事件，按时间对齐身体数据，回答「为什么」。
3. **自评**：少量主动询问「现在感觉怎么样」，作为个体校准，对抗咖啡、缺觉、运动等干扰。**频率由用户在设置里调**（含关闭），默认克制。

## 5. 与 MemoWeft 的结合

- 健康摘要作为 **observed（观察到的）证据** 写入 MemoWeft，带设备与时间来源，与「用户说的」「助手推断的」分开。
- MemoWeft 趋势模块从多次出现的同类状态归纳规律（「这周三天没睡好」「加班后 HRV 都偏低」）。
- 召回时把三类结合：**长期理解**（你说过熬夜后容易头疼）+ **近期对话**（这周提了几次加班）+ **健康趋势**（睡眠与 HRV 下降）。精灵和对话都用同一份召回。
- 说的是「从你的数据里长出来的话」，例：「你这周三天没睡好，HRV 也掉了，咱俩今晚都早点睡？」以及「你上次丧的时候是散步缓过来的」。
- 回复用到健康或记忆时，显示依据标签（「参考了你这周的睡眠」），可点开查看、纠正。
- 健康数据能否交给云端模型**由用户决定**：首次授权健康数据时询问，之后可在设置中随时更改；用户选择前只给本地模型使用。

## 6. 交互

| 交互 | 说明 |
|---|---|
| 抚摸 | 手机触摸 / 手表点按 + 触觉反馈，提升舒畅度（双方的） |
| 聊天 | 与精灵聊天就是与 WeftMate 聊天，记得你、看得到当天健康 |
| 精灵规则 | 用户在对话里说「提醒我喝水」「久坐一小时提醒我」，生成一条规则，精灵在合适时机提醒；规则可在对话中改和删 |
| 任务反馈 | 任务完成 / 需要审批时，手表震动 + 精灵提示 |
| 主动关心 | 健康明显变差、情绪低落时主动出现；主动程度可调，有安静时段 |

## 7. 各端呈现

| 端 | 精灵 |
|---|---|
| iPhone / Android | 主要家园：渲染、抚摸、聊天；主屏小组件；健康授权 |
| Apple Watch | 采集 + 轻展示：表盘复杂功能、点按抚摸、震动提醒、审批 |
| Windows / Mac | 桌面角落小窗（沿用现有桌宠与星瑶形象），点它打开对话 |
| 对话里 | 精灵头像与状态；依据标签 |

所有设备同一只精灵、同一个状态（服务端计算，经事件流推送）。

**形象由用户设定**（D14）：内置形象（如现有星瑶）、按描述孵化、或上传自己的图片；名字也可改。

## 8. 共养

- 和好朋友、伴侣**一起养一只精灵**，可以互相查看对方的状态（共享范围由各自决定，默认只共享精灵状态，不共享原始健康数据和对话）。
- 退出共养后记得过去、知道关系已变化；结束关系与删除记忆分开（见 `VISION.md`）。
- 后续：会员共享（开通会员可共享给伴侣）。

## 9. 边界

- 健康陪伴，不是健康教练，更不是医疗器械；分数是游戏化表达。
- 它是情绪练习场，不是终点，不替代真实人际连接。

## 10. MVP 顺序（来自概念文档，按 WeftMate 主线调整）

1. 只读 HealthKit → 能量/压力 → 精灵表情（验证镜像有效）。
2. 加入聊天（本地模型）+ MemoWeft 召回（近期对话 + 健康趋势）。
3. 加入抚摸与舒畅度（验证双向闭环）。
4. 精灵规则（喝水、久坐）与任务反馈（手表震动）。
5. 自评校准；共养。

## 11. 已定事项（本人 2026-10-07）

| 问题 | 决定 |
|---|---|
| 精灵与 WeftMate 的关系 | 同一个助手的另一种呈现 |
| 自评频率 | 用户在设置中调整（可关闭），默认克制 |
| 健康数据给云端模型 | 用户决定：首次授权时询问，设置中可改；未选择前仅本地模型 |
| 惩罚 / 死亡 | 不做；只有可恢复的「蔫」 |
