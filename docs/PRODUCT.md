# WeftMate 产品边界

## 一句话定义

WeftMate 是连接和管理 DSH、MemoWeft、AI-Game 的桌面集成中心，也是用户统一操作这些能力的图形界面。

## 组件关系

| 组件 | 自己负责 | WeftMate 负责 |
|---|---|---|
| DSH | Agent、模型、工具、权限和代码执行 | 提供用户界面并管理运行状态 |
| MemoWeft | 长期记忆和共同世界 | 在能力稳定后接入、展示和管理 |
| AI-Game | 主动智能体、目标、事件和设备协同 | 在能力稳定后接入用户交互 |
| WeftMate | 图形界面、集成、配置、生命周期、诊断 | 不复制其他项目的内部逻辑 |

## 当前产品边界

- WeftMate 先完成自己的最小 UI 和统一管理框架；
- DSH 是当前可用的主要运行时；
- MemoWeft 只保留可关闭、可降级的试验接缝；
- AI-Game 尚未正式接入；
- 未完成的外部系统不能阻止 WeftMate 启动和使用；
- 手机、平板和手表以后作为协同客户端接入，不复制桌面端全部能力。
