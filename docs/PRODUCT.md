# WeftMate 产品文档

> **活文档 · 中途可调** —— 做的过程中发现要改的,随时改这份。可视化蓝图见 [`blueprint.html`](./blueprint.html)(浏览器打开)。
> 定稿 2026-07-07(作者拍板 · 竞品综合 + 界面细化后通过)。

## 定位

三层别搞混:

- **MemoWeft** = 能力层 · 库(`import 'memoweft'` 当依赖,库仓库在 `../DLA_rebuild`)。
- **WeftMate** = 产品层 · 这个 **Electron 桌面常驻 App**。开源、面向大众、主打展示 MemoWeft 记忆能力。
- **星瑶** = WeftMate 里**一个可切换的人格**(作者设定,非产品名)。第一人称"我记得你"只属星瑶这层。

一句话:**WeftMate = 一套成熟桌面 App 的产品骨架 + 三样竞品都没有的独有肌肉**,终点是**越用越懂你**。

## 核心 · 懂你的循环

`相处(聊天/让她帮你写代码干活) → 感知(你在忙什么/设备状态) → MemoWeft 整理成画像(分事实与猜测) → 更懂你 → 更懂地帮你 → 回到相处`。循环转得越久越懂用户。MemoWeft 是循环里的记忆引擎。

## 界面 · Claude Desktop 风格 · 对话为主

- **左** = 对话记录列表(像 Claude Desktop),不是功能导航。
- **主区** = 对话;她能在对话里直接调工具(如 Claude CLI)帮你干活。
- **功能收在侧栏底部**(记忆与画像 / 能力与感知 / 设置 / 人格切换),点开**有切换动画**。
- **底部工具栏**:`＋(加文件 / 选工作区) · 模型选择器(内置多模型带倍率 + 自定义 + 配置 + Max/推理档) · 技能 · 沙箱权限 · 发送`。**模型配置就放这、不藏设置深处**。
- **输入框无默认提示**(不放 placeholder)。
- **桌面形象**浮在角落、随手唤起。

## 功能盘(带优先级 · MVP / 近期 / 后续)

### 产品骨架(照搬成熟做法,别自创 — Claude/Codex/Raycast 已趟平)
- **信息架构**(MVP):单一"＋"加料入口 + `/` 命令 + 设置抽屉。
- **模型 · 切换与配置**(MVP):底部选择器,内置多模型 + 自定义 + 配置 + Max/推理档。
- **隐私与数据**(MVP):主开关 + 无痕模式 + 明确留存期 + 恢复出厂。
- **历史 · 搜索 · 会话**(近期):历史/全文搜索/重命名/归档不删可恢复;跨设备接力。
- **账号 · 用量看板**(后续):个人向小看板(聊了多少/烧了多少 token,本地估算·明标非账单),BYOK,核心永远免费开源。
- **主题 · 更新 · 快捷键**(后续):明暗+无障碍字体、App 内 changelog、全局热键随叫随到。

### 三样独有肌肉(立身之本 · code 工具全没有 · 区别于"又一个 code 工具"的全部理由)
- **记忆 + 画像可视**(MVP):分事实与猜测、会变淡;把"她对你的了解"做成**能看还能纠错**的画像面板(按来源分:感知来的/对话推断的/你改删过的)。
- **记忆气泡 · 管理即对话**(MVP):新理解当场织进聊天流「记住了:X · 还没确认 · 改/删」,管理不用另开页。
- **人格 = 可切换能力包**(MVP):一个人格 = 系统提示+语气+可选形象+声音+默认模型。切人格=切包,同一份"懂你"都还在。
- **感知 + 主动关怀**(近期):感知你在用啥/活动节奏 → 喂画像(observed 默认不上云);该提醒时**形象说话**而非冷 toast。
- **桌面形象 · 陪伴**(后续):常驻形象(Live2D/立绘)表情随对话/情绪同步。桌宠有形象但缺真记忆,WeftMate 两者合体——护城河,别当彩蛋。

### 帮你干活(走 MCP 接工具 · 信任基建是前提)
- **agent 干活**(近期):计划→确认→执行,自主度三档(只建议/问一下/放手做)+ 沙箱 + 每步可视 + 一键撤回。
- **MCP 一键装市场**(近期):像装扩展一样装能力(如 Claude CLI 写代码),不手改配置;**工具定义延迟加载**。
- **上下文 · 工作区**(近期):拖文件/图片当上下文;选个工作区(文件夹)让她在里面干活;检索式召回不全量塞。

## 三条贯穿纪律(踩竞品的坑总结的)

1. **工具定义延迟加载** —— 只把名字放进上下文、用到才展开。长期陪伴接的工具越来越多,不这么做上下文必爆、token 失控。**生死线。**
2. **只报 P0/P1 · 少而准** —— 凡是主动打断(提醒/建议/发问)都要少而准。伴侣最忌唠叨。
3. **不吹大 · 记≠信** —— 守 MemoWeft 的 `docs/naming.md`:别写"真正理解你";慢活诚实说"要一会儿";用户侧不露 0–1000 原始把握度只给定性档;MemoWeft(能力层)任何文案不出现"她"。

## 生态 · 越多感知源 → 越懂你

- **现在 · 桌面端**:感知活动、帮你干活、攒画像,把根扎住。
- **后续 · 手机 + 穿戴**:应用使用时长、睡眠、心率汇进同一画像 → 更完整的你。**架构留位、先不做**(手机端还没开工)。

## 施工路线

- **S0 · sqlite** ✅ 已通:node:sqlite 在 Electron 43 / Node 24.17 可用,**走 node:sqlite·零原生模块**。
- **S1 · Electron 骨架** ✅ 已通:主进程建 core + 起 127.0.0.1 loopback + 窗口加载,现有 Host 能力已在桌面跑;实测 **Electron main 直接跑 .ts、免编译链**。
- **阶段 1 · 立身之本**:产品骨架 + 三样肌肉打底 —— Claude Desktop 风格外壳(对话为主、功能收起有动画、底部工具栏)、配模型设置、隐私开关;把**记忆 + 画像可视 + 记忆气泡 + 人格**做扎实,让"越用越懂"当场可感、可纠错。守克制纪律。
- **阶段 2 · 懂你 & 帮你**:感知 → 画像 + agent 干活的信任基建(沙箱/分级审批/回滚)+ MCP 一键装(接 Claude CLI 等)+ 上下文附件 + 历史接力。让循环真转起来。
- **阶段 3 · 陪伴 & 完整度**:桌面形象深化(表情/情绪同步)、用量看板、主题/changelog/快捷键;为手机/手表感知源留架构。

## 现状 · 已趟平(S0 / S1)

- **sqlite 结论**:未装 better-sqlite3、能跑就是 node:sqlite 生效(Electron 43 内置 Node 24.17)。零原生模块、零 electron-rebuild、零 asarUnpack。
- **架构**:`src/main.mjs` 设 userData 库路径 + 默认星瑶 + 单实例锁 → `import './server.ts'`(起 loopback + 建 core) → 开 BrowserWindow 加载 `http://127.0.0.1:7788`。
- **已从 `../DLA_rebuild/apps/memoweft-host` 复用进 `src/`**(都只经 `import 'memoweft'` 用门面,不碰库):`experiences/`(星瑶/plain 人格 + 注册表)、`scheduler.ts`(后台整理)、`chatHistory.ts`、`confBand.ts`(把握度分档)、`server.ts`(loopback + core + chat 编排)、`web/index.html`(2319 行前端·**阶段1 要重做成产品级**)。
- **三个"不解决就跑不起来"的坑**:① 模型 key 设置界面(不做装完打不开)② DB 落 userData(✅ 已做)③ 单实例锁(✅ 已做)+ 托盘常驻生命周期(before-quit 调 scheduler.dispose + core.close)。

## 红线

- **不碰 MemoWeft 库** —— 当依赖 `import 'memoweft'`,不改其源码(库仓库在 `../DLA_rebuild`,它的 main 保持"库+生态"纯粹)。
- **隐私** —— apiKey 不明文落盘(用 Electron safeStorage);observed 默认不上云;感知敏感,守 MemoWeft 已定的云优先隐私三条。
- **守 naming.md** —— 见三条纪律第 3 条。
- **能跑** —— electron 起得来、typecheck 过。
