# WeftMate 前端交互规范

> 交互标准对齐 **Claude Code**（桌面 app、手机 app）与 **Codex**（桌面 app、手机端）；功能是 WeftMate 自己的。两者底层与 WeftMate 相同：模型 → 调工具 → 看结果 → 再决定。
> 实现前请实际打开本机安装的 Claude 桌面版与 Codex 桌面版对照手感；本文件写规则，不逐像素复刻，也不使用它们的品牌元素。
> 相关决定见 `PLAN.md` D5–D7、M1-0。

## 1. 总原则

1. **对话即工作区**：一切在对话里发生和查看。没有任务页、任务详情弹窗、任务列表。
2. **过程默认安静**：执行时显示实时进度，完成后收起成一行摘要；细节点开才看。
3. **需要人时才打扰**：只有审批、提问、失败需要用户处理时才醒目提示，并就地处理。
4. **产物在侧面板打开**：文件、网页、预览在右侧面板（桌面）或全屏页（手机）打开，关掉回到对话，不开新窗口。
5. **同一个会话，任何设备接着用**：手机能看电脑上正在跑的任务、审批、接着说。
6. **少即是多**：常态界面不出现实现说明（「已连接宿主」「同步中」之类）；文案短、动词开头。

## 2. 桌面（Windows 程序 / macOS App）

### 布局

| 区域 | 内容 |
|---|---|
| 左侧栏（可收起） | 顶部「新对话」；会话列表（按时间分组，可搜索）；运行中的会话显示状态点，有待审批显示提示点，未读加粗；会话右键 / 滑动：重命名、归档（隐藏，经验保留，可在「已归档」恢复）、删除（经验一并删除，需确认；确认框可勾选「同时忘掉从这段对话形成的记忆」，默认不勾，D16）；底部账号头像 → 设置、记忆、设备 |
| 中间 | 对话时间线（居中、限宽）+ 底部输入区 |
| 右侧面板（按需） | 见下方「右侧面板」；可拖宽、可关闭 |

### 右侧面板（本人 2026-10-08，参照 Codex 桌面版）

- 对话标题栏右侧一个「输出与来源」按钮，点开为小浮层，分两组：
  - **输出内容**：本对话生成的文件 / 网页 / 成果，逐项列出；空时显示一行灰字提示。
  - **来源**：本对话用到的网页、读过的文件、引用的记忆、调用过的工具 / 连接器，逐项列出；末尾「查看全部」。
- 点选任一项，在右侧面板以**标签页**打开（标签显示图标 + 名称，可单独关闭；标签栏「+」从同一列表再开一项）；面板可拖宽、可放大、可整体收起。
- 来源条目点开显示该来源在本对话里的使用摘要（如「读取 3 次」「引用 2 次」），再点进具体内容；成果条目直接预览，可下载 / 用默认程序打开 / 在文件夹中显示。
- 成果卡、「用到了 N 条记忆」标签、步骤里的文件 / 网址，点击都在这个面板的新标签里打开。
### 时间线元素

| 元素 | 规则 |
|---|---|
| 用户消息 | 右侧气泡或简洁块；附件缩略图 |
| 助手文字 | Markdown 渲染；流式输出 |
| 工作指示 | 运行中显示「正在处理… 1分20秒」及当前步骤 |
| 工具步骤 | 连续步骤合并成一组：「读取了 3 个文件」「运行了 2 条命令」；组可展开，展开后每步一行可读描述，再点开看原始命令与输出（等宽字体、可复制）。完成后整组收起为「执行了 N 步 · 用时 X」 |
| 计划 / 待办 | 模型维护的待办清单就地显示，随进度打勾 |
| 审批卡 | 说明要做什么、影响范围、能否撤销；按钮：允许一次 / 总是允许此类 / 拒绝；处理后收成一行记录 |
| 提问卡 | 助手缺信息时提问，可给选项按钮 + 自由输入 |
| 成果卡 | 文件名、类型、大小；点击在右侧面板打开；可下载 / 在文件夹中显示 |
| 错误 | 一句话说清发生了什么 + 下一步（重试 / 换模型 / 去设置）；不显示原始异常 |
| 排队 | 运行中再发新目标 → 显示「排队中」卡片，可取消 |

### 输入区

- 多行输入，Enter 发送、Shift+Enter 换行；拖拽 / 粘贴文件与图片。
- UI-3 实现备注：Enter 发送当前选择（运行中默认插话），Ctrl/Cmd+Enter 将消息作为新任务排队，Shift+Enter 换行；停止保留排队任务。排队卡放在输入框上方，可取消或取消后编辑重新排。
- 一行工具条：附件「+」、**审批模式**（紧凑名称 + 弹出菜单，见下）、模型选择（紧凑名称 + 弹出菜单，底部「配置模型」）、语音。执行设备不常驻，默认本机，有歧义时助手在对话中问。
- 审批模式菜单（D12，样式对齐 Claude Code 的模式菜单：名称 + 一行说明 + 当前项打勾 + 数字快捷键）：
  1. 自动（推荐）— 由 WeftMate 判断，有风险才问你
  2. 每次询问 — 执行和修改前都先问
  3. 自动接受文件修改 — 改文件直接做，其他照常询问
  4. 先出计划 — 先给计划，你确认后再做
  5. 全部允许 — 不再询问
- 运行中发送按钮变为**停止**；Esc 也可停止。
- 运行中输入的内容：见第 5 节待定项。

### 快捷键

Enter 发送 · Shift+Enter 换行 · Esc 停止 · Ctrl/Cmd+N 新对话 · Ctrl/Cmd+K 搜索会话 · Ctrl/Cmd+B 收起侧栏。

## 3. 手机（Android / iOS）

- M2-4 实现备注：桌面会话右键 /「更多」、手机长按 /「更多」提供归档与删除；「已归档」可查看并恢复。归档对话先点「恢复对话」才能发送，输入区保持不可发送。删除确认写明永久删除对话、工作目录与经验；「同时忘掉从这段对话形成的记忆」默认不勾。运行中的对话先停止；停止或遗忘未确认时显示失败原因并允许重试。

- **首页是会话列表**，顶部新对话；运行 / 待审批状态同桌面。
- 进入会话：同一条时间线，工具步骤**默认收起**；成果、网页点开为全屏页，返回回到对话原位置。
- 输入区固定底部，跟随键盘；发送 / 停止同桌面。
- 审批与提问卡与桌面一致，按钮足够大可单手点。
- **通知**：任务完成、需要审批、需要回答时推送；点通知直达该会话的对应位置。
- 电脑上发起的任务，手机打开同一会话能看到实时进度并操作。
- 电脑不在线时：可以照常聊天、用记忆；交代电脑上的事会显示「等电脑上线后执行」的排队卡，可取消；电脑上线执行完成后推送通知（D17）。
- 动效：列表与页面切换跟手、键盘开合不跳动；草稿在切换和重启后保留。

## 4. Apple Watch

- 只做三件事：当前任务简进度（一行）、审批（允许 / 拒绝）、完成或需要处理时震动。
- 点开可看最近一条助手回复摘要；不在手表上输入长文本（可语音补一句）。

## 5. 运行中输入

- （已定，D9）**运行中继续输入**：默认插话，当前任务就地调整；明确的新目标排队（D7）。界面上用一个小切换或长按发送区分。

## 6b. 登录与设备（D29；细节参照 Codex / Claude 等多端 App 的通行做法）

### 登录页（电脑程序、手机、网页的第一页）
- 中间一张简洁卡片：C4 标志 + 「登录 WeftMate」；邮箱、密码（可显示 / 隐藏）、「登录」主按钮；下方「忘记密码？」「还没有账号？注册」。只做账号的事，不出现配对码、电脑地址、直连。
- 错误就地提示一句话：邮箱或密码不对、网络不通（可重试）、尝试太多次（显示还要等多久）。不说明「邮箱是否存在」。
- 底部次要入口「离线使用这台电脑」（只在电脑程序里，云不可用时的应急本地登录）。
- 登录成功后记住本设备，下次直接进入；令牌过期自动续期，续不了才回登录页并保留草稿。

### 注册与设置密码
- 邮箱 → 「发送验证码」（60 秒后可重发，显示倒计时）→ 输入 6 位验证码 → 设置密码（至少 8 位，两次一致，显示强度提示）→ 设备名称（默认取电脑 / 手机名称，可改）→ 完成并自动登录。
- 页面底部一行「注册即表示同意《服务条款》《隐私政策》」，内容见 `docs/legal/terms-zh.md`、`docs/legal/privacy-zh.md`，App 内可直接打开阅读。
- 忘记密码：邮箱 → 验证码 → 设置新密码 → 回到登录页并预填邮箱。重设密码后其他设备不受影响（与 CLOUD.md 一致：不解锁备份、不顺带撤销设备）。

### 新设备等待批准（D23）
- 登录成功但本设备还没被批准看内容时，显示等待页：「在你已登录的设备上允许这台设备」，列出可以批准的设备名称；或「用已登录的手机扫这个二维码」。可取消、可换账号。批准后自动进入，不用重新登录。
- 已登录设备上：顶部出现一条提示「新设备 iPhone 15 请求访问」→ 允许 / 拒绝；也可在设置 → 设备里处理。

### 设置 → 账户
- 邮箱、「换绑邮箱」（输入新邮箱 → 新邮箱收验证码 → 完成，旧邮箱收到「邮箱已更改」通知）、修改密码（先输入当前密码，再设置新密码）、退出登录、「退出所有其他设备」、「注销账号」（输入密码确认；确认框写明：云端账号数据全部删除且不可恢复，本机的对话与记忆仍留在设备上）。
- 不做手机号验证。

### 设置 → 设备
- 列表：本账号已登录的所有设备，每行图标（电脑 / 手机 / 平板 / 手表 / 浏览器）、名称、在线状态、最近使用时间；本机标「这台设备」；电脑类设备标「可执行任务」。
- 每台设备可：改名、移除（该设备立即退出，需确认）；电脑类设备可「连接」：已受信设备直接连；新设备扫电脑上显示的二维码配对（没相机时输入配对码作为备用）。
- 电脑上：「添加设备」显示配对二维码（2 分钟自动刷新）；「待批准」区显示请求访问的新设备。
- 「共享给其他账号」（S5）：对方出示二维码，由本账号的主设备扫码确认后才建立共享；对方不能单方面连接。

### 多端一致
- 电脑程序、手机 App、网页、iPhone / Mac 用同一套流程和文案；Watch 不登录，跟随已配对的 iPhone。
- 一台设备同一时间只登录一个账号（D30），不做多账号切换。

Apple 实现备注（LG-2）：登录 / 注册 / 找回页面与账户 / 设备设置分离；密码、验证码与密码票据不持久化，令牌失效沿用原账户草稿保存流程。正式服务当前仍按 CLIENT_API 7.1 校验 15–128 位密码；8–14 位虽然通过本页客户端初检，服务拒绝时显示实际长度要求。此处记录实现与服务的差异，不修改上面的至少 8 位规格；服务器轨道需统一密码规则。

## 6c. 设置结构（D31，所有端）

参照 Claude 桌面版设置。**所有端同一套分类、名称、顺序和图标**（图标来自 `design/icons/`），只按平台习惯改变呈现：

| 分组 | 分类 | 内容 | 出现在 |
|---|---|---|---|
| 设置 | 常规 | 开机自启、关闭窗口时最小化到托盘、通知、语言 | 全部（开机自启 / 托盘仅电脑） |
| 设置 | 外观 | 颜色模式（分段：浅色 / 深色 / 跟随系统）、主题色、字号、界面密度 | 全部 |
| 设置 | 账户 | 邮箱、换绑邮箱、修改密码、退出登录、退出所有其他设备、注销账号（6b） | 全部 |
| 设置 | 设备 | 已登录设备、改名 / 移除 / 连接、添加设备二维码、待批准（6b） | 全部 |
| 设置 | 用量 | 本月合计、每日、按对话 / 模型排行、月度上限 | 全部 |
| 助手 | 模型 | 主模型、后台模型、模型档案与单价 | 全部 |
| 助手 | 审批 | 新对话的默认审批模式 | 全部 |
| 助手 | 记忆 | 记忆管理入口（它记得什么、从哪来） | 全部 |
| 助手 | 提醒与定时任务 | 列表、暂停 / 恢复、删除、立即运行 | 全部 |
| 此电脑 | 系统状态 | 模型服务、宿主、一键修复 | 仅电脑程序 / Mac |
| 此电脑 | 备份与恢复 | 自动备份、立即备份、恢复 | 仅电脑程序 / Mac |
| 关于 | 关于 | 版本、服务条款、隐私政策、反馈 | 全部 |

- **电脑程序 / 网页 / Mac**：设置是大浮层（Mac 为独立设置窗口），右上角 ×、Esc 关闭；左侧一列分类导航，顶部搜索框，分组小标题；右侧大号分类标题，下面逐行「左：名称 + 一句灰色说明｜右：开关 / 分段按钮 / 下拉 / 输入框」，行间细分隔线，留白宽松。窄窗口（<720px）左导航折叠为顶部下拉。
- **手机（Android / iPhone）**：设置首页是分组列表（图标 + 名称 + 当前值摘要），点进子页，返回保留位置；iPhone 用系统分组列表样式，Android / 手机网页用同一结构的网页呈现。
- **Watch**：不放设置，跟随 iPhone。
- 可直接打开到某个分类（例如对话里「本对话用量」直达用量并定位该对话）。
- 新增设置只在对应分类登记一项（桌面 / 手机网页用 `src/ui-core/settings-registry.js`），不再另开页面或折叠块。

### UI-4 实现备注

桌面窗口最低宽度为 480px。

- 常规保留开机自启；通知由现有系统通知管理，关闭窗口留在托盘、简体中文是当前行为。未实现独立设置的项目显示真实状态，不增加假开关。手机的通知、离线与同步、连接、界面更新与兼容入口收在常规；远程网页的已有宿主状态也保留在常规。
- 外观颜色模式用共用分段按钮「浅色 / 深色 / 跟随系统」，主题色与字号保留原设备持久化。当前密度为标准；字体、自定义颜色、密度编辑与账号同步仍待对应功能包。
- 账户、设备保留本机应急账户与云账号的全部原有动作；按登录方式显示实际内容。模型包含主模型说明、后台模型与账户模型档案；审批保留新对话默认模式；记忆提供管理入口；资料访问保留项目与网页资料功能。
- 用量是完整分类，不用折叠块。本月费用与请求数、输入 / 缓存 / 输出、每日柱状图、对话与模型排行、月度与本月临时上限及模型单价沿用原功能。「本对话用量」直接打开设置 → 用量，并按当前对话过滤；在导航重新选「用量」回到账户总量。
- 手机使用同一分类注册表：「设置列表 → 推入子页」，返回恢复搜索和列表滚动位置，沿用 UI-P1m 方向动效。此电脑分组不显示；关于提供版本与条款 / 隐私阅读。手机已有连接电脑状态位于常规。
- 新分类登记 `{id, group, name, icon, keywords, mount}`，桌面挂载收到 `{target, core, ui, ...options}`；桌面通过 `WeftSettingsNavigation.register()` 注册即可生成导航、搜索与内容容器，手机通过 `mobileSettingsRegistry.register()` 注册。SCH-1 已合入：提醒与定时任务登记到「助手」，桌面和手机共用列表呈现，暂停 / 恢复 / 删除 / 立即运行及所属对话入口复用领域动作。BK-1 已合入：备份与恢复登记到「此电脑」、`desktopOnly: true`，保留自动备份、保留策略、立即备份、导入与恢复确认，复用领域动作与接口。
- 开关与分段按钮共用 `components/settings-controls.js`，手机资产由构建脚本从桌面母版生成。尺寸、间距、字号、圆角与动效全部来自设计令牌；分类新增 `palette`、`chart` 图标使用规范母版生成。


## 7. 外观设定（D14）

默认简约美观、操作流畅。设置 →「外观」可改：浅色 / 深色 / 跟随系统、主题色（预设 + 自定义）、字体、字号、界面密度；精灵形象（内置形象、按描述孵化、上传图片，见 `COMPANION.md`）。所有端同一账号同步外观偏好，各端可单独覆盖。

## 7b. 动效与精修（D28）

- UI-P1m 手机实现备注：沿用桌面 `base`（200 毫秒）、`fast`（180 毫秒）、`160ms`、`240ms` 与 `exit`（120 毫秒），统一 `desktop` 曲线；全屏来源页 / 会话 / 登录步骤按方向切换，抽屉进入 240 毫秒、退出 120 毫秒。新步骤按身份错开 `stagger`（24 毫秒），总延迟最多 `staggerLimit`（60 毫秒）；步骤与排队卡超过 20 项直接显示。布局立即完成，返回保留草稿和滚动，退出副本不可交互；浏览器与 Android（安卓）系统动画缩放为 0 均瞬时显示，运行中修改也生效。[手机前后连续帧与性能记录](../tests/evidence/ui-p1m/README.md)。

- UI-P1 桌面实现备注：执行块展开、审批卡与页面 / 登录步骤切换使用 `base`（200 毫秒），新步骤、排队卡和标签 / 列表使用 `fast`（180 毫秒），面板进入使用 `240ms`，消息块 / 记忆标签和发送 / 停止反馈使用 `160ms`，退出使用 `exit`（120 毫秒）；统一 `desktop` 缓动曲线。步骤错开 `stagger`（24 毫秒），总延迟最多 `staggerLimit`（60 毫秒）；超过 20 项直接显示。布局一次到位，退出副本不参与布局或交互；系统减少动态效果时全部瞬时，并响应运行中偏好变化。现有消息块按收到的粒度平滑淡入，不添加逐字播放或传输功能。[真实程序前后连续帧与性能记录](../tests/evidence/ui-p1/README.md)。

- UI-3 实现备注：审批卡和工具来源先显示共享功能层的人话摘要，原始参数收在「详情」；输出列表显示同路径最新版本，预览里可展开已读取的旧版。

- 界面与功能分层：功能（连接、会话、发送、审批、成果、记忆、设置）只在功能层实现一次；界面组件只负责摆放与样子，调整布局或挪动组件不得改动功能层。测试按可见名称与角色找元素、断言行为，不依赖位置。
- 所有颜色、字号、间距、圆角、阴影与动效参数来自 `design/tokens/`（DS-1 建立后），各端不写死数值。
- 动效原则：短（大多 150–250 毫秒）、跟手、有意义（表达展开、出现、完成），不做装饰性循环动画；系统开启「减少动态效果」时改为淡入淡出或无动画。
- 需要动效的位置：执行块展开 / 收起、步骤逐条出现、审批卡出现与处理后收成一行、右侧面板开合与标签切换、会话列表与页面切换、发送↔停止、流式文字、记忆标签出现。具体参数在 UI-P1 定稿后写回本节。
- 精修按第 9c 节分轮进行，每轮本人确认后合并。

## 8. 验收方式

每个前端工作包完成时，执行者用真实界面（Windows 桌面程序窗口、macOS 与手机 App；不以浏览器页面代替，D27）走一遍办事场景，截图或录屏放进 PR：发起目标 → 看进度 → 处理一次审批 → 打开成果 → 停止 / 排队各一次；桌面与手机各一遍。

## 6. 图标

唯一来源为 [design/icons/](../design/icons/README.md)，所有平台从母版生成，命令为 `npm run icons:generate`。应用图标采用本人 2026-10-08 确认的 C4「天蓝」：64 × 64 坐标，圆心 (25,32) / (39,32)、半径 13、线宽 5.5，两环上下交替穿过；交叉用真实透明缺口，上方左环在上、下方右环在上。中心点半径 2.6。浅底左环 #1B1D24、右环和中心点 #0A7AFF；深底左环 #F1F2F6、右环和中心点 #4DA3FF。单色版两环同色、右环与中心点 55% 透明度，用于托盘、手表、通知小图标等。

功能图标为设计稿确认的 45 个及按同规则补齐的现有动作：24 × 24 网格、线宽 1.75（16 像素及以下用 1.5）、圆角端点和拐角，只用 currentColor（继承文字颜色）。新增图标先检查已有语义，确需新增就放在 design/icons/ui/，用英文 id（标识）命名；重新生成各端资产，并在真实尺寸及浅 / 深色下验收。不另引入图标库或字符图标，不直接修改生成文件。应用母版在 design/icons/app/，苹果端由 Mac 工作包接入。
