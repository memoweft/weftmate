# WeftMate 前端交互规范

> 交互标准对齐 **Claude Code**（桌面 app、手机 app）与 **Codex**（桌面 app、手机端）；功能是 WeftMate 自己的。两者底层与 WeftMate 相同：模型 → 调工具 → 看结果 → 再决定。
> 实现前请实际打开本机安装的 Claude 桌面版与 Codex 桌面版对照手感；本文件写规则，不逐像素复刻，也不使用它们的品牌元素。
> 相关决定见 `PLAN.md` D5–D7、M1-0。

## 1. 总原则

1. **对话即工作区**：一切在对话里发生和查看。没有任务页、任务详情弹窗、任务列表。
2. **过程默认安静**：执行时显示实时进度，完成后收起成一行摘要；细节点开才看。
3. **需要人时才打扰**：只有审批、提问、失败需要用户处理时才醒目提示，并就地处理。
4. **产物在侧面板打开**：文件、网页、预览在右侧面板（桌面）或全屏页（手机）打开，关掉回到对话，不开新窗口。
5. **同一个会话，任何设备接着用**：手机能看电脑上正在跑的任务、审批、接着说。
6. **少即是多**：常态界面不出现实现说明（「已连接宿主」「同步中」之类）；文案短、动词开头。

## 2. 桌面（Windows 程序 / macOS App）

### 布局

| 区域 | 内容 |
|---|---|
| 左侧栏（可收起） | 顶部「新对话」；会话列表（按时间分组，可搜索）；运行中的会话显示状态点，有待审批显示提示点，未读加粗；会话右键 / 滑动：重命名、归档（隐藏，经验保留，可在「已归档」恢复）、删除（经验一并删除，需确认；确认框可勾选「同时忘掉从这段对话形成的记忆」，默认不勾，D16）；底部账号头像 → 设置、记忆、设备 |
| 中间 | 对话时间线（居中、限宽）+ 底部输入区 |
| 右侧面板（按需） | 见下方「右侧面板」；可拖宽、可关闭 |

### 侧栏会话行与账户（D50 / UX-P3）

- 项目常态仅显示展开 / 合上的文件夹图标和单行截断名称，无按钮和底色。鼠标悬停或键盘聚焦时，整行浅底色占满侧栏内宽，右侧行内依次出现更多和新对话；更多提供项目设置 / 移除登记，移除仍确认。项目不代表当前对话，没有选中态。触屏长按项目可新建对话。
- 对话常态单行标题，右侧一个状态位：**运行中转圈 > 未读小点 > 空**。运行与未读同时存在时仅显示转圈；置顶 / 临时属性在菜单及无障碍描述中保留，不叠加右侧图标。选中对话整行浅底色。鼠标悬停 / 键盘聚焦时状态位替换为置顶、归档两个图标，已置顶提供取消置顶；黑色小提示为「置顶聊天 / 取消置顶 / 归档」。参照采用两个图标，更多通过右键、菜单键或 Shift+F10 进入，原有重命名、移动、分叉、临时与记忆操作保留。
- 悬停约 0.5 秒在行右侧显示标题、设备图标（这台电脑 / 其它设备）、相对时间（刚刚 / 17 分 / 3 小时 / 昨天），所属项目以文件夹和名称显示；无项目不显示该行。卡片不接收指针，贴边左右翻转并限制在视口内；移开、打开菜单或 Esc 收起。隐藏的新对话菜单不会阻止信息卡。数据未变化时保留原行，避免刷新打断悬停与键盘焦点。
- 所有行的背景左右对齐，项目行和子对话之间留 3px；子对话仅标题向内一级缩进，背景仍等宽。主对话、固定入口、旁聊 / 项目标题共用行内边距和分组间距。长名称让出右侧操作位；窄侧栏保持单行截断。手机网页和安卓抽屉相同层级、间距和状态优先级；长按首层置顶 / 归档 / 更多，不显示悬停卡。
- 归档成功提供 10 秒撤销，失败使用会话错误提示。左下账户区保留名称、邮箱 / 本机标识、本月费用和额度剩余；设置 Ctrl+,、用量详情、帮助、退出确认。手机界面包设置首页显示用量条；Windows 窄窗设置分类上方不显示账户用量条。
- 公共控件样式在 `controls.css`：Electron（桌面程序框架）及安卓浏览器引擎统一使用 WebKit（浏览器引擎）滚动条伪元素，并把所有元素的标准滚动条属性重置为 auto；否则标准属性会压过伪元素并带回系统箭头。全应用无箭头、透明细轨，悬停滑块加粗。深色菜单 / 下拉 / 信息卡使用高一级表面、细边线与浮层阴影；浅色保持原表面。
- 设置记忆、设备、模型、系统、项目、网页资料、备份列表的刷新为小图标；进入页面自动读取，记忆世界版本变化自动刷新列表。记忆搜索图标在输入框内，回车即搜。手机设置子页顶栏显示分类名称，后台运行设置是带箭头次级行。

### 主对话与旁聊（IA-3 / D42）

- UX-P1：消息操作在悬停、键盘聚焦或最后一条助手回复时显示；主对话旁聊操作合入消息操作行，输入区「+」菜单提供带图标的「开旁聊」。侧栏「新旁聊」右侧下拉提供「新旁聊 / 临时对话」；记忆开关显示勾选，自动删除期限在子菜单里单选。加载更早内容与日期行统一为居中次级按钮。
- 手机主对话的搜索 / 日期图标工具行参与页面布局，搜索输入、前后结果、计数、更多和关闭在单行完成；输入区状态提示置于输入卡片上方。桌面与手机搜索高亮分别使用浅深颜色令牌，文字对比度至少 4.5:1。
- 记忆默认全部类型，顶部类型筛选与搜索，列表显示类型、状态、更新时间和可定位的来源对话；正常健康行显示形成数量和队列，异常显示原因、积压与详情。过去对话整理使用确认卡片，开始后显示进度及暂停 / 取消。
- 首次引导模型测试通过后由底栏「继续」保存并前进，内容区单独滚动且不被底栏覆盖；第一句话示例使用可点击建议卡片。正文浅深主题统一 400 字重，字体回退不合成额外粗体。设置分组标题为「模型与能力」，「个性化」使用编辑图标。

- 账户主对话固定在侧栏最上方，头像与名称为 WeftMate，不提供归档、删除或分组菜单；普通旧对话列为旁聊，保留 UX-2 的悬停、置顶、分组和项目行为。动态、目标、成果库的固定入口由 TB 包接入，本包预留隐藏导航。
- 主对话按账户时区分日，旧日默认折叠，显示条目数；日期选择和主对话内搜索定位原消息，结果摘要也能高亮。保留全部历史，旧页按需读取，正文只挂载视口附近，跳转及插入以消息身份和像素偏移保持位置。
- 消息菜单可从完整消息开旁聊，输入区可转入草稿和附件；来源可返回原消息。仅引用转移显示“相关上下文尚未带入”。结果用成功 / 失败 / 停止的一行摘要与打开箭头，不把停止表示为成功。
- 主对话首发可选择模型；已有主对话沿宿主当前模型。当前契约没有独立换模型路由，不把更换选择当作已经切换。原生单会话用量入口不在主对话冒充跨段总量；账户用量仍在设置里。
- 窄窗保留 WeftMate 标题，输出与来源使用既有图标；日期选择后收起，不覆盖正文。搜索、审批、问题和停止支持原键盘操作，搜索定位聚焦原消息，虚拟列表重绘保留聚焦控件。

### 项目 / 文件夹（D37）

- UX-9：尚未发第一条消息的旁聊，在输入卡片下方左对齐显示执行电脑、文件夹与添加文件夹三枚胶囊，一行不换行；主对话隐藏此行。首次无项目显示可关闭的轻提示，不阻挡输入，也可不选文件夹直接聊天。首次引导「第一句话」复用同一控件。
- 文件夹菜单列最近使用的 5 个项目（路径末两级与权限）、系统选择其他文件夹、不使用文件夹。偏好按账户 / 宿主保存在本设备；项目中新建继承项目，从其他位置新建沿上次选择，包括明确不使用文件夹。
- 「+」菜单在添加文件下面提供带图标的「选择文件夹」。系统选择 / 拖放目录匹配现有项目时直接归入；新目录使用就地小确认卡，包含名称、只读 / 可读写（默认只读）、完整路径与高风险位置警告。确认走已有项目登记，权限继续受审批设置约束。
- 已有内容的项目对话，在「+」右侧、审批模式前显示文件夹胶囊；悬停显示完整路径与权限，点击统一菜单：在文件夹中显示、权限单选、换文件夹、移出项目。草稿和附件保留，旧对话移动只从下回合生效。主对话选择文件夹沿开旁聊创建项目旁聊，并保留可返回的引用；临时对话的成果隔离规则不变。
- 手机 / 远程网页「选择电脑上的文件夹」只列电脑上已登记的项目、路径末两级与权限；底部说明新文件夹请在电脑上添加，离线禁用。执行胶囊显示实际电脑名与在线状态；添加按钮禁用并提示在电脑上添加。目录拖放由原生路径判断，文件（包括零字节文件）仍是附件。


- UX-2：项目内默认展示最近 5 条，多于 5 条显示「展开显示（N）」；N 是尚未显示的条数，展开后可「收起对话」。展开偏好按账户与项目保存在本设备，搜索时显示全部匹配项，不改展开偏好。手机网页与安卓界面包同样处理。

- 对话列表下方新增「项目」区：现有 folder（文件夹）图标 + 名称，展开列出该项目对话；每行可新建对话，电脑提供项目设置。普通对话仍按 D34 分组，置顶不把项目对话移出项目。
- 新建项目使用对话框：电脑文件夹（Electron〔桌面程序框架〕提供系统选择框，路径只读）、名称（默认文件夹名）、项目说明、只读 / 可写权限。新界面默认可写；旧登记与旧客户端未给权限时默认只读。项目说明固定带入每个回合。
- 项目设置可改名称、说明、权限；移除确认明确「只移除项目登记，不删除文件夹里的任何文件」，对话保留并从下个回合使用独立目录。执行中的项目不能修改设置或移除。
- 对话菜单并列「移至项目 ›」与「移至分组 ›」；项目与分组互斥。移动空闲对话后在对话里提示「从下一回合使用项目文件夹，之前的文件与经验留在原目录」。会话 / 项目只改变来源与上下文，不改变长期记忆世界。
- 手机远程网页和 Android（安卓）界面包只呈现项目名与对话，不浏览电脑目录；项目内新建对话先选择电脑模型，任务在电脑执行。所有操作使用既有账号授权、审批与回执恢复。
- 使用共享设计令牌与 design/icons/ui/folder.svg；浅 / 深色与窄窗口沿用侧栏、菜单和对话框规则。旧「项目与成果」的项目登记并入侧栏；网页资料任务与成果仍沿用各自入口。

### 右侧面板（本人 2026-10-08，参照 Codex 桌面版）

- 对话标题栏右侧一个「输出与来源」按钮，点开为小浮层，分两组：
  - **输出内容**：本对话生成的文件 / 网页 / 成果，逐项列出；空时显示一行灰字提示。
  - **来源**：本对话用到的网页、读过的文件、引用的记忆、调用过的工具 / 连接器，逐项列出；末尾「查看全部」。
- 点选任一项，在右侧面板以**标签页**打开（标签显示图标 + 名称，可单独关闭；标签栏「+」从同一列表再开一项）；面板可拖宽、可放大、可整体收起。
- 来源条目点开显示该来源在本对话里的使用摘要（如「读取 3 次」「引用 2 次」），再点进具体内容；成果条目直接预览，可下载 / 用默认程序打开 / 在文件夹中显示。
- 成果卡、「用到了 N 条记忆」标签、步骤里的文件 / 网址，点击都在这个面板的新标签里打开。
### 时间线元素

| 元素 | 规则 |
|---|---|
| 用户消息 | 右侧气泡或简洁块；附件缩略图 |
| 助手文字 | Markdown 渲染；流式输出 |
| 工作指示 | D35：首次出字 / 工具前，真实加载模型、排队、读取记忆、思考阶段用对话内灰色单行；出字或开始工具后消失。计时并入阶段行；输入框上方仅保留审批 / 提问 / 排队条目与停止入口 |
| 工具步骤 | D35：对话内灰色小字 + 右侧箭头，按真实事件顺序与正文穿插。连续步骤合并成一组：「读取了 3 个文件」「运行了 2 条命令」；组可展开，展开后每步一行可读描述，再点开看原始命令与输出（等宽字体、可复制）。默认收起；运行时显示当前步骤和简短对象，轻微文字 / 省略号动效；结束按种类计数，如「已运行 5 个命令」「读取了 2 个文件、搜索了 1 次」。展开后才出现细边框圆角列表，流式重绘保留组与各步展开状态；Enter / 空格可操作，读屏报「已收起 / 已展开」。失败警示色「第 N 步失败」，默认展开该步；已停止仍可见。纯文字回复不显示工具行 |
| 计划 / 待办 | 模型维护的待办清单就地显示，随进度打勾 |
| 审批条 | D35：输入框正上方状态条改为审批条，一句话工具 + 对象（如「要运行命令：npm test」），详情展开完整参数 / 影响范围 / 能否撤销。右侧批准 / 拒绝；批准即现有允许一次，原审批模式和同类权限仍走原接口（同类允许放详情内）。多个待批一次显示一个并提示「还有 N 个待批准」。按钮均键盘可达，Enter 只有焦点在批准按钮时才批准。有效回执后当前审批立即消失，下一项或普通状态条接替；对话流不放审批卡，仅步骤列表记「已批准 / 已拒绝」。连接失败或答复不确定仍提示核对并复用原请求 |
| 提问条 | UX-1：输入框正上方与审批条共用待处理位置；审批优先，审批条提示还有几个问题，处理后显示提问。每次一个问题，一句话 + 单选 / 多选按钮 +「其他…」输入；完整说明按需展开，提示「还有 N 个问题」。同批逐题填写，最后一题按原契约整批提交；有效回答回执后立即消失，对话原位置只留一行「已回答：…」。输入框回车不提交，提交按钮聚焦时回车提交；不明确的回执保留填写内容并重试原请求。Windows / 手机网页 / 安卓界面包已接入，Apple 待专包 |
| 成果卡 | 独立放在进展行下方，不能折叠进步骤；文件名、类型、大小与「已读回核验 / 仍待核验」；点击在右侧面板打开；可下载 / 在文件夹中显示 |
| 错误 | 一句话说清发生了什么 + 下一步（重试 / 换模型 / 去设置）；不显示原始异常 |
| 排队 | 运行中再发新目标 → 显示「排队中」卡片，可取消 |

### 消息内容渲染（UX-5）

Windows（视窗系统）程序、远程手机网页和 Android（安卓）界面包的用户消息、助手回复、Markdown（标记文本）成果预览共用 `src/ui-core/rendering.js` 与离线解析包。

- 标题、嵌套有序 / 无序 / 任务列表、引用、分隔线、粗斜删、行内代码、脚注；长英文和网址换行。HTML（网页标记）原文转义，不执行脚本、事件属性或用户样式。外链有标记，通过系统浏览器 / 浏览器新标签打开；已登记成果按身份显示文件卡片。链接卡片只使用宿主已有标题，不额外抓网页。
- 代码头显示语言；悬停 / 键盘聚焦显示复制与换行，触屏直接显示。超过 30 行默认折叠，显示总行数并可展开；代码横向滚动限于块内。浅深高亮颜色来自设计令牌。增量更新保留未变化的块、代码控件和滚动位置，未闭合代码围栏仍显示代码。
- 表格保留对齐、表头和斑马线，窄屏横向滚动，不挤压列；块内纵向滚动时表头吸顶。可复制为 Markdown 或 CSV（逗号分隔值）。
- `$…$` / `$$…$$` 由离线 KaTeX（数学公式排版库）渲染；失败保留带定界符的原文。Mermaid（图表语法）使用官方 Tiny（精简版）本地包，进入视口再加载，图与源码可切换；不支持的图型 / 不安全语法 / 解析失败显示源码。
- 光栅图片缩略图支持同消息画廊、上一张 / 下一张、缩放、下载；已登记图片成果的桌面画廊可在文件夹中显示。加载失败有占位。SVG（矢量图）消息输入只当原文，不作为可执行图像。
- PDF（便携文档）沿用既有本地预览。Office（办公文档）本步提供默认程序打开降级卡片；远程页面提示在电脑打开，不假装已经提供格式预览或下载路由。
- Markdown 导出保留原文与已有脱敏边界；PNG（图片文件）导出使用同一渲染内容，保留代码高亮、表格和公式，展开代码与表格，不把界面操作按钮导入图片。

Apple（苹果端）按相同呈现行为接线；本步只更新共用设计令牌，原生实现另交工作包。桌面实际流式正文交付时机仍由宿主现有事件决定，渲染包不新增消息或续传契约。

## 6b. 登录与设备（D29；细节参照 Codex / Claude 等多端 App 的通行做法）

### 登录页（电脑程序、手机、网页的第一页）
- 中间一张简洁卡片：C4 标志 + 「登录 WeftMate」；邮箱、密码（可显示 / 隐藏）、「登录」主按钮；下方「忘记密码？」「还没有账号？注册」。只做账号的事，不出现配对码、电脑地址、直连。
- 错误就地提示一句话：邮箱或密码不对、网络不通（可重试）、尝试太多次（显示还要等多久）。不说明「邮箱是否存在」。
- 底部次要入口「离线使用这台电脑」（只在电脑程序里，云不可用时的应急本地登录）。
- 登录成功后记住本设备，下次直接进入；令牌过期自动续期，续不了才回登录页并保留草稿。

### 注册与设置密码
- 邮箱 → 「发送验证码」（60 秒后可重发，显示倒计时）→ 输入 6 位验证码 → 设置密码（至少 8 位，两次一致，显示强度提示）→ 设备名称（默认取电脑 / 手机名称，可改）→ 完成并自动登录。
- 页面底部一行「注册即表示同意《服务条款》《隐私政策》」，内容见 `docs/legal/terms-zh.md`、`docs/legal/privacy-zh.md`，App 内可直接打开阅读。
- 忘记密码：邮箱 → 验证码 → 设置新密码 → 回到登录页并预填邮箱。重设密码后其他设备不受影响（与 CLOUD.md 一致：不解锁备份、不顺带撤销设备）。

### 新设备等待批准（D23）
- 登录成功但本设备还没被批准看内容时，显示等待页：「在你已登录的设备上允许这台设备」，列出可以批准的设备名称；或「用已登录的手机扫这个二维码」。可取消、可换账号。批准后自动进入，不用重新登录。
- 已登录设备上：顶部出现一条提示「新设备 iPhone 15 请求访问」→ 允许 / 拒绝；也可在设置 → 设备里处理。

### 设置 → 账户
- 邮箱、「换绑邮箱」（输入新邮箱 → 新邮箱收验证码 → 完成，旧邮箱收到「邮箱已更改」通知）、修改密码（先输入当前密码，再设置新密码）、退出登录、「退出所有其他设备」、「注销账号」（输入密码确认；确认框写明：云端账号数据全部删除且不可恢复，本机的对话与记忆仍留在设备上）。
- 不做手机号验证。

### 设置 → 设备
- 列表：本账号已登录的所有设备，每行图标（电脑 / 手机 / 平板 / 手表 / 浏览器）、名称、在线状态、最近使用时间；本机标「这台设备」；电脑类设备标「可执行任务」。
- 每台设备可：改名、移除（该设备立即退出，需确认）；电脑类设备可「连接」：已受信设备直接连；新设备扫电脑上显示的二维码配对（没相机时输入配对码作为备用）。
- 电脑上：「添加设备」显示配对二维码（2 分钟自动刷新）；「待批准」区显示请求访问的新设备。
- 「共享给其他账号」（S5）：对方出示二维码，由本账号的主设备扫码确认后才建立共享；对方不能单方面连接。

### 多端一致
- 电脑程序、手机 App、网页、iPhone / Mac 用同一套流程和文案；Watch 不登录，跟随已配对的 iPhone。
- 一台设备同一时间只登录一个账号（D30），不做多账号切换。

Apple 实现备注（LG-2）：登录 / 注册 / 找回页面与账户 / 设备设置分离；密码、验证码与密码票据不持久化，令牌失效沿用原账户草稿保存流程。正式服务当前仍按 CLIENT_API 7.1 校验 15–128 位密码；8–14 位虽然通过本页客户端初检，服务拒绝时显示实际长度要求。此处记录实现与服务的差异，不修改上面的至少 8 位规格；服务器轨道需统一密码规则。

## 7b. 动效与精修（D28）

- UI-P1m 手机实现备注：沿用桌面 `base`（200 毫秒）、`fast`（180 毫秒）、`160ms`、`240ms` 与 `exit`（120 毫秒），统一 `desktop` 曲线；全屏来源页 / 会话 / 登录步骤按方向切换，抽屉进入 240 毫秒、退出 120 毫秒。新步骤按身份错开 `stagger`（24 毫秒），总延迟最多 `staggerLimit`（60 毫秒）；步骤与排队卡超过 20 项直接显示。布局立即完成，返回保留草稿和滚动，退出副本不可交互；浏览器与 Android（安卓）系统动画缩放为 0 均瞬时显示，运行中修改也生效。[手机前后连续帧与性能记录](../tests/evidence/ui-p1m/README.md)。

- UI-P1 桌面实现备注：执行块展开、审批卡与页面 / 登录步骤切换使用 `base`（200 毫秒），新步骤、排队卡和标签 / 列表使用 `fast`（180 毫秒），面板进入使用 `240ms`，消息块 / 记忆标签和发送 / 停止反馈使用 `160ms`，退出使用 `exit`（120 毫秒）；统一 `desktop` 缓动曲线。步骤错开 `stagger`（24 毫秒），总延迟最多 `staggerLimit`（60 毫秒）；超过 20 项直接显示。布局一次到位，退出副本不参与布局或交互；系统减少动态效果时全部瞬时，并响应运行中偏好变化。现有消息块按收到的粒度平滑淡入，不添加逐字播放或传输功能。[真实程序前后连续帧与性能记录](../tests/evidence/ui-p1/README.md)。

- UI-3 实现备注：审批卡和工具来源先显示共享功能层的人话摘要，原始参数收在「详情」；输出列表显示同路径最新版本，预览里可展开已读取的旧版。

- 界面与功能分层：功能（连接、会话、发送、审批、成果、记忆、设置）只在功能层实现一次；界面组件只负责摆放与样子，调整布局或挪动组件不得改动功能层。测试按可见名称与角色找元素、断言行为，不依赖位置。
- 所有颜色、字号、间距、圆角、阴影与动效参数来自 `design/tokens/`（DS-1 建立后），各端不写死数值。
- 动效原则：短（大多 150–250 毫秒）、跟手、有意义（表达展开、出现、完成），不做装饰性循环动画；系统开启「减少动态效果」时改为淡入淡出或无动画。
- 需要动效的位置：执行块展开 / 收起、步骤逐条出现、审批卡出现与处理后收成一行、右侧面板开合与标签切换、会话列表与页面切换、发送↔停止、流式文字、记忆标签出现。具体参数在 UI-P1 定稿后写回本节。
- 精修按第 9c 节分轮进行，每轮本人确认后合并。

### M3-A 手机离线模式（D13 / D39）

- 电脑连接中断且已有加密副本时，进入离线对话；顶部「离线模式」，输入区明确「电脑离线，只能聊天和用记忆，不能操作电脑」。保留返回和新对话；原电脑任务不会在离线模式伪装为已执行或已排队。

### TB-1 动态实现备注（D43）

### UX-P2 控件与异常状态

输入框从一行随内容增高，最多约八行后内部滚动，删空后回缩；其他多行编辑区固定高度内部滚动，不显示原生缩放把手。所有可滚动区域使用 `controls.css` 的共用浅 / 深无箭头细滚动条令牌；菜单自适应高度，不足时才滚动。

未配模型时，空对话中央显示模型图标、说明和「设置模型」主按钮；有历史则在输入区正上方显示统一提示条。输入禁用并显示「先添加一个模型」。不在标题栏上方加提示。

记忆导出收进刷新旁的更多菜单，类型筛选与搜索留出间距，来源对话采用图标链接。形成失败与纠正未生效合并到记忆健康提示组件：图标、数量、「查看」，展开后显示原话、时间、来源与「重试」；对话中的对应回合使用同一提示条样式。
