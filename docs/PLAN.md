## 2. 验收场景：「做完」的定义

在**候选安装包**上跑：Windows 安装包和安卓 APK，用合成账号和合成数据。本人在场时，可以再用本人的安装版只读核对。每个场景记录安装包版本、设备、日期和结果（通过、失败、阻塞、未测）；失败的附一句现象和对应的 PR 或问题单。截图放仓库外的证据目录。本机清单（例如 `MAIN-PATH.md`）里有、这里没有的场景，补进本节，再删掉本机那份。

**聊天问事**
- C1 全新安装 → 注册或登录 → 填一个模型服务 → 发一句话，收到回答。Windows 和安卓各一次；安卓不连电脑也要能做完（D61）。
- C2 模型服务填错或者断网：一句人话说清发生了什么、点哪里能修，不一直显示「正在连接」。
- C3 回复进行中再发一条：按设置排队（D36）；停止按钮立即生效。
- C4 打开一个有上千条历史的对话：先显示最新内容，往上滑加载更早的。

**让电脑干活**
- W1 在「工作」里选电脑和文件夹，让它把文件夹里的文件按类型分到子文件夹：步骤在对话里能看懂，成果能打开（D5、D6）。
- W2 需要批准的操作（例如删除一个文件）：批准一次、拒绝一次，都按选择执行；手机上设了「每次询问」时，电脑必须先问（D12）。
- W3 在「对话」里提出要电脑做的事：出现「切换到工作」卡片，选好电脑和文件夹后，在原对话里接着做（D92）。
- W4 从安卓交给电脑：手机发起，电脑执行，手机上看进度、批准、拿到结果。
- W5 电脑离线时从手机交代：先排队，电脑上线后执行并通知；排队期间可以取消（D17、D40）。

**记住我的事**（规则见 [MEMORY.md](MEMORY.md)）
- M1 说「记住我喜欢喝红茶」→ 开一个新对话问「我喜欢喝什么」→ 答对。
- M2 说「我其实更喜欢绿茶」→ 新对话里按纠正后的说法回答。
- M3 在记忆页忘掉这一条 → 新对话里不再知道，记忆页里也没有；聊天原话默认保留（D33）。
- M4 换一个模型以后仍然记得（D4）。
- M5 安卓不连电脑单独用时做 M1；连上电脑后不出现两套记忆（D63）。
- 记忆要在两种环境里跑：全新安装，以及接了 MemoWeft 的环境（见 MEMORY.md 规则 1）。

**健康与提醒**
- H1 说「5 分钟后提醒我喝水」→ 到点收到通知。Windows 和安卓都要；安卓应用在后台时，界面要说明可能延迟（D41）。
- H2 安卓健康页：有数据时显示今天的数据；没有数据来源时，说清缺什么、加上以后能得到什么，不挡路。
- H3 在对话里问「我这周睡得怎么样」：回答用的是已同步的健康数据，没有数据就如实说。
