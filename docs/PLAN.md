## 2. 验收场景：「做完」的定义

在**候选安装包**上跑：Windows 安装包和安卓 APK，用合成账号和合成数据。本人在场时，可以再用本人的安装版只读核对。每个场景记录安装包版本、设备、日期和结果（通过、失败、阻塞、未测、不适用）；失败的附一句现象和对应的 PR 或问题单。截图放仓库外的证据目录，手机截图带系统栏、电脑截图带窗口标题栏。各端候选对应同一个主线提交，云端记录实际部署版本与兼容性；没有改动的端也写清所用版本。模拟器不能验证的项目写「阻塞：需真机」，不算通过。本机经典 Windows 沙盒不可用时（2026-10-18 起报 0x800706d9），Windows 候选改在本机用独立安装身份（独立 appId、安装目录、数据目录）全新安装，结果注明「本机独立安装，非干净沙盒」；干净机器上的默认安装另找机会补验。下列苹果场景留到阶段 3 执行。

验收场景只维护在这里。任何适用的主路场景失败或阻塞时，保留具体问题，不能报告这一轮已经验收通过。

**聊天问事**
- C1 全新安装 → 进入可使用的程序 → 填一个模型服务 → 发一句话，收到回答。Windows 和安卓各一次；安卓不连电脑也要能做完（D61），本机使用不强制云登录（D93）。需要云功能时在程序内注册或登录，登录后账户页显示实际云账号；新增模型服务后立即可用。
- C2 模型服务填错或者断网：一句人话说清发生了什么、点哪里能修，不一直显示「正在连接」。
- C3 回复进行中再发一条：按设置排队（D36）；停止按钮立即生效。
- C4 打开一个有上千条历史的对话：先显示最新内容，往上滑加载更早的。
- C5 冷启动不滞留登录、设备页或「正在连接」；结束程序后重开，原登录状态、对话和模型配置恢复。
- C6 回复生成到一半切到其他页面，再返回时正文完整；Windows、安卓以及后续苹果轮分别检查。
- C7 每隔约 1.5 秒连发三条：三条输入都保留，并各自得到对应回复，不丢字、不丢条。
- C8 一端的对话在另一端可见并能接着聊，保持原对话和历史；新建对话、切换模型可用。
- C9 手机软键盘打开时点输入区控件，键盘不意外收起；模拟器未显示真实软键盘时明确留待真机。
- C10 回复进展收成正文下方的一行，展开可查实际步骤；标题使用与对话相同的语言。

**让电脑干活**
- W1 在「工作」里选电脑和文件夹，让它把文件夹里的文件按类型分到子文件夹：步骤在对话里能看懂，成果能打开（D5、D6）。
- W2 需要批准的操作（例如删除一个文件）：批准一次、拒绝一次，都按选择执行；手机上设了「每次询问」时，电脑必须先问（D12）。
- W3 在「对话」里提出要电脑做的事：出现「切换到工作」卡片，选好电脑和文件夹后，在原对话里接着做（D92）。
- W4 从安卓交给电脑：分别创建一个文件、读取一个文件夹、运行一条命令；核对电脑上的实际文件、读取结果与命令执行结果，手机上能看进度、批准并拿到结果。
- W5 电脑离线时从手机交代：先排队，电脑上线后执行并通知；排队期间可以取消（D17、D40）。
- W6 已有工作所属电脑离线时，手机明确说明电脑不在线，保持原电脑归属，不一直转圈；在线后的接续与 W5 排队任务分别检查。

**记住我的事**（规则见 [MEMORY.md](MEMORY.md)）
- M1 说「记住我喜欢喝红茶」→ 开一个新对话问「我喜欢喝什么」→ 答对。
- M2 说「我其实更喜欢绿茶」→ 新对话里按纠正后的说法回答。
- M3 在记忆页忘掉这一条 → 新对话里不再知道，记忆页里也没有；聊天原话默认保留（D33）。
- M4 换一个模型以后仍然记得（D4）。本人 2026-10-16 定：这一轮先不测，记「暂缓」。
- M5 安卓不连电脑单独用时做 M1；连上电脑后不出现两套记忆（D63）。
- M6 在手机告诉它一个偏好，换到电脑的新对话仍能想起；从电脑形成的记忆在手机的获准使用路径也能采用。
- M7 在对话里让它忘掉同一偏好：确认实际删除成功后再报告完成；新对话不再知道，记忆页和来源接口不再返回被删的记忆正文，原聊天按 D33 保留。

**健康与提醒**
- H1 说「5 分钟后提醒我喝水」→ 到点收到通知。Windows 和安卓都要；安卓应用在后台时，界面要说明可能延迟（D41）。
- H2 安卓健康页：有数据时显示今天的数据；没有数据来源时，说清缺什么、加上以后能得到什么，不挡路。
- H3 在对话里问「我这周睡得怎么样」：回答用的是已同步的健康数据，没有数据就如实说。
- H4 后续苹果轮：iPhone 读取已授权的 HealthKit（苹果健康数据接口）样例，睡眠问答能采用这些数据，Watch 显示对应内容；权限、配对和后台行为按真实设备另验。
- H5 说「明天 9 点提醒我 X」→ 在目标页可查看、删除，到约定的本地时间收到通知；新建一个长期目标能显示真实进度。到点通知在各自适用端核验，不能用保存成功代替通知已收到。
