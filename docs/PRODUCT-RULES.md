# 产品规则

> 本人定下的、现在有效的产品规则。编号沿用原表，代码注释里的 `Dxx` 在这里查。
> 这里只写产品该是什么，不写怎么干活。11-03 定下的跨设备数据层和手表方向是后续交付目标。

## 方向

- **D118** 自用优先。取舍和验收以本人的日用版与数据为准。发布用来分享产品和理念。本人不提供面向他人的托管服务。
- **D119** 各端都能独立使用。电脑负责代码和文件，手机可独立问答，也可指挥在线的电脑。各端可共用模型配置。电脑可使用手机共享的健康等信息。一台设备关机时，其他设备仍可用自己的模型和已共享的数据。
- **D4、D45** 模型由用户自带，不绑定、不代付：本地模型或任意 API。引导里内置常用提供方预设。同一场景 API 模型过、本地模型不过，算模型能力。用量预算保留（本人 2026-11-01）：云端模型到本月上限就暂停发送并说明原因，本地模型不受限。
- **D87** 选定回答设备后，模型自己用通用能力办事，不按程序名或用户句式写专门分流。
- **D99** 本人日常用 iPhone、Apple Watch、Windows、安卓（一加 13）和 Mac。
- **D115** 本机日用与测试分开：本人日用的安装和数据只归本人，测试用独立身份和合成数据。修完的 Windows 版本直接推到 weftmate.com 的更新目录（只放文件）；只改界面的走界面包热更新。仓库公开，密钥、密码、令牌不进仓库、PR 和 issue。

## 界面

- **D125** 前端一份规格、各端原生呈现：页面清单、交互和令牌只定一次，各端用自己平台的控件画。加功能、加页面和上线都按 [FRONTEND](FRONTEND.md)（本人 2026-10-31）。
- **D27** 桌面是独立程序（窗口、托盘、通知、开机自启），界面代码和远程网页共用；界面改动在真实程序里看。
- **D92** 对话与工作两种模式：对话只聊天、问问题、查资料和自己的记忆；工作绑定一台电脑和一个项目或文件夹，选好才能发首条，不能切回对话。不要主对话（本人 2026-11-01）：各端不再有主对话入口和发送通道，旧主对话只作普通历史查看。没指定对话的提醒和定时任务固定发进一个「提醒」普通对话，被删了下次再建（本人 2026-11-03）。
- **D124** 前端可以重构、全部页面可以重排，保留功能和两种模式；只取 Claude / Codex 桌面版那种紧凑、顺手、过程和回答分得清、切换不闪的感觉。每轮回复过程在上、回答在下，不显示「参考了 N 条记忆」。安卓和 iPhone 的界面也按这个标准重构：iPhone 照 `design/ios/` 已认可的设计；安卓现在先做，对话界面和流式输出参考 zafiro（本人 2026-10-31）。
- **D124（续）** 2026-10-27 起整体视觉和交互以小米 MiMo 桌面版为参照，右侧有审查、终端、浏览器、文件、侧边聊天、子任务六项面板，都要真能用；只学布局、交互和职责划分，代码、图标、文案自己写。
- **D28** 颜色、字号、间距、圆角、阴影、动效时长和曲线只从 `design/tokens/` 取，图标只从 `design/icons/` 取，各端生成。动效用 5 个时长、4 条曲线，页面和弹层用 `--dur-3` / `--dur-4`。
- **D64** 现在的界面是基准，原生不能更差。**D65** 深色用中性灰，浮层半透明磨砂。**D90** 图标自己画。**D60** 记忆图标是书签。**D14** 外观用户可以改。
- **D5、D6、D35** 一切在对话里执行和查看：步骤显示人话，运行中展开、完成收成一行；待批准的操作在输入框上方，一次一项。
- **D7、D36** 同一对话可以连续交代，按顺序排队；回复进行中发的消息默认排队，设置里可改成引导。
- **D49** 自己发出、模型已处理的消息不能编辑重发；还在排队的可以改或撤回。
- **D31** 设置统一结构：桌面左边分类、右边逐行「名称 + 说明｜控件」；手机列表推子页。**D34** 对话菜单：置顶、未读、重命名、分叉、分组、归档、删除；已归档放在设置里。
- **D51** 回复结束后给 0–3 条下一步建议，点选只填草稿。**D53** 侧栏最上面是搜索，Ctrl+K 打开。**D55** 对话行状态位：待批准橙点 > 运行转圈 > 失败红点 > 完成蓝点。
- **D56** 手机底部五项：聊天、动态、健康、目标、成果库。

## 执行与审批

- **D2** 工作模式下给模型完整的命令行、文件和浏览器能力，危险操作才审批。**D12** 审批模式可选：自动（推荐）/ 每次询问 / 自动接受文件修改 / 先出计划 / 全部允许。
- **D11** 做事的经验属于那段对话；长期记忆跨对话共享。**D37** 项目就是电脑上的一个文件夹，可设只读或可写。
- **D13、D39** 电脑离线时，手机可用账号里的云端模型聊天、查询已同步的记忆。电脑本地运行的模型须等该电脑在线才能用。**D17、D40** 需要电脑执行的任务遇到电脑离线，当场告知当前做不了，不建立待执行任务。恢复连接后由本人决定是否再发。在线指令沿用实时中继。

## 记忆

- **D120** 电脑用 MemoWeft 按原则形成记忆，梳理人物关系和事件脉络，按语义召回并附原话。手机只提取明确的事实和偏好，按关键词和时间查找。手机提取后立即可用，电脑完整处理同一段对话后，用电脑结果替换该段手机稿，替换时遵守已同步的遗忘标记。只用手机时，手机稿就是正式记忆。跨对话能想起、改口能纠正、要求忘记能真删掉，仍是验收标准。
- **D16** 删除对话时，从中形成的记忆默认保留；确认框可勾「同时忘掉从这段对话形成的记忆」。**D33** 忘掉一条记忆时，确认框可勾「同时删除对话里含这句话的原话」，默认不勾，并先列出一起被忘掉的相关记忆。
- **D106、D110** 安装包自带受管 Python、MemoWeft 和完整语义组件，用户不用装开发环境。

## 账号、设备与云

- **D93** 单机使用无需密码。使用账号服务器时，可用账号密码或邮箱验证码登录。账号资料也保存在本地。
- **D20** 本人使用自管服务器保存完整加密副本，设备直连作备用。服务器负责登录、校验设备签名、中继、推送和保存密文，内容只在设备上解密。也可选择同网直连与自有网盘，网盘只需能存文件。
- **D23** 一个账号由一组设备和一把数据钥匙组成。第一台设备在本地生成钥匙，其他设备扫码入组，网盘配置随入组传递。**D24** 允许普通浏览器经中继远程访问。**D25** 用登录密码在本机锁住数据钥匙，服务器保存加密后的钥匙，新设备输入密码后在本机解锁。忘记密码就无法靠服务器解开已有密文，账号钥匙不设恢复码。
- **D80** 一台电脑可以有多个账户，记忆和数据完全隔离。**D30** 不支持同设备多账号同时登录；可以注销，注销删除云端数据；不做手机号验证。**D21** 邮箱验证用于注册、找回登录和换绑。邮箱找回登录不能恢复数据钥匙。
- **D26** 邮件先用 Resend 免费版；域名 DNS 在阿里云，解析记录和证书密钥由本人配置。
- **D41** 安卓不显示常驻通知，进程挂起后靠周期检查补发（可能延迟）。**D38、D47** 苹果端先用免费 7 天签名，发布前一个月再开通开发者计划。

## 跨设备数据层

先用钥匙和扫码把设备连成一个账号，再依次交付目录、记忆与设置同步，正文与附件按需拉取，服务器完整加密副本，手机提取记忆，以及手表按内容分配任务。

- **共享范围**按整台设备选择。开启后可共享本设备的 WeftMate 数据。关闭后，本设备的数据不参与同步，其他设备也不能指挥它。单段对话仍可选择“这段别记”。
- **同步内容**分两类。对话目录（标题、时间、所在设备）、记忆、设置和模型密钥全量加密同步。各端使用通用的正文格式。正文和附件点开时才拉取，先查服务器或网盘，那里没有才需要来源设备在线。
- **打开对话**时先显示本地内容，输入框等这段对话同步完成再开放。两端离线期间已经产生的消息，重连后按时间合进原对话，不标分支。iPhone 主要在打开应用时同步。
- **删除与遗忘**也随改动同步。每次改动有唯一编号，同一改动经云端、直连或网盘多次到达只算一次，乱序到达也能合并。目录删除优先传播。遗忘保留“别记”标记，离线设备回来时也要应用，避免恢复已删内容。服务器定期清理已遗忘内容的密文。
- **搜索**先查本机已有正文、目录和记忆。正文不全时显示“还有 N 段不在本机 · 同步后再搜”，给出下载大小并建议使用 Wi-Fi（无线网络）。拉取的正文和附件留在本机，可以从“数据与存储”清理本机副本。
- **自有网盘**由本人选定，同一组设备使用同一网盘。电脑可选择网盘客户端的同步文件夹，iPhone 可用 iCloud，安卓可接 Google Drive 或 OneDrive，也可用地址、账号和应用密码配置坚果云 WebDAV（网盘文件访问协议）。

## 手表与精灵（后续目标）

- 手表承接审批和语音对话。按住屏幕大按钮说话，精灵显示“在听”，麦克风旁显示声音动画，松开发送。可从表盘组件进入，支持操作键的 Ultra 机型可将它设为入口。
- 手表按内容选择回答设备。文件、代码、打开电脑软件交给电脑，一般问答交给手机。规则拿不准时再由小模型判断。界面显示谁在回答，本人说“让电脑来”即可改选，电脑离线时按 D17 处理。
- 精灵只动眼睛和嘴，各端共用同一套表情。手表用方脸，电脑用云朵，造型沿用本人的手绘示意。
