# 本人定下的产品规则

只列现在有效的，按分区分节；改哪一块看哪一节。编号沿用原表，代码注释里的 `Dxx` 在这里查。完整的原表（含出处、被取代和冻结的条目）在标签 `archive/2026-10-26` 的 `docs/DECISIONS.md`。本人新提、还没做完的改动见 [OWNER_CHANGES.md](OWNER_CHANGES.md)。

## 方向

- **D118** 先做本人天天用的 Windows 聊天 + 记忆（2026-10-26 已到日用），再按安卓 → iPhone → 手表把其他端做成窗口。验收就是本人用着顺。给谁用（自用还是公开发布）暂不定。
- **D119** 一个大脑、多个窗口：只有电脑上的 MemoWeft 形成、纠正、遗忘记忆。手机、iPhone、手表能单独聊天，存原话，读电脑同步来的记忆；电脑不在线时照样聊、任务先排队，电脑上线后统一整理，遗忘在电脑上做一次再同步。
- **D4、D45** 模型由用户自带，不绑定、不代付：本地模型或任意 API。引导里内置常用提供方预设。同一场景 API 模型过、本地模型不过，算模型能力。
- **D87** 模型自己用通用能力办事，不按程序名或用户句式写专门分流。
- **D99** 本人日常用 iPhone、Apple Watch、Windows、安卓（一加 13）和 Mac。

## 怎么干活

- **D112** 总代理由本人指定，可以是 Claude 或 Codex 会话：拆包、写任务书、派执行者、收结果和合并。**D96** 默认一次只开 1 个执行者，最多 2 个，按文件分开。**D97** 到节点或上下文用掉一半就交接、换新会话。
- **D121** 自动检查全绿、总代理看过就合。审查只挡这次改坏的；偶发失败重跑，同一条连续三次挡合并才修。PR 只跑 Linux 测试和相关的小检查，只改文档的只跑文档检查；Windows 全套和打包启动检查合进 main 后跑，发新版前 main 必须全绿（本人 2026-10-26）。
- **D126** 小修快速通道（本人 2026-10-30）：默认任务只改一个根因、只验相关路径，不跑全量、不重复跑已绿检查；同一失败最多修两轮，超过就停下报告。普通 UI/文案/动效不做安全审查或多轮审查。
- **D127** 2026-10-30 起暂停新功能、旧 PR 和自动发布，先清理执行规则、任务包和工作树；2026-10-31 15:00 交给 Claude，之后由本人给新指令再恢复工作。
- **D122** 工作规矩只写在 AGENTS 一页，只有本人能加。
- **D125** 少防御（本人 2026-10-26）：规矩和任务书写「怎么做」；按分区只读需要的那一页；完成的打标签归档；本人新增的改动单独一页。
- **D108、D111** 记忆由总代理派包；MemoWeft 和 WeftMate 一起维护，问题在内核就在内核修，合进主线后再换固定版本。
- **D115** 本机日用与测试分开：本人日用的安装和数据只归本人，测试用独立身份和合成数据。修完的 Windows 版本直接推到 weftmate.com 的更新目录（只放文件）；只改界面的走界面包热更新。仓库公开，密钥、密码、令牌不进仓库、PR 和 issue。
- **D94** 只在大节点、花钱、账号、不可逆的事上找本人。

## 界面

- **D27** 桌面是独立程序（窗口、托盘、通知、开机自启），界面代码和远程网页共用；界面改动在真实程序里看。
- **D92** 对话与工作两种模式：对话只聊天、问问题、查资料和自己的记忆；工作绑定一台电脑和一个项目或文件夹，选好才能发首条，不能切回对话。旧主对话作为普通历史保留。
- **D124** 前端可以重构、全部页面可以重排，保留功能和两种模式；只取 Claude / Codex 桌面版那种紧凑、顺手、过程和回答分得清、切换不闪的感觉。每轮回复过程在上、回答在下，不显示「参考了 N 条记忆」。安卓和 iPhone 的界面也按这个标准重构，先做 iOS 设计，顺了再移植安卓（本人 2026-10-27）。2026-10-27 起整体视觉和交互以小米 MiMo 桌面版为参照，右侧有审查、终端、浏览器、文件、侧边聊天、子任务六项面板，都要真能用；只学布局、交互和职责划分，代码、图标、文案自己写。
- **D28** 颜色、字号、间距、圆角、阴影、动效时长和曲线只从 `design/tokens/` 取，图标只从 `design/icons/` 取，各端生成。动效用 5 个时长、4 条曲线，页面和弹层用 `--dur-3` / `--dur-4`。
- **D64** 现在的界面是基准，原生不能更差。**D65** 深色用中性灰，浮层半透明磨砂。**D90** 图标自己画。**D60** 记忆图标是书签。**D14** 外观用户可以改。
- **D5、D6、D35** 一切在对话里执行和查看：步骤显示人话，运行中展开、完成收成一行；待批准的操作在输入框上方，一次一项。
- **D7、D36** 同一对话可以连续交代，按顺序排队；回复进行中发的消息默认排队，设置里可改成引导。
- **D49** 自己发出、模型已处理的消息不能编辑重发；还在排队的可以改或撤回。
- **D31** 设置统一结构：桌面左边分类、右边逐行「名称 + 说明｜控件」；手机列表推子页。**D34** 对话菜单：置顶、未读、重命名、分叉、分组、归档、删除；已归档放在设置里。
- **D51** 回复结束后给 0–3 条下一步建议，点选只填草稿。**D53** 侧栏最上面是搜索，Ctrl+K 打开。**D55** 对话行状态位：待批准橙点 > 运行转圈 > 失败红点 > 完成蓝点。
- **D56** 手机底部五项：聊天、动态、健康、目标、成果库。
- **D81** 截图在聊天里直接显示，单个附件最大 1 GB。**D91** 一个模型服务下自动列出全部模型，输入区一点就换。**D82** 手机对话转到电脑优先沿用原来的模型，电脑没有就问。

## 执行与审批

- **D2** 工作模式下给模型完整的命令行、文件和浏览器能力，危险操作才审批。**D12** 审批模式可选：自动（推荐）/ 每次询问 / 自动接受文件修改 / 先出计划 / 全部允许。
- **D11** 做事的经验属于那段对话；长期记忆跨对话共享。**D37** 项目就是电脑上的一个文件夹，可设只读或可写。
- **D13、D39** 电脑不在线时，手机用账户里的云模型聊天、读记忆副本，不能执行电脑任务。**D17、D40** 那时交代的电脑任务加密暂存，电脑上线后自动执行，可以取消。

## 记忆

- **D120** 形成按原则判断，召回语义优先并附原话（MemoWeft E2）。「能用」守三条：说过的事新对话想得起、改口能听进去、让它忘就真删掉。
- **D16** 删除对话时，从中形成的记忆默认保留；确认框可勾「同时忘掉从这段对话形成的记忆」。**D33** 忘掉一条记忆时，确认框可勾「同时删除对话里含这句话的原话」，默认不勾，并先列出一起被忘掉的相关记忆。
- **D106、D110** 安装包自带受管 Python、MemoWeft 和完整语义组件，用户不用装开发环境。

## 账号、设备与云

- **D93** 本机使用不用密码，用到服务器（远程、跨设备、云备份）才登录；账号 + 密码或邮箱验证码都能登。
- **D20** 轻云：对话、记忆、健康数据留在自己的设备上，服务器只做账号、中继、推送、加密备份，看不到内容。
- **D23** 新设备要看内容，需在已登录设备上批准或扫码。**D24** 允许普通浏览器经中继远程访问。**D25** 备份钥匙只在用户手里（恢复码或已登录设备）。
- **D80** 一台电脑可以有多个账户，记忆和数据完全隔离。**D30** 不支持同设备多账号同时登录；可以注销，注销删除云端数据；不做手机号验证。**D21** 邮箱验证用于注册、找回密码和换绑。
- **D26** 邮件先用 Resend 免费版；域名 DNS 在阿里云，解析记录和证书密钥由本人配置。
- **D41** 安卓不显示常驻通知，进程挂起后靠周期检查补发（可能延迟）。**D38、D47** 苹果端先用免费 7 天签名，发布前一个月再开通开发者计划。

- **D32** 更新分三层：界面包热更新（下次打开生效）、程序本体差分更新（重启生效）、服务端滚动发布；只接受签名正确且兼容的版本，失败回到上一版。
- **D46、D83** 中英文；Windows、Mac、安卓从 weftmate.com 下载，不上应用商店；官网集中下载、不用登录。
