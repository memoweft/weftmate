# 查资料成文的事实与出处约定（FACT-1）

适用于「查官方资料，再写说明、比较、报告」的文档与研究回复。普通闲聊不附加研究步骤。通过 DSH（助手运行时）的 `web_fetch`、`browser`、`read` / `grep` 取原文，继续使用 DSH 的工具历史与上下文压缩；不另建搜索、检索或答案改写服务。

研究先给简短提纲，限定比较版本和所需问题。关键断言包括版本号、数字、日期、兼容性与「必须／移除／不再支持／需要改用」等结论。每条都要保留原文的主体、条件、例外和对应片段。发布摘要不能自动推导成迁移要求；必要时读它链接的细则。比如 Node.js 本体的编译要求不能扩展成全部原生扩展的要求。

正文以 `[1]` 等编号对应文末「出处」：标题链接、实际访问时间和简短原文片段。时间由网页工具的 `capturedAt` 提供，同一冻结正文的后续查询沿用原访问时间。只有实际读取的内容才可引用。重要问题没有找到证据时，就地写「未在官方资料中确认」；不以模型记忆补出数字，不伪造检索或访问时间。未要求的外围细节可省略。

「设置 → 助手 → 成文前核对事实」默认开启，按账户保存，在下一回合生效。开启时，草稿可留在当前任务上下文；助手使用 DSH 原生 `subagent` 在同一任务内做一次聚焦核对，前台等待结果。只传拟写的关键断言及已读取的编号原文片段、链接、访问时间，不复制全部浏览历史；核对者不联网、不写文件、不再委派。模型自报「已核对」曾仍留下范围错误，因此这里让核对者单独质疑含义、范围和数字，再由原助手修正或降级为未确认，显示「断言 → 原文 → 结论」清单，保存最终稿并读回。子任务不可用时，助手展示同样的逐条自查并说明降级。没有宿主后处理改写答案。

核对只用已取回片段；片段被压缩或缺上下文时，使用 `browser read` 的 `snapshotId` + `query` 或 `sourcePath` 定位冻结正文，不重新全网搜索。关闭只跳过额外草稿自查，出处与诚实表达不确定性的要求保留。发布日志中的中间版本号和后来撤回的提交，不能单独证明发行版最终值；必要的精确常量应读取对应版本标签的官方源码或权威版本表。简短概览不扩展成底层 ABI（应用二进制接口）或全量弃用审计。

回复和成果预览中的官方链接会优先在既有「输出与来源」面板打开本对话读取过的原文。定向查询的片段优先展示，其余读取记录可展开；没有捕获记录的链接沿用地址预览，不伪装成已读取。原文仍由现有会话详情接口鉴权，来源列表不复制原始内容。文档导出后标题链接仍是正常的官方网页地址，原文片段与访问时间也保留在文件中。

这是基于提示、原生工具与可见证据的事实核对流程，不能保证任意模型逐项执行或所有技术断言都正确。宿主不在生成后替模型改写答案。评测分别报告事实错误、判据缺失、出处完整性和核对执行情况，不能把「文件已保存」当作事实正确。

固定主题与判据在 `tests/fixtures/fact-1/topics.json`；真实运行器为 `node tests/integration/fact-1.mjs --phase before|after --model mimo|lan --repeat 2`。改前通过测试专用加载钩子重放固定基线提交的提示与网页返回代码，改后使用当前代码。LAN（局域网）运行仅用 `local-quality`，原子取得 `lan.lock`，批次结束释放；锁占用时退出，由执行者五分钟后重试。凭据只读环境变量，证据不含密钥或私有地址。六主题各两次 MiMo，LAN 抽题可用 `--only node24,node-dep0190 --repeat 1`。证据存 `tests/evidence/fact-1/`。
