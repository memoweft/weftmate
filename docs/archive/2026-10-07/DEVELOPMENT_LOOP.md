## 1. 谁负责什么

用户负责真实需要、优先级、关键取舍、日常体验与最终验收。开发者负责查证、方案比较、可行性验证、实现、自测、具体操作说明、日志整理、定位与修复。

不懂代码不妨碍用户否定一个不好找、不清楚、结果不对的功能。也不能让用户“都测一下”来代替开发自测。已授权本轮范围内的普通文件读取、修改和测试自行完成；超出目标或涉及数据/账号/费用/不可逆操作时才提交关键决定。

## 2. 任务状态只有一个来源

当前任务和状态在 `CURRENT_STATE.md`，过程在 `WORKLOG.md`。默认一次一个活跃任务；可委派窄范围工作，但共享数据/分支所有权需明确。子任务自测不等于独立团队审核。

状态流转：

**未开工 → 进行中 → 开发自测通过／待用户试用 → 用户通过 → 记录后进入下一项。**

遇到报错可为“阻塞”；用户试用失败回到当前任务修复，再交付重测。“待用户试用”不是完成。“未测 / 跳过 / 环境不具备 / 用户未回复”均不算通过。用户只说“收到、知道了”不能写作验收同意；需要实际测试反馈或明确接受具体未测限制。

原型确认只关闭“布局/交互设计”这项，不关闭真实功能。开发进度不使用缺少依据的百分比，不承诺远期工期。

## 4. 开工前必须辨认实际环境

记录当前根目录、候选标识、Git 状态（有才读取，无则写无历史）、当前用户修改、数据位置、固定 DSH 来源与工具链。不要猜 `D:\AIProjects` 必然是用户现在的路径。

原 ZIP + 本累计包能构造独立基线；已有真实工程有新改动时先对比再合并。没有 .git 不能伪造 HEAD；若需新建 Git，由用户明确任务授权，在新目录建立新历史，不声称恢复旧历史。

源码候选、运行配置、运行数据分别保存。试用目录在源码之外，保持重启前后使用同一个已确认测试目录。测试账号、测试设备与日常账号分开；没有明确授权不使用真实私人库。

## 5. 开发过程纪律

从一个用户动作贯穿入口、接口、状态、错误与恢复。现有能力能复用就复用，不为完成任务卡创建没有必要的新框架。新依赖要说明必要性；不默认升级所有包。

保留来源、权限、任务身份和结果校验；不因测试失败而关闭安全门禁、删除断言、清空数据。发现旧用例不匹配，说明是需求变了、环境缺失还是实现错误，保留原结果再修。

模型输出“完成了”不是结果证明；HTTP 成功、进程在线、插件已加载、任务已受理、动作已执行、动作已验证是不同状态。未知、超时、离线、等待用户应显式表现，不静默当空列表或成功。

更新 UI 时先查真实接口，不做假成功按钮。暂不可用显示限制与原因；危险控制必须由确定的执行路径处理，不能依赖模型刚好回复。存在中的操作停止和未来插件加载开关分开。

## 6. 交给用户之前，开发者先完成

至少检查本轮正常路径、一个失败路径、适用的重启/恢复路径，以及受影响的既有功能。GUI（图形界面）相关任务要有实际目标环境或明确可替代环境的可见检查；不能只凭单元测试截图声称 UI 通过。

交付应包含：候选编号与运行目录、实际修改、精确自测命令/环境/结果、未测项、准确入口与 3—5 条用户测试、恢复方法。不能把容器里的 Linux 模拟结果标为用户 Windows 真机结果。

不具备运行条件时可以交付源码候选与静态证据，但状态写“待运行验证”，不能要求用户验收不存在的可运行应用。准备环境所需安装或网络动作说明后在授权范围执行；并不要求用户自行诊断依赖。

## 8. 什么时候可以结束当前轮

当前约定范围的开发检查通过，用户关键试用通过，没有未解释的数据/权限/停止问题，恢复办法可执行，记录已更新。低影响问题可以在用户明确接受具体限制后单列；安全、数据丢失、无法停止、错误来源混淆不能靠一句“先放着”当成通过。

如果用户明确改方向/暂停/放弃，记录决定与保留状态，也可以结束当前任务，但不是“功能验收通过”。不要以固定阶段表压过新的明确用户决定。

## 9. 恢复不是一句“用旧版本”

每轮改变什么就对什么准备恢复：代码保留上一个候选；配置保留原文件；数据变更前有一致性副本和 schema（数据结构版本）记录；外部动作不能假装能撤销。

已发生的数据格式迁移，旧应用不能随意打开新库。先停本次候选，保全诊断，再恢复匹配旧应用的测试数据副本验证。不要覆盖日常库，不用 `git reset --hard`、`clean` 或全盘删除来修复未知问题。

## 10. 收尾与新会话恢复

收尾只更新 CURRENT_STATE 的当前任务/相关缺口，追加 WORKLOG；关键产品选择才写 DECISIONS。记录最后成功/失败操作、候选版本、证据位置、未解决项和下一步，不让下个 AI 重新猜。

上下文长了就以这些实际文件恢复。进入新会话不许重新定义项目、默认旧阶段优先、把计划当已完成、把同意方案当同意外部副作用，也不许说“我永远不会忘记”。
