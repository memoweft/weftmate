# WeftMate 愿景

> 本人确认的产品定义（2026-10-06，2026-10-07 补充）。原文与历史路线见 `archive/2026-10-07/PROJECT_DIRECTION.md`。

## 一句话

围绕同一个人和账号的 AI 助手：跨设备、跨对话、换模型，用户面对的始终是同一个 WeftMate；它能自主办事，也越用越懂你。

## 核心

1. **同一个助手，没有孤岛**：聊天记录、长期记忆、健康资料、任务上下文、做事经验与共同经历，在同一账号的任何设备、任何新对话里都能接上。原对话保留完整现场，新对话也能想起相关内容。换模型只是换能力。
2. **自主办事，不写死**：用户给出完整目标，模型自主规划，用通用工具执行、观察结果、修正计划并继续推进。不为每个应用或任务写死方案；用户举的例子（记事本、计算器、浏览器……）只是方向示意，不限定能力，也不是指定验收样例。模型可以自行积累脚本、工具、Mod 等可复用做法。执行结果如实呈现，用户可随时停止；危险操作才审批，审批结合长期偏好与单次要求。
3. **从日常相处中理解**（MemoWeft）：「发生 → 记住 → 理解 → 想起」。了解用户本人、生活里常出现的人与事、双方讨论过的建议/拒绝/改主意。直接从对话提炼，不逐条弹确认；允许暂时不准，用户指出后更新并影响后续行为。AI 说过的话不等于用户认可的事实。目标是少重复解释、做出更合适的行为，不是存更多记录。
4. **各端同一现场**：Windows、macOS、Android、iOS、Apple Watch。手机和电脑看完整任务进度；手表看简要进度、处理审批、完成时震动；任务可以跨设备接续。本机作为个人服务端；手机在电脑离线时也能独立工作，联网后合并。
5. **主动陪伴与精灵**：主动程度可按偏好调整。精灵是跨手机、电脑、手表的可视化陪伴与反馈载体，结合获准的健康、情绪与约定提醒。
6. **共同空间**：共养包括共同对话、共同任务、共同经历约定和共享状态。退出后记得过去、知道关系已变化；结束关系与删除记忆分开，由各自决定。其他对话默认不共享。

## 产品与依赖

| 名称 | 角色 |
|---|---|
| WeftMate | 唯一用户入口：账号、设备、会话、模型配置、界面、跨端 |
| MemoWeft | 共享长期理解：证据、形成、召回、纠正、遗忘 |
| WeftMod | 设备能力扩展（原 AI-GAME，手机等） |
| DSH | 内嵌的对话/模型/工具/审批运行时；优先使用其原生能力 |
