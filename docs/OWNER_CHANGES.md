## 2026-10-26 安卓做成窗口

- **本人原话**（10-24）：「可以，按一个大脑、多个窗口来，手机不再自己形成记忆。」
- **做成**：手机不再自己提炼或遗忘记忆，只存原话；连上电脑就交给电脑整理，电脑的记忆同步回手机，离线聊天用这份。聊天、交任务、看进度照旧。
- **分区**：手机与同步、记忆。
- **到哪**：电脑一侧（#681、MemoWeft #145）和手机一侧（#682）已合，Windows 0.2.0-preview.19 已发布；电脑连不上时的两处问题（#684、#685）在修。本人 10-27 起在模拟器上登自己的账号、连日用的电脑试用，说「手机能天天用了」算完。

## 2026-10-26 少防御，按分区干活

- **本人原话**：「防御太多太严了，正真的进度就走不下去了，一直围绕一个口子修bug，又浪费时间还浪费token……不要给Agent过多的限制，不用告诉它不要做什么，应该告诉他怎么去做」
- **做成**：AGENTS 只写怎么做；地图按分区指明该读哪一页；旧专题文档和完整决定表打标签 `archive/2026-10-26` 后从仓库删掉；任务书只写目标、现象和做法，不附旧测试结果；代码改到哪，就删掉那里多余的兼容分支、兜底和只测它们的测试。
- **到哪**：框架已换（本页所在的 PR）；代码里的旧兼容和兜底随各分区的改动逐步删。
