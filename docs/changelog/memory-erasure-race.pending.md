删除记忆，或删除对话时选择同时遗忘记忆后，先前排队的纠正不会把原文写回本机；重启和重试也不会恢复已删除内容。

按描述找到的记忆若在同时被删，也会停止纠正并清除排队原文。

撤回来源后会清掉待处理删除记录中的原文；部分遗忘会保留已完成的结果，不再显示为整次都没找到。

撤回一个会话时，也会清掉从未纠正过的记忆所留下的待删除原文，同时保留其他会话的纠正和来源。

选择同时删除聊天原话后，只有核对原话确实擦除才会提示清理完成；暂时擦不了会保留“重试清理”入口，重启后也能继续。

记忆删除和清理的提示改为日常用语，明确说明正在处理、尚未确认或缺少权限，以及接下来可以做什么。

删除确认框和操作失败后的提示也统一改为日常用语，桌面与手机保持一致。
