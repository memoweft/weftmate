明确说“忘掉”某件事时，程序会核对删除范围和实际结果；能安全完成时删除相关记忆、旧版本和来源原文，保留原对话。
删除前会结合整句话核对意思，翻译、提问和带条件的话会继续正常处理；只删除明确指定的人的记忆，其他人或归属不清的记录会保留并说明。
同一批消息里补充的停止要求会一起核对；共用来源里还有其他话题时会保留，遗忘整条修订链前先列出连带内容，超时或取消后按实际结果说明。
纠正会关联你的真实原话，避免整理同一回合时又留下另一份相同偏好；旧版记忆组件不支持时会如实提示更新。
修复后台恢复与新遗忘请求同时出现时，新请求可能未执行就被留到稍后的问题；已有失败仍按原节奏恢复。
相关来源还包含需要保留的独立内容时，会明确说明这次未执行或只部分完成，不再把已删掉部分条目说成已经完全忘掉；此前结果不确定的请求只按原身份核对，不重复删除。
升级后继续处理旧遗忘请求前，会补核对原来确认的范围；已经执行但无法确认完整结果时会如实说明。修复他人的目标事实与本人的无关内容共用来源时，可能误挡本人遗忘请求的问题。
核对遗忘结果时，记忆归属出现冲突会停止并如实说明，避免把仍保留的本人内容误报为已完全忘掉。
保留记录的数量不再重复计算记忆与它的同一份来源，独立来源仍保留并单独计数。
遗忘请求过长或未能完整核对时会停下并说明，不再截掉后面的条件重新删除；修复记忆页无法删除尚未整理成正式记忆的独立来源的问题。
