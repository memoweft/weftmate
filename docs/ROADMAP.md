# WeftMate 总路线

## 当前：完成 WeftMate 自有 UI

- 建立最小界面：对话、系统、设置；
- 默认进入 WeftMate UI；
- DSH Web 只保留为开发和诊断入口；
- 修稳启动、关闭、错误和测试基础；
- MemoWeft 试验接缝不得影响主程序；
- 暂不接入 AI-Game。

完成结果：即使 MemoWeft 和 AI-Game 不可用，WeftMate 也能正常启动和使用。

## 接着：完成 DSH 最小产品闭环

- 会话创建与恢复；
- 消息发送与流式回答；
- 停止、重试和继续；
- 模型、工作区和权限；
- 基本工具活动与错误展示。

完成结果：用户不打开 DSH Web，也能在 WeftMate 中完成真实对话和 Agent 工作。

## 然后：完成统一管理框架

- 统一展示外部系统的安装、连接和健康状态；
- 统一启动、停止、重启和诊断；
- DSH 使用正式 adapter；
- MemoWeft 继续作为试验 adapter；
- AI-Game 等具备稳定接口后再加入。

完成结果：外部系统可以独立运行、升级和故障，不互相拖垮。

## Windows 预览版

- 打包 WeftMate UI 和 DSH；
- 完成凭据、本地数据、安装、更新和诊断；
- MemoWeft 试验功能默认不作为正式能力；
- AI-Game 未接入不阻止预览版使用。

完成结果：没有开发环境的 Windows 电脑也能安装和使用 WeftMate。

## 按成熟度接入外部能力

- MemoWeft 稳定后，接入记忆写入、Recall、来源、纠正和删除的最小闭环；
- AI-Game 稳定后，接入状态、事件、用户问题和回答的最小闭环；
- 两个项目互不等待，谁先成熟就先接谁；
- 所有内部逻辑继续留在各自项目中。

## Windows 完整集成版

DSH、MemoWeft 和 AI-Game 都形成稳定最小闭环后，统一收口安装、更新、恢复、诊断和普通用户体验。

## 多设备协同

Windows 版稳定后，再扩展 iOS、Android 和手表端。移动设备先承担聊天、通知、确认、审批和状态查看，复杂工作继续由桌面端及其连接的系统执行。

## 当前不展开

- MemoWeft 正式产品化；
- AI-Game 正式产品化；
- 桌宠与感知增强；
- 手机和手表开发；
- 插件市场；
- 复制或合并 DSH、MemoWeft、AI-Game 的内部代码。
