# UNIFIED_ASSISTANT_09：准确停止同一电脑任务，并在核对后恢复

日期：2026-10-03。状态：开发验证通过，候选已发布，待用户试用。用户明确“继续路线”；沿`PROJECT_DIRECTION`当前第4阶段接续。08的文件与任务控制候选仍待用户真机确认，本轮推进不倒填旧候选为通过。

## 用户结果

手机或电脑在同一任务详情点击停止时，正在处理该任务的电脑回合会被准确中断，待处理的同任务消息被撤回；服务记录真实终态后两端显示已停止。后来发出的其他任务或消息继续运行。恢复先核对现有步骤与成果，再按用户明确下一步继续，不重复生成已经核验的文件。停止请求、已发起取消、已观察到终止和结果不明分别呈现。

## 依据与范围

固定DSH rc.5（对话运行时）的普通`session.cancel`只有会话身份。当前`session.prompt`已经把RPC（远程调用）身份写入用户来源`source.rpcId`，WeftMate保存同一`receiptId`。本轮新增同进程控制插件：同步核对当前执行体、预设、未结束回合与确切消息来源后才调用取消；队列中只删除确切消息。混合无关用户来源、缺失身份、回合已变或IPC（进程间通信）结果不明时不猜测取消。

- 账户服务先持久记录停止意图及目标消息身份；派发回执竞速、断线和重启均按原任务重新观察。已保存的成果和已执行步骤保留，不宣传取消会回滚副作用。
- DSH父子进程采用独立、严格字段和有时限的请求/回执，核对当前子进程代次；不升级或修改vendor（内嵌依赖），不调用有竞争窗口的会话级取消作为替代。
- 历史投影增加经过验证的回合和消息回执身份；相同文字的不同消息分别辨认。旧资料无此身份时保持明确未确认状态，禁止盲目重放。
- 手机和电脑任务详情同时接真实控制状态与恢复门槛，沿用Weave；纯界面更新优先从服务器发布，原生桥不变时保留既有APK（安卓安装包）。
- 本轮不开放任意PowerShell、浏览器、文件系统根目录或朋友账户控制宿主；WorkBuddy外部业务后置。精确停止后，下一无外部账户目标为“读取获准项目目录并生成带来源摘要”，另立接续范围。
