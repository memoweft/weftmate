## 本轮实际修改

- 原文由Core（核心库）切分并编号；模型选择片段编号，代码从真实Evidence（原始证据）确定位置和正式文本，保留旧引用格式兼容。
- 人物命名按原文结构处理口语语气词，明确引号内的姓名保留。既有Entity（实体）及有效别名成为检索依据。
- 同一句前段或同会话此前用户原话只有一个明确人物时，后段代词可以绑定到该人物；多人歧义不猜，AI建议不能建立人物事实。
- 第三方偏好真实绑定到对应人物，可修正同一人的旧偏好；正式召回按人物收窄，并同时带出身份和相关当前事实，避免把本人或其他人的同词偏好混入。
- V8片段事件无法证明的可选参与者关联可以舍弃，保留原事件与同回合其他有效事实；不会编造参与关系。
- 通过现有boundary store（边界存储）对指定旧任务新建补处理任务，复用原Evidence，不重置旧终态或复制聊天。该维护入口只入队，调用方需显式唤醒或运行worker（处理进程）。

## 用户试用

1. 在当前候选另开新会话，直接问原来关于这位朋友的自然问题，不必重讲背景。
2. 换一种说法问他是谁、现在的偏好、先前与后来怎样变化，查看是否把人和时间接起来。
3. 问哪些是对方反馈、哪些只是AI建议，以及你是否确认过实际行动。
4. 需要核对时，在记忆管理的来源与依据里查看原话；之后再用另一个人物验证迁移效果。
