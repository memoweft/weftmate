# A15 · Apple UX-2 / UX-3

本包只使用合成账号、合成正文、随机回环端口与隔离目录。宿主为生产 `createPersonalAccessService`，会话、归档、用量与思考偏好走真实 HTTP / Cookie / CSRF；DSH 日志、执行后台和模型为合成，不代表真实模型或供应商账单验收。

Mac 会话行支持悬停 / 键盘聚焦的置顶、归档、更多。约 0.5 秒提示完整标题、项目 / 分组、真实更新时间和执行电脑，提示在侧栏外层按行定位，不截断、不夺焦点。归档成功后可在 10 秒内撤销。iPhone 保留长按菜单。项目按真实更新时间倒序显示最近 5 条，更多按账户与项目存本设备偏好；搜索不写偏好，项目内置顶不会进入普通置顶区。缓存保留真实更新时间与宿主，旧记录缺时间仍显示未记录。

头像菜单包含账户标识、同一账户月份的金额 / 有效额度剩余、设置、帮助 / 关于及退出确认。iPhone 设置首页使用同一用量呈现。先读账户统计时区，再请求该时区的月份；读取不写时区。金额与比例共同取自一次 `UsageSummary`，无上限显示请求数，未计价说明保留。账户 / 宿主 / 设备 / 请求代次变化会丢弃旧结果。

Mac「+」提供文件、系统区域截图和剪贴板图片；iPhone 提供相机、照片、文件。导入复用原附件草稿、暂存与回执，异步结果核对来源身份和对话，取消与切换不会带入另一草稿。区域截图使用系统 `screencapture -i -s`，离开原对话或账户会结束本包捕获进程。原生验证注入合成文件和图片，不读取 / 写入本人剪贴板，不捕获本人桌面。

深入思考仅在模型目录声明支持时显示，模型设置标明能力。已建会话 GET / PATCH `/sessions/{id}/thinking`，有效回应后才显示标记；客户端仅提交 `{enabled}`，不拼提供方字段。项目新草稿先创建、再保存偏好、最后开放聊天；保存回应丢失时复用原创建回执重试，已创建的会话不会因重试而重复创建。

运行中占位按账户的 D36 设置显示「排队到下一条…」或「引导当前回复…」。子任务从步骤与 `subtask.updated` 合并，启动工具结束不会结束后台任务；胶囊显示名称、三态、真实时间戳耗时，缺时间显示未记录，不将计时换算成进度。点击定位并展开原步骤，全部结束后隐藏。列表以原步骤身份保存控件，增量更新不夺输入焦点。Watch 未增加输入区。

- Swift A15 定向 9/9：月份边界与有效额度、无上限与未计价、展开偏好隔离 / 重读、真实时间排序 / 缓存、思考代次与身份状态机、后台身份合并 / 原生终态 / 未记录耗时。
- 两个独立 Swift 状态程序 2/2：实际用量回调先读账户时区、旧账户回调丢弃、当前账户金额、错时区拒绝；原附件上传 / 回执 / 草稿 / 身份回归。
- Node 文案、设计令牌及共同操作名定向 12/12。
- iPhone 浅 / 深 XCUITest：长按归档 / 撤销、最近 5 条与更多、头像 / 设置用量、「+」菜单与合成文件、思考开关 / 标记、D36 两种占位、子任务列表 / 原步骤展开 / 终态消失，输入文字与键盘焦点在更新后保持。
- Mac 浅 / 深 App 内原生 AX：悬停按钮与完整提示 / 焦点、归档撤销、更多、头像用量 / Esc、「+」真实菜单动作与合成附件、思考开关、子任务与原步骤、D36 设置、最窄主窗口。另保留创建成功但思考 PATCH 回应丢失的原生重试场景，确认同一会话与成功后标记。

Mac XCUITest 在执行任何用例前初始化失败：`Timed out while enabling automation mode`，原记录为 `mac-xctest-unavailable.json`。未修改机器自动化 / 辅助功能权限。Mac 的两个通过结果来自 App 自有控件 / 窗口运行器，明确不计为 XCUITest 通过。该运行器只读本 App 的 AX 对象、向本 App 窗口发原生事件并捕获本 App 窗口，不操作其他程序。

运行器：`run_a15.py`，宿主：`a15_fixture.mjs`，iPhone / Mac XCUITest 源：`A15UXUITests.swift`，Mac 替代运行器：`UI/A15MacReview.swift`。构建统一 `-jobs 2`，Xcode 构建 / 测试串行，仅使用一个专用 iPhone 模拟器。`verify_a15_evidence.mjs` 核对四组结果、原 PNG、同月用量查询、思考回执与界面文案，`validation.json` / `screenshots.json` 包含代码 / 二进制 / 截图摘要。界面扫描使用截图同时取得的原生可访问名称 / 值，合成私有正文标记和合成模型密钥标记均须为 0 命中。
