# APPLE-9 · iPhone 模型服务与多台电脑

本包消费 MODEL-1 / M3-2 已合入的契约，没有修改云、电脑运行时或 `/personal/v1` 接口。

## 行为

- 电脑模型先读 `/model-services`，利用附带模型投影与选择；404/405 才回到旧电脑模型读取，网络和认证失败保留原错误。目录一小时缓存、失败至少30秒退避，打开菜单先呈现再刷新。
- 手机模型库使用原来的 ThisDeviceOnly Keychain。迁移前将原 `.models` 数据写到同一钥匙串的 `.models.before`，保留原库；新库单个 Keychain 写入，地址规范化与密钥在内存比较，同地址同密钥合并，旧型号与别名保留。重复迁移不重复；写入失败可继续旧配置，坏新库可从保留的旧结构重新整理。聊天及附件仍使用原账号 AES-GCM 文件。
- 输入区使用已生成的 `wm-model` 项目星芒，图标按钮44点、读屏含当前型号。自绘菜单右侧单勾、无选中底色、单服务无标题、多服务分组，长目录保留当前/最近/前部常用型号，全部型号在同菜单搜索；能力只读明确声明。
- 手机发送与记忆提炼在首次等待之前固定配置，切换不取消旧回复，下一条采用新型号；新对话默认持久在钥匙串。电脑选择发送具体 `modelId` 与当前执行段 ID，读取 `selectedModelProfileId`，不修改历史创建命令。
- 服务卡片能查询、编辑、显示/隐藏、手填和删除；输入密钥后自动查询，保留显式重试，不发送测试聊天消息。认证错误与不提供目录分开说明。手机直接支持 OpenAI 兼容及 Anthropic 消息/图片/文本流，隐藏思考不进入正文或记忆。
- `capabilities.multiHost:1` 加多台目录才显示电脑按钮与标签。各电脑分别核对信任/认证，列表ID带电脑身份，同名用目录显示名；唯一在线/上次使用/来源选择，来源离线不改投另一台。
- 电脑改名/移除沿 DPoP 账号路由；移除说明保留电脑本地内容。切换电脑清理旧可见状态与回调代次，但保留各电脑的独立加密副本；删除只清目标副本，退出账号清所有副本。手机原文交接首次固定电脑，不将同一已冻结对话改投第二台。

## 验证

准确的最终通过数、构建和截图见 `verification.json`、`screenshots.json`。相关 Swift 包测试覆盖迁移备份、重复/失败/坏新库、型号别名、目录筛选/搜索、精确路由、CSRF、DPoP、404兼容、下一条选择、电脑选择与副本隔离。实际 iPhone 源码状态程序使用随机端口本机模型清单/对话服务及运行时随机凭据，验证换模期间旧回复、下一条、重建模型、加密明文扫描与账号切换；不把内存凭据替身说成真实 Keychain 证明。

原独立聊天、附件、轻量记忆、主对话与发送契约状态检查同时复验。设计令牌、回调隔离、源文案检查通过；没有本地跑全仓单测。`apple-copy-regression.test.mjs` 完整文件有一条健康页声明位置断言在 `origin/main` 同样失败，本包没有改健康页或该断言；其三个文案用例通过，失败保留在私有运行日志。

截图为真实原生 XCTest 全屏附件，带系统状态栏，内容为合成状态。模型服务与电脑组件使用产品源码；电脑截图没有真实账号/电脑认证，不作为多电脑服务端全链路证明。新增查询阶段只连接本机合成目录。模拟器台账见 `verification.json`；不打开 Simulator 窗口。

## 尚未验收 / 边界

- 环境没有 MIMO_API_KEY，没有寻找凭据，真实模型请求0；未连接生产云、本人电脑或真实账号。
- 两台真实电脑/生产中继、OS Keychain 的跨安装持久性、真机后台/撤权/通知到达、运行中电脑换模及新型号等待安装需要真机或隔离真实电脑联调。
- 原生动态按当前电脑读取并标来源，尚未汇总各电脑动态；原生没有新增跨电脑系统通知收件流程。审批已标当前来源电脑。
- 本包沿已有 M3-A 加密聊天补交及命令账本，没有新增 S7 云端离线执行事项的原生登记/取消回执页面；`COMPUTER_REMOVED` 事项取消的人话回执未接，移除由已合入的云端执行取消。没有把聊天补交等同于云执行事项验收。
- 未做跨电脑任务移动、文件搬运或记忆合并。模型能力未知不猜，尚无执行段的新对话思考仍受已有会话思考接口边界限制。
