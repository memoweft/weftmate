# APPLE-2：按需登录与设备管理

iPhone 与作为远程客户端的 Mac 共用原生登录模型：邮箱＋密码（新设备追加邮件验证码）或邮箱＋验证码；首次打开可写本机笔记，服务器功能才弹出可关闭的登录页。邮箱核对后自动连接电脑，不再出现设备批准、可信交付码、扫码配对或等待配对页面。电脑不可达时保留云登录与本机页面，提供「再试一次」。

原生协议沿 AUTH-1：App 内授权、PKCE S256、DPoP、刷新轮换、受保护存储。首次电脑连接先经过系统 CA／域名校验，再核对 `hostTrust` 的 ES256 签名、账号主体、电脑号、收件设备号、公钥指纹、120 秒期限和地址；固定证书后再次读取 `/status`，核对账户和电脑身份后才保存内容会话。已保存安装公钥或证书指纹变化不会自动覆盖。

设备页用名称、首次登录和最近使用展示已登录设备，确认后可立即下线。前台云目录检测新设备，按账号持久记录已见设备，显示可点开的应用内通知。没有新增系统通知权限、APNs 或手表登录页面；后台唤醒和真机 WatchConnectivity 仍属于原有 D38 边界。

## 重放

先构建 `WeftMatePhone` 的 `build-for-testing`，然后依次运行：

```sh
python3 apps/apple/Tests/run_apple2_ui.py \
  --xctestrun <构建目录>/WeftMatePhone_iphonesimulator26.2-x86_64.xctestrun \
  --simulator <iPhone UUID> --theme light \
  --result <隔离目录>/light.xcresult --evidence apps/apple/Tests/Evidence/APPLE-2
# 同一台模拟器退出后，以 --theme dark 和新结果目录重放。
```

每种登录方式使用独立的新合成云端和邮箱夹具，保留五次发信后的真实限速，不清空限速表、不改变云规则。浅色真实限速状态也保留截图。

夹具运行实际云服务、OIDC 提供方、文件邮件和个人服务。合成路由代理只把已授权 `/hosts/connect` 的远程地址替换成本机随机端口，以及测试指定的离线状态；登录、密码检查、邮件码、设备核对、PKCE、DPoP、宿主签名与内容会话均不替换。电脑后端复用仓库合成 DSH 日志，不运行真实模型。模拟器的 HTTP 只走已有 Debug＋UI 测试双开关；此证据不冒充生产 HTTPS／中继验收。HTTPS 固定与拒绝路径由共享包定向测试另验。

所有图片来自本包合成 App 的 XCTest 整屏截图，包括系统状态栏；深浅仅改变 App 启动参数，不修改系统或模拟器设置。不复制参考截图、不读取本人账户、不发送真实邮件，不提交运行目录、密码、验证码、证书或密钥。

文案对照见 [copy-changes.md](copy-changes.md)。最终截图与逐项测试结果见本目录验证文件和交付报告。

## 最终验证与边界

- iPhone 实服务主路：浅色 2/2、深色 2/2；每种方式新建合成云端，全部零失败／零跳过。覆盖本机免登、密码与新设备邮箱码、纯邮箱码、错码／过期／重发、自动主对话、电脑离线重试、设备通知／下线、关于、原文缓存与可取消的重新登录。
- iPhone 入口回归：3/3，覆盖本机无需密码、两种方式不出现配对／浏览器以及取消返回。
- Mac 共享包：100/100；PKCE／DPoP／刷新轮换、邮箱核对声明、收件账号与设备／签名／固定值拒绝、身份隔离、401 后只读身份与缓存、About 更新与设置解析。
- Watch 共享状态：6/6；审批登记／重复操作／手机不可达／回执不确定、完成提醒一次及拒绝／中止不误提醒。Mac／iPhone／Watch 原生构建通过。
- 文案与回调隔离：9/9；公开身份扫描 8027 文件零命中。38 张原生整屏：手机浅深各 18，真实限速状态 1，单台 Watch 合成审批展示 1；清单、尺寸和 SHA-256 见 `screenshot-manifest.json`，离线像素文字见 `screenshot-text.json`。

Watch 沿用 iPhone 的同一内容身份与原 WatchConnectivity 桥，没有独立登录页，也不传密码、云凭据或电脑 Cookie。为遵守一次只开一台模拟器，**没有同时启动手机和 Watch 做真实配对传送**；独立 Watch 图与六项状态测试不冒充手机到手表的实时批准／提醒回执。APNs、被系统结束后唤醒、真机和正式云端／Windows／生产 HTTPS 中继没有验收或部署。

旧 LG2 注册／恢复／生命周期测试与合成绑定驱动已按新入口改预期并编译；本包实际执行的是 APPLE2 四项实服务主路及 S1c 三项入口回归，没有把未重跑的旧两项流程计入通过数。原始开发失败来自标识／导航定位、合成邮件限速与本机能力夹具；最终通过门保留原断言和云规则，不按旧截图或零项执行算通过。
