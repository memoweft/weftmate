# HEALTH-4 iPhone 健康页与采集

本目录只含合成数据。iPhone 正式采集只读，不请求写权限；逐搏、位置和设备名不进入请求或队列。新的写入代码只属于独立 `WeftMateHealth4Seed` UI 测试依赖，正式 Phone / Mac / Watch 目标不包含它。页面值、分数、解读与分析来自电脑接口，手机不计算任何分数。

## 口径与持久化

- 账户时区自然日，最近 7 天变更才送。步数、活动能量与系统运动分钟使用 HealthKit 累积统计；静息心率取当日离散平均。呼吸、血氧、手腕温度、最大摄氧量按当日有效测量平均，血氧转为百分数。
- 睡眠按完整睡眠段醒来日归属，重叠区间去重，清醒覆盖睡眠，深睡／快速眼动／核心覆盖未分期，卧床不增加睡眠分钟；起止与分段都是实际时刻。夏令时使用实际经过分钟。
- 心率变异性代表值取该醒来日最长睡眠段内实际睡眠时的测量均值，清醒、日间测量和短小睡不混入。夜班主睡眠仍可代表当天。
- 小时心率恰好 24 格，十五分钟恰好 96 格，均为当地钟表格；春季缺少的格为空，秋季重复的格合并测量，平均／最低／最高不补零。
- 运动重叠按时间区间去重，跨日按实际覆盖比例分配有效运动时长与能量；心率区间依据五个最大心率百分比区间：低于60%、60–70%、70–80%、80–90%、90%以上。边界进入上一区间，每次心率最多代表下一分钟且不跨缺测长空档，区间总分钟不超过有效运动时长。HealthKit 没有公开生理最大心率量，使用约定的 `211 − 0.64 × 年龄`；缺年龄不分区。
- 每次心率变异性测量的逐搏序列只在内存。剔除相对前一原始间期超过20%的异常值，跨缺口不连接；相邻有效差算均方根，50毫秒直方图算约定压力指数，有效间期不足30或零跨度留空。并列众数组取较低组，避免非确定性；浮点边界误差不会改变组别。
- v2 请求省略每次变异性测量、十五分钟心率、睡眠分段；只有当前 overview 明确 `capabilities.record >= 3` 才发送 v3。资料仅在 `capabilities.profile == true` 时发送，只含年份、性别、身高、体重。没有完整生日、逐搏、来源设备名或位置。
- 追加授权只在健康页提出；授权尝试完即按缺测正常显示，不靠 HealthKit 读取状态推断拒绝。90天历史每批最多10天，逐批保存确认；失败和中断保留未确认日期。v3首次支持后重读／重送90天，已完成的版本不重复补传。iOS暂停后由前台、系统后台刷新或观察事件接着做，不用前台阻塞等待完成。
- 每个账户与电脑地址独立保存队列和页面缓存；文件保护、0700目录、0600文件、备份排除。页面分数、常见范围、平均线、解读与分析都来自接口。离线保留缓存与更新时间，分析只保留当天。

## 服务与系统边界

HEALTH-2远端分支的客户端文档已经有v2／页面接口，但当时该分支每日记录校验仍只收v1，且没有 `docs/HEALTH.md`。本包没有合并或修改电脑代码，使用 `health4_host_fixture.mjs` 的本机合成契约服务验证 v2/v3、页面、资料、提醒和 AI 分析；未接线上云、本人电脑或任何真机。

真实系统验证：隔离模拟器 HealthKit 的读／写授权、89天有效样本与一天缺测、重叠睡眠、心率变异性及逐搏系列、运动与心率、资料中的身高体重。仅造数目标有写权限。系统禁止第三方写睡眠手腕温度，模拟器也没有设置生日／性别的公开接口；这三项在 Debug+simulator 测试路径注入合成值。系统运动分钟只读，合成运动记录的五分钟并不冒充系统运动分钟；后者无测量保持空。

界面测试宿主调用实际采集、队列、个人客户端与原生健康页；「接着问它」调用实际主对话草稿方法，测试宿主呈现草稿输入框，不自动发送。正式五项导航的接线经过原生构建；完整真实主对话加载与真机后台唤醒仍需后续验收。

## 两个 AI 开关

顶部解读直接显示电脑回执；`modelInsightsEnabled` 与下面各项的 `itemAnalysisEnabled` 独立。旧电脑缺少后者时没有打开入口。每项默认收起，只有展开才POST，已生成当天内容通过GET和本地缓存恢复；关闭保留当天旧结果，409／离线／失败可重新操作。统计版和模型版使用同一呈现。两个开关可在现有设置和健康页设置里随时改变。

## 需要电脑端配合

1. 实现并部署第16节v2批量／页面接口以及v3能力与资料接口；只有支持完整v3后才公告record:3。
2. 第4节分析缓存GET尚未规定外层结构，本端使用 `{items:[分析]}`；请在正式契约里固定或通知调整。
3. HEALTH-5三张卡只定了名字，没有overview结构和metrics指标定义；本端暂读可选 `stress / energy / fitnessAge`，数值使用score或value，压力时刻measuredAt或updatedAt，电能曲线points中的value。正式落地需要固定字段与趋势id；未返回字段就完全不显示卡。
4. 第16节overview睡眠只有时长／起止，深睡和快速眼动经metrics读取；usage仅有深夜分钟，没有最后使用电脑时刻，页面据此显示「深夜使用电脑xx分钟」。有lastActiveAt时才显示结束时刻，不把1–5点使用量推断为几点关电脑。

Apple Watch 原生端未改；Mac 原生端未改，共用文件的导航和设置改动均限定在iOS。
